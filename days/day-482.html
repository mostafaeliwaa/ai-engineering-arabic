تسخين ٥ دقايق: فاكر الدرس اللي فات؟

امبارح بنيت الـ evaluator (درس ٥٣: Result Evaluator). جاوب في دماغك الأول، وبعدين افتح الإجابة.

  1. ليه paired t test؟
    الإجابةلأن نفس الـ seed بين candidate وbaseline بيلغي ضوضاء التهيئة، فالفرق المتبقي منسوب للتغيير.
  2. إيه ترتيب بوابات الـ verdict؟
    الإجابةأولًا failed (أي terminal مش ok)، بعدين threshold الـ improvement (٢٪)، بعدين الـ significance (p ≤ 0.05)، وأخيرًا الإشارة تحدد improved أو regressed.
  3. ليه بنعمل log للـ perplexity قبل المقارنة؟
    الإجابةلأنها أُسّية في الـ loss. الـ log بيخلّي threshold نسبي زي ٢٪ مفهوم مع الـ linear metrics، (32→28 بتبقى ≈ 0.039).

01

ليه Skeleton الأول؟ الهيكل هو العقد

الـ LaTeX skeleton هو عقد بين الباحث والـ typesetter: لو العقد اتكسر الـ document مبيتعملوش compile، والفشل بيبقى عالي الصوت. فابني الهيكل الأول، وبعدين املاه.

المسودة اللي بتبدأ كنثر بتجمّع «دين هيكلي»: المقدمة تكبر تلات فقرات المفروض يبقوا في Related Work، وfigure بيتشاور عليه قبل ما يتعرّف، والـ bibliography يطلع فيها تلات keys لنفس الورقة. لما تاخد بالك، تكلفة إعادة الكتابة أكبر من تكلفة الكتابة.

تشبيه: زي مهندس معماري: بيرسم الهيكل الخرساني (الأعمدة والبلاطات) الأول، وبعدين بيبني الحيطان والتشطيب. لو بدأت بالتشطيب من غير هيكل، أول دور تاني هيبوّظ كل حاجة.

الـ skeleton بيعكس ده: الهيكل يتعلن كـ data من الأول. الأقسام slots ليها أسماء وترتيب. الـ figures slots ليها ids وcaptions. الـ bibliography keys معلنة فوق مع الـ entries بتاعتها. وبعدين الـ prose بيتولّد في الـ slots واحد واحد. والـ harness يقدر يتأكد قبل أي نثر إن كل figure ليه slot، وكل citation ليه entry، وكل قسم في الفهرس.

نفس الانضباط: زي ما الدروس اللي فاتت طبّقته على الـ plans والـ tool calls والـ traces: الهيكل هو العقد.
02

شكل الـ Paper: كله data عادية

الـ Paper = metadata (عنوان، مؤلفين، abstract) + قائمة sections + قائمة figures + قائمة bibliography. كل ده Python data عادية. والـ renderer دالة pure من Paper لنص LaTeX. الـ harness يقدر يفحص الـ paper قبل الـ render: يعدّ الأقسام، يلاقي الـ figures الناقصة، يتأكد إن كل \cite{key} ليها BibEntry.

03

عقد الـ Render وبوابات الـ Validation

الـ renderer بيضمن ٣ حاجات: كل figure slot بيطلّع \begin{figure} بـ label ثابت fig:<id>. وكل section بيطلّع \section{} بـ label sec:<id> عشان الـ cross-references تشتغل. وblock الـ \bibliography بيشاور على references.bib فيه بالظبط الـ entries المعلنة على الـ paper، لا أكتر ولا أقل. كسر أي واحدة = render error مش warning.

والـ writer بيشغّل بوابات قبل ما يكتب أي ملف. الدرس بيعدّ ٤ في الشرح، والكود الفعلي بيفحص أكتر:

  1. الـ title مش فاضي.
  2. الـ abstract مش فاضي.
  3. كل figure id فريد (وكمان bibliography key فريد في الكود).
  4. كل cites في أي section ليها key معلن في الـ bibliography (وكمان كل figure_refs ليها figure معلن).

أي بوابة بتفشل بترمي PaperValidationError بسبب دقيق، من غير كتابة جزئية: يا كل الملفات التلاتة يا ولا واحد.

ملحوظة: وجود ملف الـ figure على القرص مش بيتفحص هنا؛ الـ LaTeX compiler هو اللي بيتأكد منه بعدين.

معمل ١: مسار الـ PaperWriter.write

دوس على الخطوات: validate ثم fill prose ثم render ثم كتابة التلات ملفات. لاحظ إن الـ validation أول حاجة، لأن مفيش partial write.

معمل ٢: كسّر الـ Paper وشوف مين يوقفه

فعّل (1) أي «عيب» وشوف رسالة الـ PaperValidationError المناسبة وهل الملفات اتكتبت. لاحظ إن الـ gates بتتفحص بالترتيب: أول فشل هو اللي بيظهر.

04

حقن الـ Figures من نتايج التجارب

الدروس اللي فاتت طلّعت نتايج التجارب كـ JSON manifests. كل manifest فيه name وقائمة artifacts (كل واحد path وcaption). الـ read_experiment_manifest بيحوّلهم لـ Figure records:

  • الـ id: مشتق من اسم التجربة + عدّاد تصاعدي عام (monotonic) على كل الـ manifests، ومنضّف بـ regex: أي حاجة مش حرف أو رقم بتتحوّل -، وبعدين lowercase.
  • الـ caption: من الـ manifest (ولو فاضي بياخد اسم التجربة).
  • الـ path: os.path.relpath بالنسبة لمجلد الـ paper، عشان الـ LaTeX يعمل compile حتى لو مخرجات التجربة في مكان تاني. أي artifact من غير path بيتتخطى.

الحقن حتمي (deterministic): نفس الـ manifests = نفس الـ ids. وبكده بتقدر تجرّب بالـ tests.

معمل ٣: الـ ids والـ escaping

الجزء الأول بيوري إزاي العدّاد التصاعدي بيطلّع الـ ids. والتاني بيوري _escape_latex: اكتب نص فيه رموز LaTeX الخاصة وشوف إزاي بتتهرّب. من غير ده الـ title اللي فيه % أو _ هيكسر الـ compile.

الدرس مبينادييش موديل. الـ MockProseGenerator بيقرا outline (جملة قصيرة لكل section) ويطلّع نثر حتمي: فقرتين، العنوان مضفّر فيهم. بيذكر الـ figures والـ citations بالظبط لما الـ outline يعلنهم. ده كفاية لاختبار كل سلوك في الـ writer.

import json, os, re
from dataclasses import dataclass, field
from typing import Callable, Iterable

class PaperValidationError(Exception):
    pass

@dataclass
class BibEntry:
    key: str
    entry_type: str
    fields: dict
    def to_bibtex(self):
        lines = [f"@{self.entry_type}{{{self.key},"]
        for k, v in sorted(self.fields.items()):
            safe = str(v).replace("{", "").replace("}", "")
            lines.append(f"  {k} = {{{safe}}},")
        lines.append("}")
        return "\n".join(lines)

@dataclass
class Figure:
    id: str
    path: str
    caption: str
    width: str = "0.8\\textwidth"
    @property
    def label(self): return f"fig:{self.id}"

@dataclass
class Section:
    id: str
    title: str
    body: str = ""
    cites: list[str] = field(default_factory=list)
    figure_refs: list[str] = field(default_factory=list)
    @property
    def label(self): return f"sec:{self.id}"

@dataclass
class Paper:
    title: str
    authors: list[str]
    abstract: str
    sections: list[Section] = field(default_factory=list)
    figures: list[Figure] = field(default_factory=list)
    bibliography: list[BibEntry] = field(default_factory=list)

خطوة ٢: بوابات الـ validation

def _validate(paper):
    if not paper.title.strip():    raise PaperValidationError("title is empty")
    if not paper.abstract.strip(): raise PaperValidationError("abstract is empty")
    fig_ids = set()
    for fig in paper.figures:
        if fig.id in fig_ids:
            raise PaperValidationError(f"duplicate figure id: {fig.id}")
        fig_ids.add(fig.id)
    bib_keys = set()
    for b in paper.bibliography:
        if b.key in bib_keys:
            raise PaperValidationError(f"duplicate bibliography key: {b.key}")
        bib_keys.add(b.key)
    for sec in paper.sections:
        for key in sec.cites:                       # كل citation لازم ليها entry
            if key not in bib_keys:
                raise PaperValidationError(
                    f"section {sec.id!r} cites unknown bibliography key {key!r}")
        for fid in sec.figure_refs:                 # وكل figure ref لازم ليه slot
            if fid not in fig_ids:
                raise PaperValidationError(
                    f"section {sec.id!r} references unknown figure id {fid!r}")

خطوة ٣: الـ escaping والـ render

def _escape_latex(text):
    repl = {"\\": r"\textbackslash{}", "&": r"\&", "%": r"\%", "$": r"\$", "#": r"\#",
            "_": r"\_", "{": r"\{", "}": r"\}", "~": r"\textasciitilde{}",
            "^": r"\textasciicircum{}"}
    return "".join(repl.get(ch, ch) for ch in text)   # حرف حرف، فمفيش double-escape

def render_latex(paper):
    _validate(paper)                                  # الأول: لو فشل، مفيش render
    lines = ["\\documentclass{article}", "\\usepackage{graphicx}", "\\usepackage{hyperref}",
             "\\title{" + _escape_latex(paper.title) + "}",
             "\\author{" + " \\and ".join(_escape_latex(a) for a in paper.authors) + "}",
             "\\begin{document}", "\\maketitle",
             "\\begin{abstract}", _escape_latex(paper.abstract), "\\end{abstract}"]
    for sec in paper.sections:
        lines.append("\\section{" + _escape_latex(sec.title) + "}")
        lines.append("\\label{" + sec.label + "}")
        lines.append(sec.body if sec.body else "% body pending")
        for fid in sec.figure_refs: lines.append("See Figure~\\ref{fig:" + fid + "}.")
        for cite in sec.cites:      lines.append("See~\\cite{" + cite + "}.")
    for fig in paper.figures:
        lines += ["\\begin{figure}", "\\centering",
                  "\\includegraphics[width=" + fig.width + "]{" + fig.path + "}",
                  "\\caption{" + _escape_latex(fig.caption) + "}",
                  "\\label{" + fig.label + "}", "\\end{figure}"]
    if paper.bibliography:
        lines += ["\\bibliographystyle{plain}", "\\bibliography{references}"]
    lines.append("\\end{document}")
    return "\n".join(lines) + "\n"

def render_bibtex(paper):
    return "\n\n".join(b.to_bibtex() for b in paper.bibliography) + ("\n" if paper.bibliography else "")

انتبه للـ backslashes: في ملفك استخدم "\\documentclass" (backslash مزدوج) عشان Python يطلّع backslash واحد. الأصل في code/main.py فتحه وقارن.

خطوة ٤: الـ Mock prose وقراءة الـ manifest

class MockProseGenerator:
    def __init__(self, outlines):
        self.outlines = outlines
    def __call__(self, section, paper):
        seed = self.outlines.get(section.id, section.title)
        first = f"In this section we discuss {section.title.lower()}: {seed}."
        bits = []
        for fid in section.figure_refs:
            bits.append(f"Figure~\\ref{{fig:{fid}}} shows the relevant artifact.")
        for c in section.cites:
            bits.append(f"This builds on prior work~\\cite{{{c}}}.")
        second = " ".join(bits) if bits else "We discuss implications below."
        return first + "\n\n" + second

def read_experiment_manifest(manifests, paper_dir):
    figs, counter = [], 0
    for m in manifests:
        name = m.get("name", "exp")
        for art in m.get("artifacts", []):
            path, caption = art.get("path", ""), art.get("caption", "")
            if not path:
                continue                               # artifact من غير path: اتخطّاه
            counter += 1                               # عدّاد عام تصاعدي
            try:    rel = os.path.relpath(path, paper_dir)
            except ValueError: rel = path
            fid = re.sub(r"[^a-zA-Z0-9]+", "-", f"{name}-{counter}").strip("-").lower()
            figs.append(Figure(id=fid, path=rel, caption=caption or name))
    return figs

خطوة ٥: الـ PaperWriter

@dataclass
class PaperWriter:
    prose: Callable                                     # بيتحقن: mock أو موديل

    def fill_prose(self, paper):
        for sec in paper.sections:
            if not sec.body:
                sec.body = self.prose(sec, paper)
        return paper

    def write(self, paper, out_dir):
        os.makedirs(out_dir, exist_ok=True)
        self.fill_prose(paper)
        tex, bib = render_latex(paper), render_bibtex(paper)   # لو validation فشل هنا، مفيش ملفات
        tex_path = os.path.join(out_dir, "paper.tex")
        bib_path = os.path.join(out_dir, "references.bib")
        man_path = os.path.join(out_dir, "manifest.json")
        open(tex_path, "w", encoding="utf-8").write(tex)
        open(bib_path, "w", encoding="utf-8").write(bib)
        manifest = {"title": paper.title, "authors": list(paper.authors),
            "sections": [{"id": s.id, "title": s.title, "cites": list(s.cites),
                          "figure_refs": list(s.figure_refs), "body_chars": len(s.body)}
                         for s in paper.sections],
            "figures": [{"id": f.id, "path": f.path, "caption": f.caption, "label": f.label}
                        for f in paper.figures],
            "bibliography": [b.key for b in paper.bibliography],
            "tex_path": tex_path, "bib_path": bib_path}
        json.dump(manifest, open(man_path, "w", encoding="utf-8"), indent=2, sort_keys=True)
        return manifest

ملحوظة: الأصل بيستخدم with open(...) لكل ملف. استخدمه في نسختك عشان الملفات تتقفل صح. وطبّق fill_prose قبل الـ render زي ما هو، لأن الـ prose هو اللي بيحط \ref و\cite في الـ body.

إضافة مني: اللي الدرس مقالهوش

الحدس: فصل «إيه الهيكل» عن «إيه الكلام» هو نفس نمط الـ structured output في الـ LLMs: بتدّي الموديل schema (slots) وهو بيملاها، بدل ما تطلب نص حر وتحاول تظبطه بعدين. الـ validation قبل وبعد التوليد بيمسك الأخطاء بدري.
  • خطأ شائع ١: ننسى الـ escaping. % في LaTeX بداية comment، و_ بيكسر الـ compile برا math mode. الـ title والـ caption والـ abstract بيعدّوا من _escape_latex، لكن الـ body بيتحط زي ما هو (لأن فيه أوامر \ref و\cite). يعني الـ generator مسؤول عن نضافة نصه.
  • خطأ شائع ٢: موديل حقيقي ممكن يخترع \cite{key} مش موجودة. بوابة الـ cites بتمسك ده بس لو الـ citations معلنة في الـ section.cites. لو الـ prose فيه cite داخل النص، الـ validation مش هيشوفها: ممكن تزوّد gate تفحص الـ body نفسه.
  • «سلسلة الـ research loop»: ٥٠ يولّد hypotheses، ٥١ يفلتر المحلول، ٥٢ يشغّل، ٥٣ يحكم، ٥٤ يكتب. الـ manifest والـ Verdict بيعدّوا بين الحلقات كـ data، مش كنص.
  • حدود: الـ mock prose مش علم: الدرس بيختبر الـ harness. وأي ادعاء علمي في ورقة حقيقية لازم يتراجع بشريًا.
  • في الـ agents: أي agent بيطلّع deliverable (تقرير، PR، ورقة) بينفع يتبني بنفس النمط: schema أولًا، generation في slots، validation gates، وmanifest بيقراه critic أو شخص.

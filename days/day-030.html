ليه الـ representation أهم من الخوارزمية؟

في الـ ML الكلاسيكي، شكل الداتا بيفرق أكتر من اختيار الخوارزمية. موديل سعر بيت فيه «المساحة» و«عدد الأوض» هيكسب موديل فيه «العنوان كـ string خام» مهما كان الـ learner متطور. الخوارزمية بتشتغل باللي انت بتديهولها وبس.

تشبيه: طباخ شاطر جدًا ومعاه مكونات بايظة، هيطلع أكل وحش. طباخ عادي ومكوناته طازة ومتقطعة صح، هيكسبه. الـ features هي المكونات، والموديل هو الطباخ.

Feature engineering = تحويل الداتا الخام لتمثيلات تسهّل على الموديل يلاقي النمط. Feature selection = رمي الـ features اللي بتضيف noise من غير signal. مع بعض هما أعلى حاجة بتجيب نتيجة في الـ ML الكلاسيكي.

الطريقةبتعمل إيهمثال color = red / blue / greenخد بالك

Target encoding مع smoothing

category فيها صفين بس متوسطها مش موثوق. فبنخلطه مع المتوسط العام حسب عدد الصفوف:

weight = count / (count + smoothing) enc(cat) = weight · mean(cat) + (1 − weight) · global_mean

تشبيه: مطعم جديد عنده تقييمين 5 نجوم. هل هو أحسن من مطعم عنده 2000 تقييم متوسطهم 4.6؟ غالبًا لأ. الـ smoothing بيقول: «لحد ما يجيلك تقييمات كفاية، افترض إنه قريب من المتوسط العام».

الـ Data leakage

الـ leakage = استخدام معلومة في التدريب مش هتبقى موجودة وقت التوقع، فالنتيجة تطلع متفائلة بزيادة. في الـ target encoding: لو حسبت المتوسطات على الداتا كلها (والـ test جواها)، الـ labels بتاعة الـ test دخلت في الـ features. ولو category فيها صف واحد، الـ encoding بتاعه = الـ target بتاعه بالظبط. الموديل بيشوف الإجابة.

معمل ٣: الـ target encoding بيغش إزاي

feature اسمها user_id فيها categories كتير، وكل category فيها صفوف قليلة. الـ target هنا random تمامًا، مفيش أي علاقة حقيقية. بنعمل target encoding على الـ train، ونقيس الـ correlation بين الـ encoding والـ target على الـ train وعلى test منفصل.

  • smoothing = 0 و categories كتير: correlation الـ train عالي جدًا (الموديل «فاكر» إن الـ feature قوية)، والـ test حوالين الصفر. ده overfitting من الـ encoding نفسه.
  • زوّد الـ smoothing: الـ encoding بيتسحب ناحية المتوسط العام والكذبة على الـ train بتقل.
  • جرّب «leave-one-out» (تمرين ٢): كل صف بيتحسب له المتوسط من غير الـ target بتاعه، فالغش بيختفي تقريبًا.

النص: من كلام لأرقام

Count vectorizer: عدّ كل كلمة في المستند. "the cat sat on the mat" ← {the: 2, cat: 1, sat: 1, on: 1, mat: 1}.

TF-IDF: بيوزن الكلمة بقد إيه هي مميزة على مستوى كل المستندات. الكلمات المنتشرة زي «the» وزنها قليل، والكلمات النادرة المميزة وزنها عالي.

TF(word, doc) = count(word in doc) / total words in doc IDF(word) = log( total docs / docs containing word ) TF-IDF = TF · IDF

تشبيه: في جروب واتساب العيلة، كلمة «صباح الخير» في كل رسالة، فمبتقولش حاجة عن الرسالة. بس كلمة «خطوبة» ظهرت في رسالة واحدة، يبقى هي اللي بتعرّف الرسالة دي. كلمة موجودة في كل المستندات IDF بتاعها log(1) = 0، يعني اتشالت عمليًا.

معمل ٢: TF-IDF بإيدك

دي نفس الـ 5 أوصاف بتاعة البيوت اللي في الريبو. عدّل أي سطر أو ضيف سطور (كل سطر مستند)، واختار مستند تشوف الـ count قصاد الـ TF-IDF لكلماته.

  • في المستند الأول: «house» و«pool» مش موجودين غير فيه، فواخدين أعلى وزن. «with» في 3 مستندات، فوزنها أقل.
  • ضيف كلمة «house» في كل السطور: الـ IDF بتاعها بيبقى صفر.
  • الـ count بيدي كل الكلمات نفس الوزن تقريبًا. الـ TF-IDF بيرتبهم حسب التميّز.

Feature Selection: أقل أحسن ساعات

features مش مفيدة بتزوّد noise، وبتطوّل التدريب، وممكن تعمل overfitting. موديل بـ 10 features كويسة غالبًا هيكسب نفس الموديل بـ 10 كويسة + 90 noise، لأن الـ noise بيدي الموديل فرصة يحفظ أنماط في الـ train مش هتتكرر.

Filter methods (قبل الموديل)

  • Variance threshold: شيل الـ features اللي تقريبًا ما بتتغيرش (عمود كله نفس القيمة ملوش لازمة).
  • Correlation: شيل الـ features اللي correlation بينها وبين بعض عالي (مكررة). اتنين r = 0.98 تقريبًا نفس المعلومة.
  • Mutual information: قد إيه معرفة الـ feature بتقلل عدم اليقين عن الـ target.
r(x, y) = cov(x, y) / (std_x · std_y) MI(X; Y) = Σ p(x, y) · log( p(x, y) / (p(x) · p(y)) )

في الكود الـ MI بيتحسب بعد ما الـ feature تتقسم لـ 10 bins. لو X و Y مستقلين، p(x,y) = p(x)p(y) فالـ log = 0 والـ MI = 0.

Wrapper methods (بالموديل)

  • L1 regularization (Lasso): بيزق أوزان الـ features اللي مالهاش لازمة لصفر بالظبط.
  • Recursive feature elimination: درّب، شيل أضعف feature، كرر.

import math
import random

def min_max_scale(values):
    lo, hi = min(values), max(values)
    if hi == lo:                                  # عمود ثابت: رجّع أصفار
        return [0.0] * len(values)
    return [(v - lo) / (hi - lo) for v in values]

def standardize(values):
    n = len(values)
    mean = sum(values) / n
    variance = sum((v - mean) ** 2 for v in values) / n
    std = math.sqrt(variance) if variance > 0 else 1.0
    return [(v - mean) / std for v in values]

def log_transform(values):
    return [math.log(v + 1) for v in values]      # +1 عشان log(0)

def bin_values(values, n_bins=5):
    lo, hi = min(values), max(values)
    width = (hi - lo) / n_bins
    if width == 0:
        return [0] * len(values)
    return [min(int((v - lo) / width), n_bins - 1) for v in values]   # الـ max يروح لآخر صندوق

def polynomial_features(row, degree=2):
    n = len(row)
    result = list(row)
    if degree >= 2:
        for i in range(n):
            result.append(row[i] ** 2)            # المربعات
        for i in range(n):
            for j in range(i + 1, n):
                result.append(row[i] * row[j])    # الـ interactions
    return result

خطوة ٢: الـ categorical encoding

def one_hot_encode(values):
    categories = sorted(set(values))
    idx = {c: i for i, c in enumerate(categories)}
    encoded = []
    for v in values:
        row = [0] * len(categories)
        row[idx[v]] = 1                           # واحد بس = 1
        encoded.append(row)
    return encoded, categories

def label_encode(values):
    categories = sorted(set(values))
    m = {c: i for i, c in enumerate(categories)}
    return [m[v] for v in values], m

def target_encode(feature_values, target_values, smoothing=10):
    global_mean = sum(target_values) / len(target_values)
    stats = {}
    for feat, t in zip(feature_values, target_values):
        s = stats.setdefault(feat, {"sum": 0.0, "count": 0})
        s["sum"] += t
        s["count"] += 1
    encoding = {}
    for cat, s in stats.items():
        cat_mean = s["sum"] / s["count"]
        w = s["count"] / (s["count"] + smoothing)   # صفوف قليلة = ثقة قليلة
        encoding[cat] = w * cat_mean + (1 - w) * global_mean
    return [encoding[v] for v in feature_values], encoding

def count_vectorize(documents):
    vocab = {}
    for doc in documents:
        for word in doc.lower().split():
            if word not in vocab:
                vocab[word] = len(vocab)          # رقم لكل كلمة جديدة
    vectors = []
    for doc in documents:
        vec = [0] * len(vocab)
        for word in doc.lower().split():
            vec[vocab[word]] += 1
        vectors.append(vec)
    return vectors, vocab

def tfidf(documents):
    n_docs = len(documents)
    vocab = {}
    for doc in documents:
        for word in doc.lower().split():
            if word not in vocab:
                vocab[word] = len(vocab)
    doc_freq = {}                                 # الكلمة ظهرت في كام مستند
    for doc in documents:
        for word in set(doc.lower().split()):
            doc_freq[word] = doc_freq.get(word, 0) + 1
    vectors = []
    for doc in documents:
        words = doc.lower().split()
        tf_map = {}
        for w in words:
            tf_map[w] = tf_map.get(w, 0) + 1
        vec = [0.0] * len(vocab)
        for w, c in tf_map.items():
            tf = c / len(words)
            idf = math.log(n_docs / doc_freq[w])  # منتشرة = IDF قليل
            vec[vocab[w]] = tf * idf
        vectors.append(vec)
    return vectors, vocab

def impute_mean(values):
    present = [v for v in values if v is not None]
    if not present:
        return [0.0] * len(values), 0.0
    mean = sum(present) / len(present)
    return [v if v is not None else mean for v in values], mean

def impute_median(values):
    present = sorted(v for v in values if v is not None)
    if not present:
        return [0.0] * len(values), 0.0
    n = len(present)
    median = (present[n // 2 - 1] + present[n // 2]) / 2 if n % 2 == 0 else present[n // 2]
    return [v if v is not None else median for v in values], median

def impute_mode(values):
    present = [v for v in values if v is not None]
    if not present:
        return values, None
    counts = {}
    for v in present:
        counts[v] = counts.get(v, 0) + 1
    mode = max(counts, key=counts.get)            # أكتر قيمة متكررة
    return [v if v is not None else mode for v in values], mode

def add_missing_indicator(values):
    return [0 if v is not None else 1 for v in values]   # اعمله قبل التعبئة

خطوة ٥: الـ feature selection

def correlation(x, y):
    n = len(x)
    mx, my = sum(x) / n, sum(y) / n
    cov = sum((a - mx) * (b - my) for a, b in zip(x, y)) / n
    sx = math.sqrt(sum((a - mx) ** 2 for a in x) / n)
    sy = math.sqrt(sum((b - my) ** 2 for b in y) / n)
    return 0.0 if sx == 0 or sy == 0 else cov / (sx * sy)

def mutual_information(feature, target, n_bins=10):
    lo, hi = min(feature), max(feature)
    width = (hi - lo) / n_bins if hi != lo else 1.0
    fb = [min(int((v - lo) / width), n_bins - 1) for v in feature]   # قسّم لـ bins
    n = len(feature)
    p_feat = {b: fb.count(b) / n for b in set(fb)}
    p_target = {t: target.count(t) / n for t in set(target)}
    mi = 0.0
    for b in p_feat:
        for t in p_target:
            p_joint = sum(1 for a, c in zip(fb, target) if a == b and c == t) / n
            if p_joint > 0:
                mi += p_joint * math.log(p_joint / (p_feat[b] * p_target[t]))
    return mi

def variance_threshold(features, threshold=0.01):
    n, d = len(features), len(features[0])
    keep = []
    for j in range(d):
        col = [features[i][j] for i in range(n)]
        m = sum(col) / n
        if sum((v - m) ** 2 for v in col) / n >= threshold:
            keep.append(j)
    return keep

def remove_correlated(features, threshold=0.9):
    n, d = len(features), len(features[0])
    drop = set()
    for i in range(d):
        if i in drop:
            continue
        ci = [features[r][i] for r in range(n)]
        for j in range(i + 1, d):
            if j in drop:
                continue
            cj = [features[r][j] for r in range(n)]
            if abs(correlation(ci, cj)) >= threshold:   # مكررة: شيل التانية
                drop.add(j)
    return [i for i in range(d) if i not in drop]

def make_housing_data(n=200, seed=42):
    random.seed(seed)
    data = []
    for _ in range(n):
        sqft = random.uniform(500, 5000)
        bedrooms = random.choice([1, 2, 3, 4, 5])
        age = random.uniform(0, 50)
        neighborhood = random.choice(["downtown", "suburbs", "rural"])
        has_pool = random.choice([True, False])
        sqft_m = sqft if random.random() > 0.05 else None   # ~5% ناقص
        age_m = age if random.random() > 0.08 else None     # ~8% ناقص
        price = (50 * sqft + 20000 * bedrooms - 1000 * age
                 + (50000 if neighborhood == "downtown" else 10000 if neighborhood == "suburbs" else 0)
                 + (15000 if has_pool else 0) + random.gauss(0, 20000))
        data.append({"sqft": sqft_m, "bedrooms": bedrooms, "age": age_m,
                     "neighborhood": neighborhood, "has_pool": has_pool, "price": price})
    return data

التمارين

  1. Robust scaling: ضيف scaling بالـ median والـ IQR بدل الـ mean والـ std، وقارنه بالـ standard على داتا فيها outliers ضخمة.
    تلميح(x − median) / (Q3 − Q1). حط قيمة واحدة ×1000 في الداتا: الـ standardize هيكبس كل القيم العادية جنب بعض لأن الـ std انفجر، والـ robust هيسيبهم متوزعين لأن الـ median والـ IQR تقريبًا ما اتأثروش. (نفس اللي شفته في معمل ١ مع min-max.)
  2. Leave-one-out target encoding: لكل صف احسب متوسط الـ target للـ category من غير الـ target بتاع الصف ده. ورّي إنه بيقلل الـ overfitting عن الـ naive.
    تلميحenc_i = (sum_cat − y_i) / (count_cat − 1)، ولو count_cat = 1 استخدم المتوسط العام. على الـ test استخدم الـ encoding العادي المحسوب من الـ train. جرّبها في معمل ٣ بالـ checkbox: الـ correlation على الـ train بتنزل لمستوى قريب من الـ test.
  3. Pipeline selection أوتوماتيك: اجمع variance threshold + correlation filter + ترتيب بالـ MI. طبّقه على داتا البيوت وقارن linear regression بكل الـ features قصاد المختارة.
    تلميحاستخدم الـ SimpleLinearRegression أو الـ gradient descent من Lesson 2، وقيس على test منفصل (اعمل الـ split قبل أي fit للـ scaling). وخد بالك إن السعر في الداتا معتمد على bedrooms و has_pool كمان، والـ feature matrix في الكود ما فيهاش الاتنين دول. ضيفهم وشوف الفرق.
  4. إضافة مني · features لـ router بتاع LLM: عندك log فيه 200 prompt من يوزرز، وكل واحد معاه: النص، الوقت، نوع اليوزر (free / pro / team)، وهل الموديل الصغير جاوب صح ولا اتصعّد للموديل الكبير (label). ابني features: طول الـ prompt بالكلمات، log الطول، عدد علامات الاستفهام، هل فيه كود (``` أو def )، الساعة بـ cyclical encoding (sin/cos(2π·hour/24))، one-hot لنوع اليوزر، و TF-IDF لأهم 50 كلمة. رتّبهم بالـ MI مع الـ label. ده بالظبط إزاي بيتبني router رخيص يقرر يبعت الـ prompt لأنهي موديل.
    تلميحلو مش معاك log حقيقي، اعمل 200 prompt صناعي بقاعدة بسيطة (مثلًا الطويل اللي فيه كود بيتصعّد أكتر) وشوف هل الـ MI بيلاقي القاعدة. الساعة 23 و 0 قريبين من بعض، والـ sin/cos بيعرف ده، الرقم الخام لأ.

الحدس

كل feature انت بتضيفها هي «تلميح» للموديل عن شكل الحل. الـ BMI بيقول للموديل «النسبة دي هي المهمة». لما تكون عارف المجال، انت بتوفر على الموديل إنه يكتشف ده من الداتا، وده بيفرق جدًا لما الداتا قليلة.

غلطات شائعة

  • fit على الداتا كلها قبل الـ split: الـ scaler أو الـ imputer أو الـ target encoder أو الـ IDF. كلهم لازم يتعلموا من الـ train بس. (هتشوفها رسمي بكرة كـ data leakage.)
  • الـ correlation بيقيس العلاقة الخطية بس. لو y = x² و x متماثلة حوالين الصفر، الـ correlation تقريبًا صفر مع إن y متحددة بالكامل من x. الـ MI بيمسكها.
  • Label encoding لـ category من غير ترتيب مع موديل خطي أو KNN: الموديل هيصدق إن rural (1) «في النص» بين downtown و suburbs.
  • One-hot لعمود فيه آلاف القيم (zip code مثلًا): الأعمدة بتنفجر وأغلبها شبه فاضي.
  • تنسى الـ missing indicator وتعبّي بالمتوسط، فتضيّع معلومة إن «الخانة كانت فاضية».

بيظهر فين في الـ LLMs والـ Agents؟

الـ deep learning بيتعلم الـ features لوحده (الـ embeddings)، بس الفكرة ما اختفتش: BM25 اللي في الـ hybrid search جوه أنظمة RAG هو قريب جدًا من TF-IDF. الـ metadata اللي بتضيفها للـ chunks (التاريخ، المصدر، النوع) features بتستخدمها للفلترة والـ reranking. الـ LLM routers والـ guardrails الخفيفة بتشتغل على features زي اللي في تمرين ٤. والـ tokenization نفسها قرار representation. وحتى الـ prompt engineering في جزء منه feature engineering: انت بتختار تبيّن للموديل أنهي معلومة وبأي شكل.

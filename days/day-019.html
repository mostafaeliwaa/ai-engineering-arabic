العدد المركب: نقطة في مستوى

المشكلة اللي الدرس بيبدأ بيها: هتفتح أي paper عن الـ Fourier transform تلاقي i في كل حتة، وهتبص على الـ positional encodings في الـ Transformer تلاقي sin وcos بترددات مختلفة. من غير الأعداد المركبة مش هتفهم الـ DFT ولا الـ FFT ولا الـ RoPE.

العدد المركب ليه جزئين:

z = a + bi a = real part b = imaginary part i² = −1

بس كده. بدل ما الأرقام عايشة على خط، بقت عايشة في مستوى. المحور الأفقي للأرقام الحقيقية، والرأسي للتخيلية. يعني:

العددالنقطةمكانها
3 + 2i(3, 2)في النص
−1 + 0i(−1, 0)على المحور الحقيقي
0 + 4i(0, 4)على المحور التخيلي

العدد المركب في نفس الوقت نقطة ومتجه من الصفر لحد النقطة دي (فاكر يوم ١؟). المستوى ده اسمه complex plane أو Argand plane.

العمليات الأربعة

الجمع: اجمع الحقيقي مع الحقيقي والتخيلي مع التخيلي. زي جمع متجهين بالظبط.

(3 + 2i) + (1 + 4i) = 4 + 6i

الضرب: افتح الأقواس عادي وافتكر إن i² = −1:

(a+bi)(c+di) = (ac − bd) + (ad + bc)i
(3+2i)(1+4i) = 3 + 12i + 2i + 8i² = 3 + 14i − 8 = −5 + 14i

الـ Conjugate (المرافق): اقلب إشارة الجزء التخيلي. هندسيًا ده انعكاس في مراية على المحور الحقيقي. وأهم خاصية: العدد × مرافقه دايمًا رقم حقيقي:

conj(a + bi) = a − bi (a + bi)(a − bi) = a² + b²

القسمة: اضرب البسط والمقام في مرافق المقام. المقام يبقى رقم حقيقي ونخلص:

(a + bi) / (c + di) = (a + bi)(c − di) / (c² + d²)
تشبيه: القسمة على عدد مركب زي إنك عايز تشيل «اللفة» من المقام. المرافق بيعمل لفة عكسية، فالمقام يتعدل على المحور الحقيقي ويبقى رقم عادي تقسم عليه.

الـ Polar form: الضرب = لف + تكبير

أي نقطة تقدر توصفها بطريقتين: «امشي a يمين وb فوق» (rectangular)، أو «بُص بزاوية θ وامشي مسافة r» (polar).

r = |z| = √(a² + b²) θ = atan2(b, a)
z = r (cos θ + i sin θ) = r·e^(iθ)

الـ r اسمها magnitude أو modulus، والـ θ اسمها phase أو argument. القاعدة الذهبية: الـ rectangular سهلة في الجمع، والـ polar سهلة في الضرب:

z₁·z₂ = (r₁·r₂) · e^(i(θ₁ + θ₂))

يعني: اضرب الأطوال واجمع الزوايا. ولو |w| = 1، الضرب فيه بيبقى لفّ صافي من غير ما يكبّر أو يصغّر.

جرب بإيدك: اسحب z (الأزرق) وw (البرتقالي). الناتج z·w باللون الغامق. بص على الـ readout: الطول = حاصل ضرب الطولين، والزاوية = مجموع الزاويتين. بعدين دوس «w = i» واضغط «اضرب تاني» كذا مرة: النقطة بتلف ٩٠° كل مرة.

03

Euler: الجسر بين الأُس والـ sin والـ cos

أهم معادلة في الدرس:

e^(iθ) = cos θ + i sin θ

ومعناها: لما θ تتغير، النقطة e^(iθ) بتمشي على دايرة الوحدة (unit circle، نص قطرها ١). عند θ = 0 انت عند (1, 0)، وعند π/2 عند (0, 1)، وعند π عند (−1, 0)، وعند 3π/2 عند (0, −1)، ولفة كاملة = 2π.

ولو حطيت θ = π:

e^(iπ) = cos π + i sin π = −1 ⟹ e^(iπ) + 1 = 0

خمس ثوابت أساسية (e و i و π و 1 و 0) في معادلة واحدة. بس الأهم بالنسبالنا: الـ complex exponentials هي حرفيًا لفّات.

الضرب المركب = مصفوفة اللف

اضرب (x + yi) في e^(iθ) وافتح الأقواس:

(x + yi)(cos θ + i sin θ) = (x cos θ − y sin θ) + (x sin θ + y cos θ)i

وقارن بمصفوفة اللف اللي شفتها في يوم ٣:

[[cos θ, −sin θ], [sin θ, cos θ]] · [x, y] = [x cos θ − y sin θ, x sin θ + y cos θ]

نفس النتيجة بالظبط. مصفوفة اللف 2×2 ما هي إلا ضرب مركب مكتوب بشكل مصفوفات.

ليه i² = −1 مش لغز

كلمة «تخيلي» غلطة تاريخية: ديكارت استخدمها بتريقة. والأرقام السالبة نفسها الناس رفضتها في الأول. السالب بيجاوب «أطرح ٥ من ٣ يطلع كام؟»، والـ i بتجاوب «إيه اللي تربيعه −1؟».

الأحسن تفكر فيها كده: i = أمر «لف ٩٠°». اضرب رقم حقيقي في i مرة يلف ٩٠° ويروح على المحور التخيلي. اضربه تاني (i²) يلف ٩٠° كمان، يبقى بص في الاتجاه السالب. نص لفة = −1. خلاص.

عشان كده أي حاجة بتلف (موجات كهرومغناطيسية، quantum states، إشارات بتتذبذب، positional encodings) الأعداد المركبة بتوصفها بشكل طبيعي.

الـ Phasor: الموجة هي ضل نقطة بتلف

e^(iωt) نقطة بتلف على دايرة الوحدة بسرعة زاوية ω. مع الوقت:

e^(iωt) = cos(ωt) + i sin(ωt)

الجزء الحقيقي = موجة cos، والتخيلي = موجة sin. يعني موجة الـ sin هي ضل نقطة بتلف.

ده اسمه phasor. بدل ما تتابع موجة متعرّجة، بتتابع سهم بيلف بهدوء:

  • الـ phase shift بقى زاوية بداية مختلفة.
  • تغيير الـ amplitude بقى طول السهم.
  • جمع موجتين بقى جمع متجهين.
جرب: شغّل الأنيميشن وغيّر الـ phase φ: الموجة كلها بتزق يمين وشمال. غيّر A: السهم يطول والموجة تعلى.

زمان كانوا بيكتبوا الإشارة A cos(ωt + φ). شغالة، بس جمع اتنين cos بـ phases مختلفة محتاج متطابقات مثلثية مزعجة. بالـ complex exponentials نفس الإشارة A e^(i(ωt + φ)):

  • جمع إشارتين = جمع عددين مركبين.
  • الضرب (modulation) = اضرب الأطوال واجمع الزوايا.
  • الـ phase shift = جمع زاوية، والـ frequency shift = ضرب في phasor.

«الإشارة الحقيقية» هي دايمًا الجزء الحقيقي بس، والتخيلي بيتشال معاها كـ «دفتر حسابات» عشان الجبر يمشي نضيف. عشان كده مجال الـ signal processing كله اتحول للكتابة دي.

جذور الواحد والـ DFT

الـ N-th roots of unity هي N نقطة متوزعة بالتساوي على دايرة الوحدة:

w_k = e^(2πi·k/N) k = 0, 1, …, N−1

لـ N = 4: 1, i, −1, −i (الاتجاهات الأربعة). لـ N = 8: الأربعة دول + الأربع أقطار. خاصيتين مهمين: كل جذر طوله ١ بالظبط، ومجموعهم كلهم = صفر (بيلغوا بعض بالتماثل). والخاصيتين دول هما اللي بيخلوا الـ DFT ينفع يتعكس: الجذور بتعمل orthogonal basis لعالم الترددات.

الـ DFT: سيجنال = مجموع phasors

الـ Discrete Fourier Transform لسيجنال x[0..N−1]:

X[k] = Σₙ x[n] · e^(−2πi·k·n/N)

كل X[k] بيقيس «السيجنال شبه الـ phasor اللي تردده k قد إيه» (correlation). الـ DFT بيفكك السيجنال لـ N سهم بيلفوا، ويقولك الطول (amplitude) والزاوية (phase) لكل واحد. والتكلفة هنا O(N²) لأن كل X[k] جمع على N عينة. الـ FFT اللي هتشوفه بكرة بيعمل نفس الحساب أسرع بكتير.

والعكس (inverse DFT): نفس المعادلة بس اقلب إشارة الأُس واقسم على N. بترجّعلك السيجنال الأصلي بالظبط (لحد دقة الكمبيوتر). مفيش معلومة بتضيع.

معمل ب: فكّك سيجنال لتردداته

السيجنال: A₁ sin(2π f₁ t) + A₂ sin(2π f₂ t)، متاخد على N = 32 نقطة (t = n/32). فوق السيجنال، وتحت طول X[k] لـ k من 0 لـ 16 (النص التاني صورة مراية).

لاحظ القاعدة: sine بسعة A بيعمل قمة طولها A·N/2. يعني بالقيم الافتراضية (A₁ = 1، A₂ = 0.5): قمة 16 عند k = 3 وقمة 8 عند k = 7. ده بالظبط تمرين ٣.

الربط بالـ Transformers

الـ Sinusoidal positional encodings

من paper الـ Transformer الأصلي:

PE(pos, 2i) = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

كل زوج (sin, cos) هو الجزء التخيلي والحقيقي لـ complex exponential بتردد معين. كل تردد بيدي «دقة» مختلفة للمكان: الترددات الواطية بتتغير ببطء (مكان تقريبي)، والعالية بتتغير بسرعة (مكان دقيق). مع بعض بيدوا كل position «بصمة ترددات» فريدة.

تشبيه: زي عقارب الساعة. عقرب الثواني بيلف بسرعة (تفاصيل)، والدقايق أبطأ، والساعات أبطأ وأبطأ. من مكان التلات عقارب مع بعض تعرف الوقت بالظبط. كل زوج sin/cos عقرب بيلف بسرعته.

إضافة مني: ليه الـ RoPE بيشوف «المسافة» بس

خد زوج أرقام من الـ query واعتبره عدد مركب q، وزوج من الـ key واعتبره k. الـ RoPE بيلف q بزاوية m·θ (m = مكان الـ query) ويلف k بزاوية n·θ. الـ dot product بين المتجهين الملفوفين:

Re( q e^(imθ) · conj(k e^(inθ)) ) = Re( q · conj(k) · e^(i(m−n)θ) )

الـ m والـ n اختفوا وفضل m − n بس. يعني الـ score بيعتمد على بُعد التوكنين عن بعض، مش مكانهم المطلق. جرّب الزرار «زق الاتنين +5»: السهمين بيلفوا، بس الـ score ثابت.

أخطاء شائعة:

  • تنسى إن atan2(b, a) مش atan(b/a): الأخيرة بتغلط في الربع التاني والتالت وبتقع لو a = 0.
  • في Python الوحدة التخيلية j مش i، وabs(z) هي الطول.
  • بتبص على النص التاني من الـ DFT لسيجنال حقيقي وتفتكر فيه ترددات زيادة: ده مراية للنص الأول.
  • بتقارن عددين مركبين بـ == بعد حسابات float. استخدم tolerance زي ما الكود بيعمل (1e-10).

خطوة ١: كلاس Complex

import math

class Complex:
    def __init__(self, real, imag=0.0):
        self.real = real
        self.imag = imag

    def __add__(self, other):          # حقيقي + حقيقي، تخيلي + تخيلي
        return Complex(self.real + other.real, self.imag + other.imag)

    def __mul__(self, other):          # (ac - bd) + (ad + bc)i
        r = self.real * other.real - self.imag * other.imag
        i = self.real * other.imag + self.imag * other.real
        return Complex(r, i)

    def __truediv__(self, other):      # اضرب في مرافق المقام
        denom = other.real ** 2 + other.imag ** 2
        r = (self.real * other.real + self.imag * other.imag) / denom
        i = (self.imag * other.real - self.real * other.imag) / denom
        return Complex(r, i)

    def magnitude(self):               # المسافة من الصفر
        return math.sqrt(self.real ** 2 + self.imag ** 2)

    def phase(self):                   # الزاوية، atan2 مش atan
        return math.atan2(self.imag, self.real)

    def conjugate(self):               # مراية على المحور الحقيقي
        return Complex(self.real, -self.imag)

الكلاس الأصلي في الريبو فيه كمان __sub__ و__neg__ و__repr__ و__eq__ (بـ tolerance 1e-10)، وبيقبل أرقام عادية في العمليات. ضيفهم لما تخلص.

خطوة ٢: Polar وEuler

def to_polar(z):
    return z.magnitude(), z.phase()            # (r, θ)

def from_polar(r, theta):
    return Complex(r * math.cos(theta), r * math.sin(theta))

def euler(theta):                              # e^(iθ) = cos θ + i sin θ
    return Complex(math.cos(theta), math.sin(theta))

اتأكد: euler(theta).magnitude() دايمًا 1، وeuler(0) = (1, 0)، وeuler(math.pi) = (−1, 0).

خطوة ٤: الـ DFT من الضرب المركب

def dft(signal):
    N = len(signal)
    result = []
    for k in range(N):                         # لكل تردد k
        total = Complex(0, 0)
        for n in range(N):                     # اجمع على كل العينات
            angle = -2 * math.pi * k * n / N
            total = total + Complex(signal[n], 0) * euler(angle)
        result.append(total)
    return result                              # O(N²)

خطوة ٥: الـ Inverse DFT

def idft(spectrum):
    N = len(spectrum)
    result = []
    for n in range(N):
        total = Complex(0, 0)
        for k in range(N):
            angle = 2 * math.pi * k * n / N    # الإشارة اتقلبت
            total = total + spectrum[k] * euler(angle)
        result.append(Complex(total.real / N, total.imag / N))   # واقسم على N
    return result

خطوة ٦: جذور الواحد

def roots_of_unity(N):
    return [euler(2 * math.pi * k / N) for k in range(N)]

roots = roots_of_unity(8)
print([round(r.magnitude(), 6) for r in roots])  # كلهم 1
s = Complex(0, 0)
for r in roots:
    s = s + r
print(s.magnitude())                             # قريب جدًا من الصفر

    تلميح 
    def rope(vec, pos, d=4):
    out = []
    for i in range(d // 2):
        theta = 1 / (10000 ** (2 * i / d))
        z = Complex(vec[2*i], vec[2*i+1]) * euler(pos * theta)
        out += [z.real, z.imag]
    return out

def dot(a, b):

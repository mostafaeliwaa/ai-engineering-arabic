الـ Maximum Margin: أعرض شارع

تخيل حيين بينهم شارع. عايز ترسم الشارع بحيث يبقى أعرض ما يمكن من غير ما يدخل في أي بيت. خط النص هو الـ decision boundary، والرصيفين هما الـ margin. شارع عريض = الموديل واثق، وأي نقطة جديدة فيها noise بسيط مش هتقلب الناحية. عشان كده بيعمم أحسن.

الـ labels هنا y ∈ {−1, +1} (مش 0 و1 زي logistic)، والخط هو wᵀx + b = 0. بُعد أي نقطة عن الخط:

distance = |wᵀxᵢ + b| / ‖w‖

النقطة متصنفة صح لو yᵢ(wᵀxᵢ + b) > 0. بنثبّت الرصيفين عند wᵀx + b = +1 و −1، فعرض الشارع كله = 2/‖w‖. المسألة:

maximize 2/‖w‖ subject to yᵢ(wᵀxᵢ + b) ≥ 1 for all i ⟺ minimize ½‖w‖² subject to yᵢ(wᵀxᵢ + b) ≥ 1

تكبير 2/‖w‖ = تصغير ‖w‖²، والتانية أسهل في الحل. دي convex quadratic program، يعني ليها حل global واحد بس، مفيش local minima تتوه فيها.

Support Vectors: القلة اللي بتحكم

النقط اللي واقفة على الرصيف بالظبط (yᵢ(wᵀxᵢ + b) = 1) اسمها support vectors. هما بس اللي بيحددوا الخط. حرّك أو امسح أي نقطة تانية بعيدة: الخط مش هيتحرك خالص. جرب ده في المعمل ٢.

  • وقت الـ prediction محتاج تخزن الـ support vectors بس، مش الداتا كلها، فالموديل خفيف في الميموري.
  • عدد الـ support vectors بيدي حد (bound) للـ generalization error: كل ما يقلوا بالنسبة لحجم الداتا، التعميم يبقى أحسن.

Soft Margin و C و Hinge Loss

الداتا الحقيقية نادرًا تنفصل بخط نضيف. فيه نقط جوه الشارع أو في الناحية الغلط. الحل: نسمح بمخالفات ونحاسب عليها بـ slack variables ξᵢ (قد إيه النقطة i مخالفة):

minimize ½‖w‖² + C·Σ ξᵢ s.t. yᵢ(wᵀxᵢ + b) ≥ 1 − ξᵢ , ξᵢ ≥ 0
Cالسلوك
C كبيرغرامة المخالفة غالية → شارع ضيق وغلطات أقل على الـ train → ممكن overfit
C صغيربنسامح أكتر → شارع عريض وغلطات أكتر → ممكن underfit

الـ C هي عكس قوة الـ regularization: C كبير = regularization أقل.

Hinge loss

نقدر نكتب نفس المسألة من غير قيود:

minimize ½‖w‖² + C·Σ max(0, 1 − yᵢ·f(xᵢ))

الجزء max(0, 1 − y·f(x)) هو الـ hinge loss (شكله زي مفصّلة الباب): صفر لو النقطة صح وبره الشارع (y·f(x) ≥ 1)، وخطي لو جوه الشارع أو غلط. قارنه بالـ logistic loss بتاع امبارح log(1 + e^(−y·f(x))): ناعم وعمره ما بيوصل صفر بالظبط.

معمل ١: hinge قصاد logistic

اسحب النقطة على المحور الأفقي (y·f(x)). شوف إمتى الـ hinge يبقى صفر بالظبط والـ logistic لسه بيحسب.

النتيجة المهمة: الـ hinge بيدي حلول sparse: النقط اللي بره الشارع مساهمتها صفر، فالـ support vectors بس هي اللي بتفرق. الـ logistic بيستخدم كل النقط.

تدريب Linear SVM بالـ Gradient Descent (Primal)

مش لازم QP solver. خد الـ hinge + L2 واعمل gradient descent:

L(w,b) = (λ/2)‖w‖² + (1/n)·Σ max(0, 1 − yᵢ(wᵀxᵢ + b)) لو yᵢ(wᵀxᵢ+b) ≥ 1: ∂L/∂w = λw ∂L/∂b = 0 لو yᵢ(wᵀxᵢ+b) < 1: ∂L/∂w = λw − yᵢxᵢ ∂L/∂b = −yᵢ

يعني: لو النقطة مرتاحة بره الشارع، بس صغّر w شوية (regularization). لو جوه الشارع أو غلط، زقّ الخط ناحيتها. ده اسمه primal formulation، وتكلفته O(n·d) لكل epoch، سريع جدًا للداتا الكبيرة الـ sparse عالية الأبعاد زي تصنيف النصوص. الـ λ هنا بتلعب دور 1/C (الكود بيستخدم λ = 1/(C·n)).

اضغط في مكان فاضي عشان تضيف نقطة من الـ class المختار. اسحب أي نقطة تحركها. فعّل «مسح» وادوس على نقطة تشيلها.

  • الخط الغامق = الـ boundary، والمتقطعين = الرصيفين (±1).

الـ Dual والـ Kernel Trick

من Convex Optimization (شروط KKT) نقدر نكتب نفس المسألة في صورة تانية اسمها dual، فيها متغير αᵢ لكل نقطة:

maximize Σαᵢ − ½·Σᵢⱼ αᵢαⱼ yᵢyⱼ (xᵢ · xⱼ) s.t. 0 ≤ αᵢ ≤ C , Σ αᵢyᵢ = 0

بص كويس: الداتا بتظهر بس جوه dot products xᵢ · xⱼ. دي الفكرة كلها. بدّل كل dot product بدالة K(xᵢ, xⱼ) اسمها kernel، والـ SVM هتتعلم حدود مش خطية من غير ما تحسب التحويل لفضاء أعلى أبدًا.

Linear: K(x,z) = x · z Polynomial: K(x,z) = (x · z + c)^d RBF: K(x,z) = exp(−γ‖x − z‖²)

الـ kernel = φ(x)·φ(z): الـ dot product بعد ما تودّي النقطتين لفضاء أكبر. الـ trick إنك بتحسب الرقم ده مباشرة بتكلفة رخيصة. مثلًا الـ polynomial من درجة d في D بُعد، الفضاء الصريح فيه حوالي O(D^d) بُعد، بس K(x,z) بيتحسب في O(D).

الـ RBF بيودّيك لفضاء لا نهائي الأبعاد. معناه بالبلدي: «قد إيه النقطتين قريبين؟» قريبين جدًا = قريب من 1، بعاد = قريب من 0. ويقدر يتعلم أي حدود ناعمة.

معمل ٣: ارفع الداتا لبُعد تالت

الأزرق جوه دايرة والبرتقاني حواليه. مستحيل خط مستقيم يفصلهم في 2D. ضيف feature تالتة z = x₁² + x₂² (المسافة من المركز تربيع). في الرسمة التانية (x₁ قصاد z) الأزرق تحت والبرتقاني فوق، فخط أفقي بيفصلهم.

حرّك الـ threshold. الخط المستقيم في الفضاء الجديد = دايرة في الفضاء الأصلي. ده بالظبط اللي الـ kernel بيعمله ضمنيًا. في الريبو: Linear SVM على الداتا الدايرية بتفشل، وعلى (x₁, x₂, x₁², x₂², x₁x₂) بتنجح.

SVR، وإمتى الـ SVM لسه بتكسب

Support Vector Regression

بدل الشارع، بنرسم أنبوبة عرضها ε حوالين الداتا. النقط جوه الأنبوبة خسارتها صفر، واللي بره بتتحاسب خطيًا:

minimize ½‖w‖² + C·Σ(ξᵢ + ξᵢ*) s.t. yᵢ − (wᵀxᵢ + b) ≤ ε + ξᵢ , (wᵀxᵢ + b) − yᵢ ≤ ε + ξᵢ* , ξ ≥ 0

ε أكبر = أنبوبة أوسع = support vectors أقل وتوقع أنعم. ε أصغر = support vectors أكتر و fit أضيق.

خطوة ١: أدوات + hinge loss

import math, random

def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def vec_norm(a):
    return math.sqrt(dot(a, a))

def hinge_loss(X, y, w, b):
    total = 0.0
    for xi, yi in zip(X, y):
        margin = yi * (dot(w, xi) + b)     # y·f(x)
        total += max(0.0, 1.0 - margin)    # صفر لو بره الشارع
    return total / len(X)

def svm_objective(X, y, w, b, lambda_param):
    return 0.5 * lambda_param * dot(w, w) + hinge_loss(X, y, w, b)

خطوة ٢: LinearSVM بالـ SGD على الـ primal

class LinearSVM:
    def __init__(self, lr=0.001, lambda_param=0.01, n_epochs=1000):
        self.lr, self.lambda_param, self.n_epochs = lr, lambda_param, n_epochs
        self.w, self.b = None, 0.0

    def fit(self, X, y):                    # y لازم تبقى ‎-1 / +1
        self.w = [0.0] * len(X[0])
        self.b = 0.0
        for epoch in range(self.n_epochs):
            idx = list(range(len(X)))
            random.shuffle(idx)
            for i in idx:
                margin = y[i] * (dot(self.w, X[i]) + self.b)
                if margin >= 1:             # مرتاحة: regularization بس
                    self.w = [wj - self.lr * self.lambda_param * wj for wj in self.w]
                else:                       # جوه الشارع/غلط: زق الخط
                    self.w = [wj - self.lr * (self.lambda_param * wj - y[i] * X[i][j])
                              for j, wj in enumerate(self.w)]
                    self.b -= self.lr * (-y[i])

    def predict(self, X):
        return [1 if dot(self.w, x) + self.b >= 0 else -1 for x in X]

    def decision_function(self, X):
        return [dot(self.w, x) + self.b for x in X]

    def margin_width(self):                 # 2 / ‖w‖
        n = vec_norm(self.w)
        return 0.0 if n == 0 else 2.0 / n

    def find_support_vectors(self, X, y, tol=0.1):
        return [i for i in range(len(X))
                if abs(y[i] * (dot(self.w, X[i]) + self.b) - 1.0) < tol]

لاحظ إن الـ find_support_vectors هنا تقريبية: بتدور على النقط اللي y·f(x) بتاعها قريب من 1 في حدود tol، لأن الـ SGD مش بيوصل للحل بالظبط.

خطوة ٣: الـ kernels

def linear_kernel(x, z):
    return dot(x, z)

def polynomial_kernel(x, z, degree=3, c=1.0):
    return (dot(x, z) + c) ** degree

def rbf_kernel(x, z, gamma=0.5):
    diff = [xi - zi for xi, zi in zip(x, z)]
    return math.exp(-gamma * dot(diff, diff))     # قريب = 1، بعيد = 0

for z in ([2.0, 0.0], [1.1, 0.1], [5.0, 0.0]):
    print(z, linear_kernel([1.0, 0.0], z), round(rbf_kernel([1.0, 0.0], z), 4))

random.seed(0)
X, y = [], []
for _ in range(100):
    X.append([random.gauss(2, 1), random.gauss(2, 1)]);   y.append(1)

for C in [0.01, 1.0, 100.0]:

التمارين

  1. Support vectors: ولّد داتا 2D تنفصل بخط، درّب LinearSVM، وطلّع الـ support vectors. اتأكد إنها أقرب نقط للخط.
    تلميحاحسب |w·x + b| / ‖w‖ لكل نقطة ورتّب. أقل كام واحدة لازم يطابقوا اللي find_support_vectors رجّعها (مع tol حوالي 0.3).
  2. الـ C من 0.001 لـ 1000: على داتا فيها noise، ارسم الحدود لكل C.
    المتوقعنفس اللي في المعمل ٢: C صغير = شارع عريض والخط مش مهتم بالنقط الخاينة (underfit لو زاد). C كبير = شارع ضيق بيحاول يرضي كل نقطة (overfit).
  3. داتا دايرية: وريني إن الـ linear SVM بتفشل، واحسب مصفوفة الـ RBF kernel ووضح إن الـ classes بتبقى قابلة للفصل.
    تلميحمصفوفة K[i][j] = rbf(xᵢ, xⱼ). رتّب النقط حسب الـ class واطبع متوسط K جوه نفس الـ class قصاد بين الـ classes. جوه الـ class هيبقى أعلى بوضوح. أو اعمل زي الريبو: ضيف x₁², x₂², x₁x₂ ودرّب linear.
  4. Hinge قصاد Logistic: درّب SVM و logistic regression على نفس الداتا. عدّ كام نقطة بتساهم في الحدود في كل واحد.
    الإجابةالـ SVM: الـ support vectors بس (النقط اللي y·f(x) < 1 أو عليها). الـ logistic: كل النقط ليها gradient مش صفر، لأن الـ loss عمرها ما بتبقى صفر.
  5. SVR: اعمل ε-insensitive loss، وfit على y = sin(x) + noise، وارسم الأنبوبة ولوّن النقط اللي برّاها.
    تلميحloss لكل نقطة = max(0, |y − f(x)| − ε). الـ gradient صفر جوه الأنبوبة و ±x برّاها. علشان sin محتاج features زي x, x², x³ أو RBF.
  6. إضافة مني · مصنف intents لـ chatbot: اكتب 40 رسالة قصيرة لـ 2 intents (مثلًا «refund» و«tracking»)، حوّلهم لمتجهات bag-of-words بنفسك، ودرّب LinearSVM بتاعتك. ده بالظبط نوع المشاكل اللي الـ SVM لسه بتلمع فيها: داتا صغيرة، أبعاد كتير، sparse. قارن بعدين بـ LinearSVC على TfidfVectorizer.
    تلميحvocab = كل الكلمات اللي ظهرت. المتجه = عدّ. الـ labels +1 / −1. بعد التدريب، أكبر 5 أوزان موجبة وسالبة في w هيقولولك أنهي كلمات بتشد لكل intent.
08

إضافة مني: الحدس والغلطات وفين في الـ LLMs

الحدس

فكّر في الـ SVM كإنها بتسأل: «مين النقط الصعبة؟» وتبني القرار عليهم بس. النقط السهلة البعيدة ملهاش صوت. ده عكس الـ logistic اللي بيسمع للكل بنسب مختلفة.

غلطات شائعة

  • تنسى الـ scaling. أول حاجة تعملها مع SVM أو KNN.
  • تستخدم labels 0/1 مع كود معمول لـ −1/+1: الـ y·f(x) هيبقى صفر لكل الـ class صفر والتدريب يبوظ.
  • تلخبط اتجاه الـ C: C كبير = regularization أقل (عكس λ و alpha).
  • تجرب SVC(kernel="rbf") على مليون صف. الـ kernel SVM من O(n²) لـ O(n³). استخدم LinearSVC أو موديل تاني.
  • تظبط C و γ لوحدهم. هما مربوطين؛ اعمل grid search عليهم مع بعض.

بيظهر فين؟

فكرة الـ kernel («قيس التشابه بدالة وابني عليه») هي نفس روح الـ attention: softmax(q·k) هو dot product مستخدم كـ similarity، وفيه أبحاث بتفسر الـ attention كـ kernel smoother. والـ margin فكرته موجودة في الـ contrastive و triplet losses اللي بتدرّب موديلات الـ embeddings المستخدمة في الـ RAG: عايز المتشابهين قريبين والمختلفين بعيد بمسافة margin على الأقل.

تسخين ٥ دقايق: فاكر امبارح؟

امبارح بنيت إطار لتقييم الرفض (Refusal Evaluation). جاوب في دماغك الأول، وبعدين افتح الإجابة.

  1. إيه الفرق بين under-refusal وover-refusal؟ وليه لازم تقيس الاتنين؟
    الإجابةunder-refusal: الموديل جاوب على prompt متعلّم إنه unsafe. over-refusal: الموديل رفض prompt متعلّم إنه safe. لو قست واحد بس هتشحن موديل يا إما بيرفض واجب الكيميا يا إما بيشرح الأذى. الاتنين bugs.
  2. ليه استخدمنا mock LLM ثابت (deterministic) بدل موديل حقيقي؟
    الإجابةعشان الموديل الحقيقي «هدف متحرك»: أي تغيير في الـ system prompt أو الـ temperature بيحرك المقاييس. مع mock ثابت، أي تغيير في الأرقام سببه معروف: تغيير في الكود. وبعدين ممكن تبدّل الـ mock بنداء HTTP لموديل حقيقي من غير ما تغيّر إطار القياس.
  3. موديل بيقول confidence:0.9 بس صح في ٦٠٪ من الحالات بس. الـ ECE في الـ bin ده تقريبًا كام؟
    الإجابةحوالي |0.9 − 0.6| = 0.3. الـ ECE بيقيس هل الموديل «عارف إمتى هو صح»، ومستقل عن over/under refusal.

المشكلة: الـ input مش هو الباب الوحيد

تخيل مطعم بيفحص المكونات اللي داخلة المطبخ كويس جدًا. ده مهم، بس لو مفيش حد بيدوق الطبق قبل ما يطلع للزبون، أي غلطة جوه المطبخ هتوصل للترابيزة. نفس الكلام هنا: الموديل ممكن يعدّي كل فحوصات الـ input، ويطلّع رد:

  • • فيه PII (بيانات شخصية): إيميل، رقم تليفون، رقم كارت.
  • • بيكرر شتايم أو تحرش اتعلمها من الداتا اللي اتدرب عليها.
  • • بيرجّع الـ system prompt نفسه لليوزر لأنه سأل سؤال ذكي.

الـ output classifier بيشوف الرد الحقيقي، مش السؤال، وبيسأل سؤال مختلف: بغض النظر الـ prompt وصل هنا إزاي، هل اللي إحنا على وشك نبعته لليوزر مقبول؟

حجتين بيقولهم الناس عشان يسيبوا الخطوة دي، والاتنين غلط:
١) «الـ input classification كفاية»: لأ، أي نوع هجوم جديد الـ input pipeline مش مغطيه هيوصل لليوزر مباشرة. ده bypass من أول محاولة.
٢) «هيزود الـ latency»: صحيح، بس ليها حل: الـ classifiers تشتغل بالتوازي مع الـ streaming، والبوابة (gate) تمسك آخر chunk في buffer وتطبّق حكم الـ classifier قبل ما تعمله flush.

الـ Verdict والـ Router: كل واحد يقول رأيه، والأخطر يكسب

كل classifier هو callable بيرجّع ClassifierVerdict فيه ٤ حاجات:

ClassifierVerdict(name, score ∈ [0,1], severity ∈ {none, low, medium, high}, findings: list[str])

والـ router بياخد قايمة الـ verdicts، يطلّع أعلى severity، ويطبّق جدول ثابت:

SeverityActionيعني إيه
highblockارمي الرد كله ورجّع رسالة رفض (policy refusal)
mediumredactشغّل الـ redactor بتاع كل classifier اشتغل وامسح الأجزاء الخطر
lowwarnسجّل وزوّد ملاحظة خفيفة في آخر الرد
nonelogسجّل الحكم في الـ trace وابعت الرد زي ما هو

الـ block بيكسب دايمًا. redact + warn = redact. log + warn = warn. تشبيه: لجنة من ٣ دكاترة؛ لو واحد بس قال «الحالة خطيرة» المريض بيدخل الطوارئ، مش بناخد المتوسط.

الـ router بيرجّع Action فيه verb وoutput وseverity وverdicts وmetadata (عدد الـ verdicts وأسماء اللي اشتغلوا). البوابة في درس ٨٧ هتسجّل الـ metadata دي في trace.

كل classifier ليه redactor خاص بيه، ومستقلين عن بعض: لو الرد فيه شتيمة و PII الاتنين، النص بيعدّي على الـ redactor الأولاني وبعدين التاني.

معمل ١: الـ Router شغّال قدامك

ده نفس الكود بتاع الدرس متحوّل لـ JavaScript (نفس الـ regex ونفس الأرقام). اختار رد جاهز أو اكتب ردك، وشوف كل classifier بيقول إيه، والـ router بياخد أنهي طريق.

from dataclasses import dataclass, field

SEVERITY_ORDER = ("none", "low", "medium", "high")   # الترتيب هو اللي بيخلي max يشتغل

@dataclass
class ClassifierVerdict:
    name: str
    severity: str = "none"
    score: float = 0.0
    findings: list[str] = field(default_factory=list)   # وصف كل حاجة اتمسكت


  
خطوة ٢ (M2): Toxicity مع نافذة النفي

  
import re

HARASSMENT_TERMS = ["moron", "idiot", "stupid", "worthless", "trash human",
                    "kill yourself", "lowlife", "scumbag", "useless person", "good for nothing"]
_NEGATION_WINDOW = 20

class ToxicityClassifier:
    name = "toxicity"

    def __init__(self, terms=None):
        self._terms = [t.lower() for t in (terms if terms is not None else HARASSMENT_TERMS)]
        joined = "|".join(re.escape(t) for t in self._terms)
        self._needle = re.compile(rf"\b({joined})\b", re.IGNORECASE)   # حدود كلمة

    def _negated_at(self, text, start):
        window = text[max(0, start - _NEGATION_WINDOW):start].lower()   # آخر ٢٠ حرف قبل الكلمة
        return bool(re.search(r"\b(not|never|no)\b", window))

    def classify(self, text):
        findings, hits = [], 0
        for m in self._needle.finditer(text):
            if self._negated_at(text, m.start()):
                continue                                   # "not stupid" مش شتيمة
            findings.append(f"matched '{m.group(0)}'")
            hits += 1
        if not findings:
            return ClassifierVerdict(name=self.name)
        score = min(1.0, 0.4 + 0.2 * hits)
        sev = "high" if hits >= 3 else "medium" if hits == 2 else "low"
        return ClassifierVerdict(self.name, sev, score, findings)

    def redact(self, text):
        def _sub(m):
            return m.group(0) if self._negated_at(text, m.start()) else "[redacted-language]"
        return self._needle.sub(_sub, text)


  
خطوة ٣ (M3): PII و Luhn

  
_EMAIL_RE = re.compile(r"\b[\w.+-]+@[\w-]+\.[\w.-]+\b")
_PHONE_RE = re.compile(r"\b(?:\+?\d{1,3}[ .-]?)?(?:\(?\d{3}\)?[ .-]?)\d{3}[ .-]?\d{4}\b")
_SSN_RE   = re.compile(r"\b\d{3}-\d{2}-\d{4}\b")
_CARD_RE  = re.compile(r"\b(?:\d[ -]?){12,18}\d\b")          # 13 لـ 19 رقم بمسافات أو شرط
_IPV4_RE  = re.compile(r"\b(?:\d{1,3}\.){3}\d{1,3}\b")

def _luhn(digits):
    s, parity = 0, len(digits) % 2
    for i, ch in enumerate(digits):
        d = int(ch)
        if i % 2 == parity:          # الخانات اللي بتتضاعف
            d *= 2
            if d > 9:
                d -= 9
        s += d
    return s % 10 == 0

class PIIClassifier:
    name = "pii"

    def classify(self, text):
        findings = []
        findings += [f"email '{m.group(0)}'" for m in _EMAIL_RE.finditer(text)]
        findings += [f"phone '{m.group(0)}'" for m in _PHONE_RE.finditer(text)]
        findings += [f"ssn '{m.group(0)}'" for m in _SSN_RE.finditer(text)]
        for m in _CARD_RE.finditer(text):
            digits = re.sub(r"\D", "", m.group(0))
            if 13 <= len(digits) <= 19 and _luhn(digits):   # شكل كارت + check digit صح
                findings.append(f"card '{m.group(0)}'")
        findings += [f"ip '{m.group(0)}'" for m in _IPV4_RE.finditer(text)]
        if not findings:
            return ClassifierVerdict(name=self.name)
        score = min(1.0, 0.5 + 0.15 * len(findings))
        if any(f.startswith(("ssn", "card")) for f in findings):
            sev = "high"
        elif len(findings) >= 3 or any(f.startswith("email") for f in findings):
            sev = "medium"
        else:
            sev = "low"
        return ClassifierVerdict(self.name, sev, score, findings)

    def redact(self, text):
        out = _EMAIL_RE.sub("[redacted-email]", text)
        out = _PHONE_RE.sub("[redacted-phone]", out)
        out = _SSN_RE.sub("[redacted-ssn]", out)
        def _card_sub(m):
            d = re.sub(r"\D", "", m.group(0))
            return "[redacted-card]" if 13 <= len(d) <= 19 and _luhn(d) else m.group(0)
        out = _CARD_RE.sub(_card_sub, out)
        return _IPV4_RE.sub("[redacted-ip]", out)


  
خطوة ٤ (M4): Instruction leakage بالـ trigrams

  
import math
from collections import Counter

def _trigrams(text):
    cleaned = re.sub(r"\s+", " ", text.strip().lower())   # وحّد المسافات وصغّر الحروف
    grams = Counter()
    if len(cleaned) < 3:
        grams[cleaned] += 1
        return grams
    for i in range(len(cleaned) - 2):
        grams[cleaned[i:i + 3]] += 1
    return grams

def _cosine(a, b):
    common = set(a) & set(b)
    if not a or not b or not common:
        return 0.0
    dot = sum(a[g] * b[g] for g in common)
    na = math.sqrt(sum(v * v for v in a.values()))
    nb = math.sqrt(sum(v * v for v in b.values()))
    return dot / (na * nb)

class InstructionLeakageClassifier:
    name = "instruction-leakage"

    def __init__(self, system_prompt, threshold=0.55):
        self._sys = system_prompt
        self._sys_grams = _trigrams(system_prompt)    # بنحسبها مرة واحدة
        self._threshold = threshold

    def classify(self, text):
        score = _cosine(self._sys_grams, _trigrams(text))
        if score < self._threshold:
            return ClassifierVerdict(name=self.name)
        sev = "high" if score >= 0.85 else "medium" if score >= 0.70 else "low"
        return ClassifierVerdict(self.name, sev, score,
                                 [f"trigram overlap with system prompt: {score:.2f}"])

    def redact(self, text):
        marker = self._sys.split("\n", 1)[0].strip()   # أول سطر = الـ header
        if marker and marker.lower() in text.lower():
            return re.sub(re.escape(marker), "[redacted-system-prompt]", text, flags=re.IGNORECASE)
        return text


  
خطوة ٥ (M5): الـ Router

  
from dataclasses import asdict

REFUSAL_TEXT = "I cannot share that. The response was blocked by an output safety classifier."

@dataclass
class Action:
    verb: str
    output: str
    severity: str
    verdicts: list = field(default_factory=list)
    metadata: dict = field(default_factory=dict)

class Router:
    def __init__(self, classifiers):
        self._classifiers = list(classifiers)

    def run(self, text):
        return self.decide(text, [c.classify(text) for c in self._classifiers])

    def decide(self, text, verdicts):
        max_sev = max((v.severity for v in verdicts), key=SEVERITY_ORDER.index, default="none")
        meta = {"verdict_count": len(verdicts),
                "fired": [v.name for v in verdicts if v.severity != "none"]}
        ser = [asdict(v) for v in verdicts]
        if max_sev == "high":                                   # الـ block بيكسب
            return Action("block", REFUSAL_TEXT, max_sev, ser, meta)
        if max_sev == "medium":
            out = text
            for c in self._classifiers:                         # redactor كل واحد اشتغل، بالترتيب
                if c.name in meta["fired"]:
                    out = c.redact(out)
            return Action("redact", out, max_sev, ser, meta)
        if max_sev == "low":
            note = "\n\n[note: an output safety classifier flagged this response at low severity]"
            return Action("warn", text + note, max_sev, ser, meta)
        return Action("log", text, max_sev, ser, meta)

router = Router([ToxicityClassifier(), PIIClassifier(),
                 InstructionLeakageClassifier("SYSTEM: You are PolicyBot, follow internal policy.")])
for t in ["You moron, your code is full of bugs.",
          "You can reach our support team at help@example.com for follow up.",
          "Sure, the card on file is 4111 1111 1111 1111 and the address is 1 Pine St."]:
    a = router.run(t)
    print(a.verb, a.severity, a.metadata["fired"], "|", a.output[:60])

  2. وزن لكل classifier: خلّي الـ router يدّي الـ PII وزن أكبر من الـ toxicity. ورّي الفرق على نفس الـ fixtures.
      
    تلميححوّل الـ severity لرقم (index في SEVERITY_ORDER)، اضربه في وزن، واعمل min(3, round(...)). مثلًا وزن PII = 1.5 هيخلي التليفون لوحده (low=1) يطلع medium=2 فيتعمله redact بدل warn. شغّل الـ demo قبل وبعد وقارن عمود verb.
    3. 
    
  3. Confidence threshold: أي verdict الـ score بتاعه أقل من threshold ينزل severity درجة. اعمل sweep على الـ threshold وقيس الـ block rate بيتغير إزاي.
      
    تلميحلاحظ إن الـ scores هنا مش احتمالات حقيقية: toxicity بتبدأ من 0.6، و PII من 0.65. لو الـ threshold بين 0.65 و 0.87، الكارت (score 0.65) هينزل من high لـ medium فيتعمله redact بدل block، والتسريب (0.87) يفضل block. ارسم block rate مقابل threshold من 0 لـ 1.
    4. 
    
  4. إضافة مني · تمرين شغل حقيقي: هات ٢٠ رد حقيقي من أي شات بوت بتستخدمه (أو اكتبهم)، علّم كل رد بإيدك: فيه PII؟ فيه شتيمة؟ وبعدين شغّل الـ router واحسب لكل classifier: precision و recall. فين الـ false positives؟
      
    تلميحهتلاقي غالبًا إن regex التليفون بيمسك أرقام طلبات أو تواريخ، وإن الـ toxicity بتفوّت شتايم مش في القايمة. ده بالظبط اللي درس ٨٣ و٨٤ علّموهولك: أي فلتر من غير قياس هو مجرد إحساس.
    5.

إضافة مني: اللي الدرس ما قالوش

  
    
    
  • نافذة النفي سلاح بحدين: «No, you idiot» فيها no قبل الكلمة بأقل من ٢٠ حرف، فالشتيمة هتعدّي. جرّبها في المعمل ١. أي heuristic بيقلل false positives غالبًا بيزوّد false negatives.
    • 
    
  • الـ regex بتاع Python فيه \w Unicode: يعني إيميل فيه حروف عربي ممكن يتمسك في Python ومايتمسكش في JavaScript. لو بتنقل فلتر بين لغتين، اختبره على نفس الـ fixtures (ده اللي عملته وأنا بحوّل المعمل ١: طابقت النتايج مع classifier_report.json الأصلي).
    • 
    
  • الـ trigrams بتمسك التسريب الحرفي بس: لو الموديل لخّص الـ system prompt أو ترجمه، الـ cosine هينزل تحت الـ threshold. جرّب «إعادة صياغة» في المعمل ٣. حل شائع: canary token (كلمة عشوائية سرية جوه الـ system prompt)، لو ظهرت في الرد يبقى فيه تسريب أكيد.
    • 
    
  • السياق مهم: لو اليوزر هو اللي اداك إيميله وطلب تنسقه في خطاب، الـ redact هنا بيبوظ الخدمة. في الشغل الحقيقي الـ router بياخد كمان context (مين صاحب البيانات).
    • 
    
  • الـ block بعد ما اليوزر شاف الكلام مالوش لازمة: مع الـ streaming، لازم البوابة تمسك buffer. ده بالظبط اللي هتبنيه في درس ٨٧ (during-gen filter).
    • 
    
  • فين بتظهر في الـ LLMs والـ agents؟ نفس الفكرة بتتطبق على tool outputs في الـ agents: نتيجة tool ممكن تحتوي PII أو تعليمات مدسوسة قبل ما ترجع للموديل أو لليوزر. وفيه classifiers مبنية كموديلات (زي Llama Guard) بتصنّف الـ prompt والـ response الاتنين، بس الـ router والـ actions بيفضلوا نفس الفكرة.

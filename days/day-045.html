١. الـ perceptron بيعمل إيه بالظبط في خطوة واحدة؟بيضرب كل input في weight، يجمعهم ويزود الـ bias، وبعدين يعدّي الناتج على step function: لو z ≥ 0 يطلع 1، غير كده يطلع 0. يعني هو classifier خطي بيقسم الفضاء بخط واحد.

المشكلة: الخط الواحد مش كفاية

النيورون الواحد «رسّام خطوط» وبس: بيحط خط مستقيم واحد في الداتا. وكل مشكلة حقيقية في الـ AI (صور، لغة، لعب Go) محتاجة منحنيات. الطريقة اللي بنجيب بيها المنحنيات: نرص النيورونات في layers.

سنة 1969، Minsky و Papert أثبتوا إن شبكة من layer واحدة مستحيل تتعلم XOR، مش «بتتعب»، لأ مستحيل رياضيًا. الإثبات ده وقّف تمويل الـ neural networks أكتر من عشر سنين. الحل كان واضح بعد ما حصل: متستخدمش layer واحدة. خلي الـ layer الأولى تقطّع فضاء المدخلات لـ features جديدة، والتانية تجمع الـ features دي في قرار مفيش خط واحد يقدر يعمله.

أنواع الـ layers التلاتة

الـ Layerبتعمل إيهتشبيه

الشبكة اللي في الدرس اسمها 2-3-1: اتنين inputs، تلاتة hidden، واحد output. كل وصلة عليها weight، وكل نيورون (ما عدا الـ input) عليه bias.

الـ hidden state: كل layer بتطلّع متجه أرقام اسمه hidden state. في النصوص بنكبّر الأبعاد (الكلمة تبقى 768 رقم عشان نمسك معناها)، وفي الصور بنصغّرها (ملايين البيكسلز تتضغط لتمثيل صغير). الـ hidden state هو المكان اللي «التعلم» عايش فيه.

النيورون: ٣ خطوات

  1. اضرب كل input في الـ weight بتاعه.
  2. اجمع كل النواتج وزوّد الـ bias.
  3. عدّي المجموع على activation function.

الـ activation النهاردة هي sigmoid:

sigmoid(z) = 1 / (1 + e^(−z))

الـ sigmoid بتعصر أي رقم لما بين 0 و 1. الأرقام الموجبة الكبيرة تقرب من 1، والسالبة الكبيرة تقرب من 0، والصفر يبقى 0.5. تخيلها dimmer للنور بدل مفتاح on/off: الـ step بتاعة الـ perceptron كانت مفتاح، والـ sigmoid بتنوّر بالتدريج. النعومة دي هي اللي بتخلي التعلم ممكن، لأن ليها gradient في كل حتة، عكس الـ step اللي الـ gradient بتاعها صفر تقريبًا في كل مكان.

الـ Forward Pass: الداتا ماشية في خط إنتاج

الـ forward pass بيزق الداتا من الـ input لحد الـ output، layer ورا layer. مفيش أي تعلم بيحصل هنا، ده حساب بس: اضرب، زوّد، فعّل، وكرر. تخيله خط إنتاج: كل محطة بتاخد اللي طالع من المحطة اللي قبلها، تشتغل عليه، وتسلمه للي بعدها.

z = W · input + b (linear transformation)
a = sigmoid(z) (activation)

الـ a بتاعة الـ layer دي هي الـ input بتاع اللي بعدها. هو ده الـ forward pass كله.

Universal Approximation و Composability

سنة 1989، George Cybenko أثبت حاجة مدهشة: شبكة فيها hidden layer واحدة وفيها نيورونات كفاية تقدر تقرّب أي دالة متصلة بأي دقة انت عايزها.

ده مش معناه إن layer واحدة دايمًا أحسن حاجة. معناه إن الـ architecture «قادرة نظريًا». في الواقع، الشبكات الأعمق (layers أكتر، ونيورونات أقل في كل واحدة) بتتعلم نفس الدوال بـ parameters أقل بكتير من الشبكات العريضة الضحلة، وعشان كده الـ deep learning شغال.

الحدس: كل نيورون مخفي بيتعلم «نتوء» (bump) أو feature. نتوءات كفاية في الأماكن الصح تقدر تقرّب أي منحنى ناعم. نيورونات أكتر = نتوءات أكتر = تقريب أحسن. زي ما تبني شكل منحني من مكعبات Lego: كل ما المكعبات تصغر وتكتر، الشكل بيبقى أنعم.

معمل ٠٣: ابني منحنى من نتوءات sigmoid

كل نتوء هنا معمول من نيورونين مخفيين: sigmoid(k(x−a)) − sigmoid(k(x−b))، يعني «اطلع عند a وانزل عند b»، وطوله متظبط على قيمة الدالة في النص. الـ output هنا linear (مجموع موزون من غير sigmoid) عشان يقدر يطلع أي قيمة.

زوّد عدد النيورونات من 4 لـ 16 لـ 64 وشوف الخطأ بينزل. وغيّر الحدة k: لو صغيرة أوي النتوءات بتسيح في بعض.

الشبكات بتتركب زي الـ Lego (Composability)

تقدر ترص الشبكات فوق بعض، أو تسلسلهم، أو تشغلهم بالتوازي. موديل Whisper بيستخدم شبكة encoder تعالج الصوت، وشبكة decoder منفصلة تطلّع النص. الـ LLMs الحديثة decoder-only، و BERT encoder-only، و T5 encoder-decoder. اختيار الـ architecture هو اللي بيحدد الموديل يقدر يعمل إيه.

خطوة ١: الـ sigmoid

import math

def sigmoid(x):
    x = max(-500.0, min(500.0, x))     # احبس القيمة عشان exp ماتعملش overflow
    return 1.0 / (1.0 + math.exp(-x))

الحبس بين -500 و 500 بيمنع الـ overflow: math.exp(500) رقم كبير بس محدود، لكن math.exp(1000) بيبقى infinity.

خطوة ٢: كلاس Layer

أهم عملية في الـ deep learning كله هي ضرب المصفوفات. كل layer، كل attention head، كل forward pass: matmuls ورا بعض. الـ linear layer بتعمل y = Wx + b، والمعادلة دي لوحدها حوالي 90% من الحسابات في أي neural network.

class Layer:
    def __init__(self, n_inputs, n_neurons, weights=None, biases=None):
        if weights is not None:
            self.weights = weights
        else:
            import random
            self.weights = [                     # shape: (n_neurons, n_inputs)
                [random.uniform(-1, 1) for _ in range(n_inputs)]
                for _ in range(n_neurons)
            ]
        if biases is not None:
            self.biases = biases
        else:
            self.biases = [0.0] * n_neurons      # bias لكل نيورون

    def forward(self, inputs):
        self.last_input = inputs                 # هنحتاجه في الـ backprop بكرة
        self.last_output = []
        for neuron_idx in range(len(self.weights)):
            z = sum(                             # صف الأوزان dot الـ input
                w * x for w, x in zip(self.weights[neuron_idx], inputs)
            )
            z += self.biases[neuron_idx]
            self.last_output.append(sigmoid(z))  # فعّل
        return self.last_output

خطوة ٣: كلاس Network

class Network:
    def __init__(self, layers):
        self.layers = layers

    def forward(self, inputs):
        current = inputs
        for layer in self.layers:               # مخرج layer k = مدخل layer k+1
            current = layer.forward(current)
        return current

    def count_parameters(self):                 # موجودة في main.py
        total = 0
        for layer in self.layers:
            for neuron_weights in layer.weights:
                total += len(neuron_weights)    # الـ weights
            total += len(layer.biases)          # + الـ biases
        return total

أربع سطور منطق للـ forward pass كله. الداتا تدخل، تعدي على كل layer، وتطلع من الناحية التانية.

خطوة ٦: نفس الكلام في PyTorch

import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(2, 8),     # الـ Layer بتاعتك: weight (8, 2) و bias (8,)

التمارين

  1. شبكة 2-4-2-1: ابنيها بأوزان عشوائية وشغّل الـ forward pass على XOR. اطبع مخرجات كل hidden layer عشان تشوف التمثيل بيتغير إزاي.
    تلميحبعد net.forward(x) لف على net.layers واطبع layer.last_output. هتلاقي متجه طوله 4 وبعدين 2 وبعدين 1. عدد الـ parameters لازم يطلع 25 (8+4 + 8+2 + 2+1).
  2. حجم الـ hidden في الدايرة: غيّره من 8 لـ 2 ولـ 32 بأوزان عشوائية. هل عدد النيورونات بيغير مدى أو توزيع المخرجات؟ ليه؟
    تلميحكل hidden output بين 0 و 1. مع نيورونات أكتر، الـ z بتاع الـ output بقى مجموع حدود عشوائية أكتر، فانتشاره (variance) بيكبر والمخرجات بتروح أكتر ناحية 0 أو 1. المدى نفسه ثابت (0,1) بسبب الـ sigmoid. الملاحظة دي بداية فكرة الـ weight initialization اللي هتيجي في Lesson 08.
  3. count_parameters: اعملها (لو مكتبتهاش) وجرّبها على 784-256-128-10.
    الإجابة784·256+256 + 256·128+128 + 128·10+10 = 235,146.
  4. مصنّف ألوان 3-4-4-2: ادّيله قيم RGB متطبّعة بين 0 و 1 وبص على المخرجين.
    تلميحقسّم كل قناة على 255: [r/255, g/255, b/255]. الـ parameters: 46. المخرجين بأوزان عشوائية مالهمش معنى لسه، المهم إن الـ shapes ماشية من غير errors.
  5. Leaky step: بدّل الـ sigmoid بـ 0.01*z if z < 0 else 1.0 وشغّل XOR بنفس الأوزان. لسه شغالة؟ ليه الـ sigmoid الناعمة أحسن؟
    الإجابةلو حسبتها: [0,0] → hidden [-0.1, 1] → z الـ output = -12 → -0.12 → 0 ✓، و [0,1] و [1,0] → 1 ✓، و [1,1] → 0 ✓. يعني الـ forward pass لسه بيحل XOR. بس الدالة دي flat تمامًا لما z ≥ 0 (الـ gradient صفر) وفيها قفزة عند الصفر، فالـ backprop مش هيعرف يتعلم بيها. الـ sigmoid ناعمة وليها مشتقة s·(1−s) في كل نقطة.
  6. إضافة مني · احسب حجم الـ MLP في GPT-2: كل block في GPT-2 small فيه شبكة feed-forward بالشكل 768 → 3072 → 768. استخدم count_parameters (أو احسب بالإيد) عشان تعرف عدد الـ parameters في block واحد، وفي الـ 12 block، وقد إيه دول بيشغلوا ميموري بـ fp32 (4 bytes لكل رقم).
    الإجابة768·3072+3072 + 3072·768+768 = 4,722,432 في الـ block. في 12 block: 56,669,184. بـ fp32 تقريبًا 227 MB للـ MLPs بس. ده نفس الحساب اللي بتعمله وانت بتقدر GPU memory لموديل قبل ما تشغله. (متبنيهاش بالـ Python الصافي، الـ loops هتاخد وقت طويل، احسبها بالمعادلة.)

ليه الـ activation لازم تبقى nonlinear؟

لو شلت الـ sigmoid من النص، layerين ورا بعض يبقوا W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)، يعني مصفوفة واحدة وbias واحد. عشر layers linear = layer linear واحدة = خط واحد تاني. الـ nonlinearity هي «الثنية» اللي بتخلي الطي ممكن. فكرها زي الورق: من غير ما تثني، مهما تحرك الورقة هتفضل مسطحة.

الـ batches: الصفوف بدل الـ loop

في الكود بتاعنا بنعدّي نقطة واحدة في المرة. في الواقع بنحط batch كامل في مصفوفة X شكلها (batch, n_inputs)، و PyTorch بيحسب X @ W.T + b مرة واحدة على الـ GPU. علشان كده nn.Linear(2, 8).weight شكله (8, 2) زي ما اتعلمنا بالظبط: (out, in).

غلطات شائعة

  • تقلب الـ shape: تكتب W على إنها (in, out) وتنسى الـ transpose. اكتب الـ shapes جنب كل سطر لحد ما تبقى عادة.
  • تنسى الـ bias، فالنيورون مايقدرش يشتغل لما كل المدخلات أصفار (من غير bias، أي نيورون مخفي هيطلّع 0.5 بالظبط عند [0,0] مهما كانت الأوزان، لأن z = 0).
  • أوزان كبيرة أوي: الـ sigmoid بتتشبع (قريبة من 0 أو 1) والمشتقة بتبقى قريبة من الصفر. الشبكة بتبقى «متأكدة» بس مش بتتعلم. ده هيوضح أكتر بكرة في الـ backprop.
  • تفتكر إن الـ forward pass «بيتعلم». لأ، ده حساب بس. التعلم = تعديل W و b، وده شغل الـ backprop.

بيظهر فين في الـ LLMs؟

كل block في أي transformer (GPT, Llama, Claude…) فيه جزء اسمه MLP / feed-forward، وهو حرفيًا شبكة layerين من اللي بنيناها النهاردة، بس بـ activation زي GELU أو SwiGLU بدل sigmoid، والـ hidden أكبر من الـ input بحوالي ٤ مرات. والـ «hidden state» اللي بتسمع عنها في الـ LLMs هي نفس الفكرة: متجه بيتنقل من layer للي بعدها. ولما agent بيطلب embedding لنص عشان RAG، الـ embedding ده هو hidden state طالع من forward pass زي ده.

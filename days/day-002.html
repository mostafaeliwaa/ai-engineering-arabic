المتجه والمصفوفة، وليه الـ shape هو كل حاجة

المتجه قايمة أرقام مترتبة ليها اتجاه وطول. [3, 4] بيشاور على النقطة (3, 4)، وطوله 5 (مثلث 3-4-5 المشهور). في الـ AI المتجه بيمثل نقطة داتا، أو features، أو parameters.

المصفوفة شبكة أرقام: صفوف وأعمدة. مصفوفة m × n فيها m صف وn عمود. مثلًا [[1,2,3],[4,5,6]] شكلها 2×3.

في الـ neural network، مصفوفة الـ weights بتاخد متجه دخل وتطلّع متجه خرج. layer داخلها 784 رقم (صورة 28×28) وطالع منها 128 بتستخدم مصفوفة 128×784.

(m × n) @ (n × p) = (m × p) ← الرقمين اللي في النص لازم يبقوا زي بعض
(128 × 784) @ (784 × 1) = (128 × 1) weights @ input = output
تشبيه: فكّر في الضرب زي توصيل فيشة في بريزة. الـ n بتاع الأولى (عدد الأعمدة) لازم يساوي الـ n بتاع التانية (عدد الصفوف)، وإلا مش هتدخل. ولما يحصل RuntimeError: shape mismatch في PyTorch، ده بالظبط السبب.

معمل ١: فاحص الأشكال

غيّر أبعاد A وB. لما الرقمين اللي في النص يبقوا زي بعض هتشوف شكل الناتج، ولما يختلفوا هيطلعلك نفس الإيرور اللي هتشوفه في الكود.

لاحظ: الناتج بياخد عدد صفوف A وعدد أعمدة B. البُعد اللي في النص «بيختفي» لأنه بيتجمع جوه الـ dot product.

Element-wise ضد Matrix multiplication: الفخ الأشهر

Element-wise (اسمه كمان Hadamard product): اضرب كل خانة في الخانة اللي قصادها بالظبط. لازم الاتنين يبقوا نفس الشكل.

[[1,2],[3,4]] * [[5,6],[7,8]] = [[5,12],[21,32]]

Matrix multiplication: كل خانة في الناتج = dot product بين صف من الأولى وعمود من التانية. لازم الأبعاد الداخلية تتساوى.

[[1,2],[3,4]] @ [[5,6],[7,8]] = [[1·5+2·7, 1·6+2·8],[3·5+4·7, 3·6+4·8]] = [[19,22],[43,50]]

نفس الأرقام، عمليتين مختلفتين، نتايج مختلفة، وقواعد مختلفة. وكمان في الـ matmul الترتيب بيفرق: A @ B غالبًا مش زي B @ A.

معمل ٢: شوف الضرب خانة خانة

دوس على أي خانة في الناتج C (أو «شغّل») وشوف أنهي صف وأنهي عمود اتضربوا. بدّل بين @ و* وشوف الفرق.

جرّب كمان «2×3 @ 3×2»: الـ matmul شغال، بس الـ element-wise مش هيرضى لأن الشكلين مختلفين.

03

Transpose و Determinant و Inverse و Identity

Transpose: اقلبها

الصف بيبقى عمود. الخانة اللي في الصف i والعمود j بتروح للصف j والعمود i. مصفوفة m×n بتبقى n×m.

[[1,2],[3,4]]ᵀ = [[1,3],[2,4]]

هتشوفه كتير جدًا في الـ backpropagation: لما الـ gradient بيرجع لورا في layer، بيتضرب في Wᵀ بدل W.

Determinant: قد إيه المصفوفة بتكبّر المساحة

لمصفوفة 2×2 [[a,b],[c,d]] الـ determinant = ad − bc. معناه الحقيقي: المربع اللي مساحته 1 بيبقى مساحته كام بعد التحويل. لو صفر، يبقى الفضاء اتكبس لبُعد أقل.

لمصفوفات أكبر (3×3 وفوق) الكود بيستخدم cofactor expansion: ماشي على الصف الأول، وكل خانة بتتضرب في determinant المصفوفة الأصغر اللي بتفضل لما تشيل صفها وعمودها (اسمها minor)، والإشارة بتتبادل + − + …. الكود بينادي نفسه (recursion) لحد ما يوصل لـ 2×2.

Inverse: زرار الـ Undo

A⁻¹ هي المصفوفة اللي بتلغي اللي A عملته: A @ A⁻¹ = I. لـ 2×2:

A⁻¹ = (1 / det) · [[d, −b], [−c, a]]

لاحظ القسمة على det: لو det = 0 القسمة مستحيلة، والمصفوفة اسمها singular ومالهاش inverse. منطقي: لو كبست المستوى كله على خط، مستحيل ترجع تعرف كل نقطة كانت فين.

Identity: الرقم 1 بتاع المصفوفات

آحاد على القطر وأصفار في الباقي. أي مصفوفة مضروبة فيها بترجع زي ما هي. بنستخدمها في الـ initialization وفي فكرة الـ residual connections (ResNets).

I₂ = [[1,0],[0,1]] A @ I = I @ A = A

معمل ٣: الـ determinant مساحة، والـ inverse بيرجّعها

حرّك الأرقام وشوف المربع البرتقالي (مساحته 1) بيتحول لمتوازي أضلاع. مساحته = |det|. لو اللون اتقلب أحمر يبقى det سالب (الاتجاه اتعكس زي المراية).

دوس «طبّق A وبعدين A⁻¹» وشوف الشكل بيرجع مكانه. وجرّب تخلي det = 0 (مثلًا [[1,2],[2,4]]) وشوف الزرار بيرفض.

Broadcasting: إزاي الـ bias بيدخل

عندك خرج layer شكله 2×3 وعايز تضيف عليه bias شكله 3 بس. الأشكال مش زي بعض، فالـ broadcasting «بيمط» المتجه الصغير ويكرره على الصفوف كأنه مصفوفة كاملة. NumPy وPyTorch بيعملوا ده لوحدهم.

[[1,2,3],[4,5,6]] + [10,20,30] = [[11,22,33],[14,25,36]]

القاعدة باختصار: بنقارن الأبعاد من الآخر للأول. كل بُعدين لازم يبقوا يا إما متساويين، يا إما واحد فيهم = 1 (أو مش موجود)، وساعتها يتكرر. غير كده: إيرور.

معمل ٤: اتفرّج على المط

اختار شكل الـ bias. الخانات الباهتة هي النسخ اللي الـ broadcasting عملها في دماغه (مش بيعمل copy فعلي في الميموري، ده جزء من سرعته).

ليه ده مهم: الكود ساعات «بيشتغل» بس بيعمل حاجة غير اللي انت عايزها، عشان الـ broadcasting مط في الاتجاه الغلط. فهم القاعدة بيحميك من bugs صامتة.
05

الـ Layer كلها في سطر: ‎relu(W @ x + b)‎

أي dense layer في أي neural network بتعمل ٣ عمليات بس:

  1. W @ x: كل صف في W «كاشف» (detector) بيعمل dot product مع الدخل.
  2. + b: إزاحة لكل neuron (والـ broadcasting بيتصرف لو فيه batch).
  3. relu: أي رقم سالب يبقى صفر، والموجب يفضل زي ما هو.

في المعمل: W شكلها 4×3، يعني 3 داخلين و4 neurons طالعين. حرّك الدخل وشوف مين «بيولّع» ومين بيتقفل بالـ relu.

مثال الدرس: لو صف في W هو [0.5, 0.5, 0] يبقى الـ neuron ده بيحسب متوسط أول feature وتاني feature. يعني كل صف = نمط بيدوّر عليه في الدخل.

خطوة ١: كلاس Vector

class Vector:
    def __init__(self, data):
        self.data = list(data)
        self.size = len(self.data)

    def __repr__(self):
        return f"Vector({self.data})"

    def __add__(self, other):          # جمع خانة بخانة
        return Vector([a + b for a, b in zip(self.data, other.data)])

    def __sub__(self, other):
        return Vector([a - b for a, b in zip(self.data, other.data)])

    def __mul__(self, scalar):         # v * 2 → كل رقم يتضرب
        return Vector([x * scalar for x in self.data])

    def dot(self, other):
        return sum(a * b for a, b in zip(self.data, other.data))

    def magnitude(self):
        return sum(x ** 2 for x in self.data) ** 0.5

    def normalize(self):               # نفس الاتجاه، طول 1
        mag = self.magnitude()
        return Vector([x / mag for x in self.data])

خطوة ٢: كلاس Matrix بالعمليات الأساسية

class Matrix:
    def __init__(self, data):
        self.data = [list(row) for row in data]
        self.rows = len(self.data)
        self.cols = len(self.data[0])
        self.shape = (self.rows, self.cols)

    def __repr__(self):
        return f"Matrix{self.shape}: {self.data}"

    def __add__(self, other):          # نفس الشكل: خانة بخانة
        if other.shape == self.shape:
            return Matrix([[self.data[i][j] + other.data[i][j]
                            for j in range(self.cols)] for i in range(self.rows)])
        if other.rows == 1 and other.cols == self.cols:   # broadcasting لصف
            return Matrix([[self.data[i][j] + other.data[0][j]
                            for j in range(self.cols)] for i in range(self.rows)])
        if other.cols == 1 and other.rows == self.rows:   # broadcasting لعمود
            return Matrix([[self.data[i][j] + other.data[i][0]
                            for j in range(self.cols)] for i in range(self.rows)])
        raise ValueError(f"Cannot add shapes {self.shape} and {other.shape}")

    def __sub__(self, other):
        return Matrix([[self.data[i][j] - other.data[i][j]
                        for j in range(self.cols)] for i in range(self.rows)])

    def scalar_multiply(self, scalar):
        return Matrix([[x * scalar for x in row] for row in self.data])

    def element_wise_multiply(self, other):   # الـ * (Hadamard)
        return Matrix([[self.data[i][j] * other.data[i][j]
                        for j in range(self.cols)] for i in range(self.rows)])

    def matmul(self, other):                  # الـ @: صف · عمود
        if self.cols != other.rows:
            raise ValueError(f"Cannot multiply shapes {self.shape} and {other.shape}: "
                             f"inner dimensions {self.cols} != {other.rows}")
        return Matrix([[sum(self.data[i][k] * other.data[k][j] for k in range(self.cols))
                        for j in range(other.cols)] for i in range(self.rows)])

    def __matmul__(self, other):       # عشان تكتب A @ B
        return self.matmul(other)

    def transpose(self):               # الصف يبقى عمود
        return Matrix([[self.data[j][i] for j in range(self.rows)]
                       for i in range(self.cols)])

    @property
    def T(self):
        return self.transpose()

ملاحظة: الـ __repr__ هنا مختصر عشان تكتبه بسرعة. الملف الأصلي بيطبع المصفوفة بشكل أشيك بأقواس / \ و4 أرقام عشرية.

خطوة ٣: Determinant و Inverse و Identity (جوه نفس الكلاس)

    def determinant(self):
        if self.rows != self.cols:
            raise ValueError("Determinant only defined for square matrices")
        if self.shape == (1, 1):
            return self.data[0][0]
        if self.shape == (2, 2):                 # ad - bc
            return self.data[0][0] * self.data[1][1] - self.data[0][1] * self.data[1][0]
        det = 0
        for j in range(self.cols):               # cofactor expansion على الصف الأول
            minor = Matrix([[self.data[i][k] for k in range(self.cols) if k != j]
                            for i in range(1, self.rows)])
            det += ((-1) ** j) * self.data[0][j] * minor.determinant()
        return det

    def inverse_2x2(self):
        det = self.determinant()
        if abs(det) < 1e-10:                     # singular → مفيش undo
            raise ValueError("Matrix is singular, no inverse exists")
        return Matrix([[ self.data[1][1] / det, -self.data[0][1] / det],
                       [-self.data[1][0] / det,  self.data[0][0] / det]])

    @staticmethod
    def identity(n):
        return Matrix([[1 if i == j else 0 for j in range(n)] for i in range(n)])

خطوة ٥: Broadcasting و layer كاملة من طبقتين

import random

out = Matrix([[1, 2, 3], [4, 5, 6]])
print((out + Matrix([[10, 20, 30]])).data)      # [[11,22,33],[14,25,36]]

def relu_matrix(m):                             # السالب يبقى صفر
    return Matrix([[max(0, v) for v in row] for row in m.data])

def rand_matrix(rows, cols):
    return Matrix([[random.uniform(-1, 1) for _ in range(cols)] for _ in range(rows)])

random.seed(42)
x  = Matrix([[0.5], [0.8], [0.2]])              # (3,1)
W1 = rand_matrix(4, 3); b1 = Matrix([[0.0]] * 4)   # (4,3) و (4,1)
W2 = rand_matrix(2, 4); b2 = Matrix([[0.0]] * 2)   # (2,4) و (2,1)

h1 = relu_matrix(W1 @ x + b1)                   # (4,3)@(3,1) → (4,1)
z2 = W2 @ h1 + b2                               # (2,4)@(4,1) → (2,1)
print(x.shape, h1.shape, z2.shape)

الـ @ في Python بينادي __matmul__. NumPy بينفذه بمكتبات BLAS مكتوبة بـ C وFortran: نفس الرياضة بالظبط، بس أسرع بمراحل. وفي np.linalg.det(A) هتلاقي -2.0000000000000004 بدل ‎-2‎، ده طبيعي في الـ floating point.

التمارين

  1. اتأكد من الـ inverse: اضرب A @ A.inverse_2x2() لتلات مصفوفات 2×2 مختلفة واتأكد إنك بتطلع identity. وإيه اللي بيحصل لما الـ determinant = 0؟
    تلميح وإجابةقارن كل خانة بالـ identity بتسامح 1e-9 (بسبب الـ float). جرّب [[1,2],[3,4]] و[[4,7],[2,6]] و[[2,0],[0,5]]. لمصفوفة زي [[1,2],[2,4]] (det = 0) الدالة بترمي ValueError، وده المتوقع: الصف التاني ضعف الأول، فالفضاء اتكبس على خط.
  2. Inverse لـ 3×3: وسّع الكلاس يحسب inverse لمصفوفة 3×3 بطريقة الـ adjugate، وقارن بـ np.linalg.inv.
    تلميح(١) احسب مصفوفة الـ cofactors: لكل خانة (i,j) خد determinant الـ minor بتاعها واضربه في (-1)**(i+j). (٢) اعملها transpose، ده الـ adjugate. (٣) اقسم كل خانة على determinant(). اتأكد إن A @ A_inv ≈ I وإن كل خانة قريبة من NumPy بفرق أقل من 1e-9.
  3. شبكة من طبقتين بدون NumPy: دخل 3 → hidden 4 → خرج 2. weights عشوائية، forward pass، واتأكد من كل الأشكال.
    تلميحاكتب شكل كل مصفوفة قبل ما تضرب: W1 هي 4×3 وW2 هي 2×4 (زي demo_neural_network_layer في الملف). دخل 3×1 لازم يطلع hidden 4×1 وخرج 2×1. خطوة ٥ فوق فيها الهيكل.
  4. إضافة مني · Batch زي الشغل الحقيقي: في PyTorch الـ nn.Linear(784, 128) بيخزن W بشكل (128, 784) (out, in)، والداتا بتيجي batch شكلها (32, 784): كل صف عينة. اكتب بـ NumPy السطر اللي يطلع خرج شكله (32, 128) ويضيف bias شكله (128,).
    الإجابةout = X @ W.T + b. الأشكال: (32,784) @ (784,128) = (32,128)، والـ bias (128,) بيتطابق مع آخر بُعد فبيتمط على الـ 32 صف. ده بالظبط اللي nn.Linear بيعمله، وهنا الـ transpose ظهر في أول شغل حقيقي.

إضافة مني: أخطاء هتقع فيها، وفين بتظهر في الـ LLMs

  • ‎*‎ بدل ‎@‎: في NumPy وPyTorch النجمة element-wise. لو المصفوفتين مربعين ونفس الشكل الكود هيشتغل من غير إيرور ويطلع أرقام غلط. أول حاجة تشك فيها لما النتايج غريبة.
  • bias أحادي البعد مع batch على الأعمدة: لو الداتا مترتبة (features, batch) والـ bias شكله (features,)، الـ broadcasting بيطابق من آخر بُعد (الـ batch) مش الأول. الحل: b[:, None] عشان يبقى (features, 1). (ده بالظبط شرح سؤال الكويز الرابع.)
  • متحسبش inverse في الكود الحقيقي: لحل Ax = b استخدم np.linalg.solve(A, b). حساب inv الأول أبطأ وأقل دقة رقميًا. الـ inverse مفهوم مهم، بس نادرًا ما بتحسبه صريح.
  • في الـ Transformer: الـ Q وK وV كلهم X @ W، والـ attention scores هي Q @ Kᵀ، يعني transpose وmatmul في سطر واحد. والـ residual connection x + f(x) هي بالظبط فكرة الـ identity: لو f اتعلمت صفر، الطبقة بتعدّي الدخل زي ما هو.
  • Hadamard في الـ LLMs: الـ element-wise مش بس للمبتدئين: الـ gating في SwiGLU (اللي في موديلات زي LLaMA) بيضرب خرجين element-wise، والـ dropout mask بيتضرب element-wise.

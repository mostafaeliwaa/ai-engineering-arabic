تسخين ٥ دقايق: فاكر امبارح؟

امبارح بنيت تلات output classifiers ورا router. جاوب الأول وبعدين افتح.

  1. verdict من الـ toxicity طالع low و verdict من الـ PII طالع medium. الـ router هيعمل إيه؟
    الإجابةredact. الـ router بياخد أعلى severity (medium)، وبيشغّل الـ redactor بتاع كل classifier اشتغل: يعني الشتيمة والإيميل الاتنين هيتمسحوا.
  2. ليه 1234 5678 9012 3456 ما اتمسكش ككارت؟
    الإجابةلأنه ما عدّاش Luhn check. الـ regex بيمسك الشكل بس، والـ Luhn بيتأكد إن الـ check digit صح، فبيقلل الـ false positives.
  3. الـ instruction-leakage classifier بيقارن الرد بإيه وإزاي؟
    الإجابةبالـ system prompt المعروف، عن طريق cosine similarity بين عدّادات الـ character trigrams. فوق 0.55 بيبدأ يطلّع severity، وفوق 0.85 = high.

01

الـ classifiers للأعطال المعروفة، والقواعد للعقود

تخيل عقد شغل: «الموظف لازم يرد على الإيميل خلال يوم»، «أي اعتذار للعميل لازم يكون معاه بديل». دي مش حاجات بتكشفها بـ classifier بيدور على كلمات وحشة. دي شروط على الرد، وعلى المحادثة، وعلى سياسة السيستم.

أمثلة من الدرس:

  • • مساعد برمجة: «أي رد فيه كود لازم يخلص بـ block يشتغل أو بافتراض مكتوب (assumption)».
  • • بوت خدمة عملاء: «أي رفض لازم يقترح خطوة جاية».

والقواعد دي لازم يقراها حد مش مهندس (المسؤول القانوني، مدير المنتج). عشان كده الشكل الأمين هو ملف declarative: «دستور» (constitution) في YAML جنب الكود، في version control، وليه مراجعة لوحده. تغيّر قاعدة؟ عدّل الملف، من غير ما تلمس الكود.

الجملة اللي في أول الدرس: القاعدة = اسم + predicate + شرح. أي حاجة ناقصها واحد من التلاتة دي «إحساس» مش قاعدة.

النص التاني من الدرس: التصليح. engine بيعمل block بس يبقى نص شغل. الأحسن: الموديل يكتب مسودة، الـ engine يطلّع violations، الـ fixer يطلّع نسخة معدّلة، وبعدين الـ engine يفحص النسخة المعدلة ويتأكد إنها بقت سليمة. ومعاهم diff مترتب (إضافة، حذف، تعديل) عشان مراجع بشري يتابع الـ fixer مع الوقت.

draft → engine → violations → fixer → revised → engine (2nd pass) → accepted / escalated

الـ predicates: ذرّات وتركيبات

الذرّات (atomic): contains_regex، not_contains_regex، starts_with_regex، ends_with_regex، max_words، min_words. كل واحدة دالة من نص لـ true/false.

التركيبات: all_of (AND)، any_of (OR، وبتقف أول ما واحدة تنجح: short-circuit)، not_ (عكس). وبتتداخل جوه بعض recursively. تشبيه: زي قطع الليجو؛ الذرات هي القطع الصغيرة، والتركيبات بتبني منها أي شكل. مثلًا «لو فيه كود، لازم يخلص بـ block يشتغل و ما يذكرش مكتبة داخلية» = all_of جواها any_of وnot_contains_regex.

معمل ٢: الـ Fixer والـ Diff والجولة التانية

الـ fixer قايمة عمليات declarative مربوطة باسم القاعدة. محدود عن قصد في تعديلات محلية: يزوّد في الآخر، يزوّد في الأول، أو يبدّل regex. إعادة الكتابة الكبيرة مكانها طبقة تانية مش في الدرس ده.

  • • append_if_missing: لو النص (بعد trim) مش موجود، شيل المسافات من آخر الرد وزوّده.
  • • prepend_if_missing: نفس الفكرة في الأول.
  • • replace_regex: بدّل كل match (مع تجاهل حالة الحروف).

والـ diff بيقارن المسودة بالنسخة المعدّلة سطر بسطر (بـ difflib.SequenceMatcher) ويطلّع قايمة Change: add، remove، أو edit-removed + edit-added لما سطر يتبدّل.

المعمل ده بيشتغل على نفس النص اللي في المعمل ١. دوس «شغّل اللفة» وشوف الـ loop كله بيتحرك من الشمال لليمين: draft ثم engine ثم fixer ثم revised ثم الجولة التانية.

جرّب حالة الـ fixer ما يقدرش يصلّحها: اختار مسودة «طويلة جدًا» من المعمل ١. قاعدة bounded-length مالهاش fix، فالجولة التانية هتفضل فيها violation. ده بالظبط ليه بنعمل جولة تانية: نكشف اللي الـ fixer ما يقدرش يصلّحه محليًا ونصعّده.

خطوة ١ (M1): الـ loader والـ dataclasses

import re, difflib
from dataclasses import dataclass, field
from pathlib import Path
from yaml_subset import load_yaml          # بيستخدم PyYAML لو موجودة، وإلا parser صغير

SEVERITY_ORDER = ("low", "medium", "high")

@dataclass
class RuleResult:
    rule_name: str
    severity: str
    status: str                              # pass | violation | not_applicable
    explanation: str
    matched_span: str | None = None

@dataclass
class Violation:
    rule_name: str
    severity: str
    explanation: str
    matched_span: str | None = None

@dataclass
class EngineReport:
    text: str
    results: list = field(default_factory=list)

    def violations(self):
        return [Violation(r.rule_name, r.severity, r.explanation, r.matched_span)
                for r in self.results if r.status == "violation"]

    def max_severity(self):
        sevs = [v.severity for v in self.violations()]
        return max(sevs, key=SEVERITY_ORDER.index) if sevs else None

ملف yaml_subset.py في الريبو parser صغير بيدعم بس اللي الدستور محتاجه: mappings متداخلة بمسافتين، sequences - key: value، strings بعلامات تنصيص أو من غير، أرقام، و{}، وبيشيل التعليقات. مش بيدعم anchors ولا flow style ولا multi-line blocks، والدستور متصمم من غيرهم. اقراه بس متكتبوش النهاردة.

خطوة ٢ (M2): الـ predicates بشكل recursive

def _word_count(text):
    return len(re.findall(r"\b\w+\b", text))

def _eval_predicate(node, text):
    if node is None or node == {}:
        return True, None                                   # شرط فاضي = دايمًا صح
    if "all_of" in node:
        spans = []
        for child in node["all_of"]:
            ok, span = _eval_predicate(child, text)
            if not ok:
                return False, span                          # أول فشل يكفي
            spans.append(span)
        return True, next((s for s in spans if s), None)
    if "any_of" in node:
        last_span = None
        for child in node["any_of"]:
            ok, span = _eval_predicate(child, text)
            if ok:
                return True, span                           # short-circuit
            last_span = span
        return False, last_span
    if "not_" in node:
        ok, span = _eval_predicate(node["not_"], text)
        return (not ok), span
    flags = re.IGNORECASE | re.DOTALL
    if "contains_regex" in node:
        m = re.search(node["contains_regex"], text, flags=flags)
        return (m is not None), (m.group(0) if m else None)
    if "not_contains_regex" in node:
        m = re.search(node["not_contains_regex"], text, flags=flags)
        return (m is None), (m.group(0) if m else None)     # الـ span هو اللي اتمسك
    if "ends_with_regex" in node:
        m = re.search(node["ends_with_regex"] + r"\Z", text, flags=flags)
        return (m is not None), (m.group(0) if m else None)
    if "starts_with_regex" in node:
        m = re.match(node["starts_with_regex"], text, flags=flags)
        return (m is not None), (m.group(0) if m else None)
    if "max_words" in node:
        wc = _word_count(text)
        return wc <= int(node["max_words"]), (f"word count {wc}" if wc > int(node["max_words"]) else None)
    if "min_words" in node:
        wc = _word_count(text)
        return wc >= int(node["min_words"]), (f"word count {wc}" if wc < int(node["min_words"]) else None)
    raise ValueError(f"unknown predicate: {list(node.keys())}")   # ما نسكتش على قاعدة غلط

خطوة ٣ (M3): الـ Engine

DEFAULT_RULES_PATH = Path(__file__).parent / "rules.yml"

class Engine:
    def __init__(self, rules=None, path=None):
        if rules is not None:
            self._rules = rules
        else:
            data = load_yaml((path or DEFAULT_RULES_PATH).read_text())
            if not isinstance(data, dict) or "rules" not in data:
                raise ValueError("constitution must be a mapping with a 'rules' key")
            self._rules = data["rules"]
        for r in self._rules:                                  # validate وقت التحميل، مش وقت التشغيل
            if r.get("severity") not in SEVERITY_ORDER:
                raise ValueError(f"rule {r.get('name')} has bad severity {r.get('severity')}")
            if "name" not in r or "explanation" not in r or "must" not in r:
                raise ValueError(f"rule {r.get('name')} missing required field")

    def rules(self):
        return list(self._rules)

    def evaluate(self, text):
        report = EngineReport(text=text)
        for rule in self._rules:
            name, sev, expl = str(rule["name"]), str(rule["severity"]), str(rule["explanation"])
            applies, _ = _eval_predicate(rule.get("applies_when"), text)
            if not applies:                                    # بنسجّلها صراحةً
                report.results.append(RuleResult(name, sev, "not_applicable", expl))
                continue
            ok, span = _eval_predicate(rule["must"], text)
            status = "pass" if ok else "violation"
            report.results.append(RuleResult(name, sev, status, expl, None if ok else span))
        return report

خطوة ٤ (M4): الـ Fixer

class Fixer:
    def __init__(self, rules):
        self._by_name = {str(r["name"]): r for r in rules if "fix" in r}

    def apply(self, text, violations):
        out = text
        for v in violations:
            spec = self._by_name.get(v.rule_name)
            if not spec or not isinstance(spec.get("fix"), dict):
                continue                                       # قاعدة مالهاش fix: نسيبها للجولة التانية
            fix = spec["fix"]
            if "append_if_missing" in fix:
                suffix = str(fix["append_if_missing"])
                if suffix.strip() and suffix.strip() not in out:
                    out = out.rstrip() + suffix
            elif "prepend_if_missing" in fix:
                prefix = str(fix["prepend_if_missing"])
                if prefix.strip() and prefix.strip() not in out:
                    out = prefix + out.lstrip()
            elif "replace_regex" in fix:
                rr = fix["replace_regex"]
                out = re.sub(str(rr["pattern"]), str(rr["replacement"]), out, flags=re.IGNORECASE)
        return out

خطوة ٥ (M5): الـ diff والـ loop

@dataclass
class Change:
    op: str
    text: str

def diff(draft, revised):
    a, b = draft.splitlines(), revised.splitlines()
    out = []
    for op, a1, a2, b1, b2 in difflib.SequenceMatcher(a=a, b=b).get_opcodes():
        if op == "delete":
            out += [Change("remove", l) for l in a[a1:a2]]
        elif op == "insert":
            out += [Change("add", l) for l in b[b1:b2]]
        elif op == "replace":                                  # سطر اتبدّل = اتشال + اتحط
            out += [Change("edit-removed", l) for l in a[a1:a2]]
            out += [Change("edit-added", l) for l in b[b1:b2]]
    return out

engine = Engine()
fixer = Fixer(engine.rules())
draft = "I cannot help with that question."
report = engine.evaluate(draft)
revised = fixer.apply(draft, report.violations())
print([v.rule_name for v in report.violations()])               # الجولة الأولى
print([v.rule_name for v in engine.evaluate(revised).violations()])  # الجولة التانية
print([(c.op, c.text[:30]) for c in diff(draft, revised)])

التمارين

  1. قاعدة «If this is urgent»: أي رد لازم يحتوي «If this is urgent» لما الـ prompt يتكلم عن safety. استخدم composition.
    تلميحالـ engine الحالي بيشوف الرد بس، فيا إما تمرّر الـ prompt مع النص (مثلًا evaluate(text, context) و predicate جديد prompt_contains_regex)، يا إما كبداية تخلي applies_when = contains_regex: '\bsafety\b' على الرد. والـ must: contains_regex: 'if this is urgent'. جربت النسخة البسيطة في المعمل ٣.
  2. Fixer بقوالب (templating): بدل الـ regex، fixer بياخد slots بأسماء. ورّي قاعدة واحدة متكتبة بالتصميم الجديد.
    تلميحمثلًا fix: {template: "{draft}\n\nNext step: {next_step}", slots: {next_step: "contact support"}} وتعمل template.format(draft=out.rstrip(), **slots). جرّبه على no-empty-refusal.
  3. Metrics endpoint: دالة بتاخد corpus مسودات وترجّع نسبة الـ violation لكل قاعدة عشان الفريق يشوف أنهي قاعدة over-firing.
    تلميحCounter لكل rule_name على status == "violation" مقسومة على عدد المسودات. احسب كمان نسبة not_applicable: قاعدة دايمًا not_applicable ممكن تكون ميتة. المعمل ٣ بيعمل بالظبط ده.
  4. إضافة مني · تمرين شغل حقيقي: اكتب دستور من ٤ قواعد لمساعد خدمة عملاء لشركة شحن تخيلية: (أ) أي رد فيه رقم شحنة لازم يكون فيه لينك تتبع، (ب) ممنوع وعود بمواعيد «guaranteed»، (ج) أي اعتذار لازم يكون معاه خطوة جاية، (د) مفيش أرقام تليفون شخصية. اعمل ٨ مسودات اختبار واطلع معدل الإطلاق.
    تلميح(ب) not_contains_regex: '\bguarantee(d)?\b' مع fix replace_regex لـ «expected». (أ) applies_when: contains_regex: '\b[A-Z]{2}\d{9}[A-Z]{2}\b' و must contains_regex: 'https?://'. اكتب الـ explanation بلغة يفهمها مدير خدمة العملاء.

إضافة مني: اللي الدرس ما قالوش

  • النطاق أوسع من المقصود: cite-when-asserting-fact بتدور على سطر بيبدأ بـ «According to»، بس الـ must بيدور على أي قوس في الرد كله. يعني لو فيه قوس في أي حتة تانية القاعدة هتعدّي. والـ fix بيزوّد «(citation pending)» في آخر الرد مش آخر السطر. جرّبها في المعمل ١. الدرس: القاعدة بتتحقق من اللي كتبته، مش من اللي قصدته، فاكتب لكل قاعدة test إيجابي وسلبي.
  • كلمة «example» جوه الإيميل نفسه: lee@example.com فيها example بحدود كلمة، فـ no-pii-in-examples بتنطبق على أي إيميل في دومين example.com حتى لو مفيش «مثال». حاجة زي دي بتطلع بس لما تبص على الـ matched span.
  • ترتيب الـ fixes مهم: الـ fixer بيمشي على الـ violations بالترتيب. لو fix بيزوّد نص فيه كلمة بتشغّل قاعدة تانية، الجولة التانية هتمسكها. عشان كده الجولة التانية مش رفاهية.
  • regex في الـ YAML: في YAML الـ single quotes بتحافظ على الـ \b زي ما هي، بس الـ double quotes بتفسّر الـ escapes. الدستور بيستخدم single quotes للـ regex و double quotes للنصوص اللي فيها \n. غلطة شائعة جدًا.
  • فين بيظهر في الـ LLMs؟ الاسم جاي من فكرة «Constitutional AI»: إن الموديل يتقيّم ويتصلح حسب مبادئ مكتوبة. الدرس هنا نسخة deterministic وقت التشغيل (runtime) من نفس الفكرة: draft → critique → revise. وفي الـ agents نفس النمط بيتطبق على الـ tool calls: قواعد زي «ممنوع أي DELETE من غير WHERE» قبل ما الـ agent ينفّذ.

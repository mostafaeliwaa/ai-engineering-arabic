01

المشكلة، والـ Chain Rule تاني بعمق

الـ neural network مش دالة بسيطة. هي مئات الدوال متركبة: matrix multiply، add bias، activation، matrix multiply تاني، softmax، cross-entropy. الخرج دالة في دالة في دالة. ولازم تعرف gradient الـ loss بالنسبة لكل weight.

  • بالإيد: مستحيل لملايين الـ parameters.
  • Numerical (finite differences): بطيء جدًا.
  • الـ chain rule (الرياضة) + الـ automatic differentiation (الـ algorithm): gradients مظبوطة لأي تركيبة دوال، في وقت قريب من forward pass واحد. ده اللي PyTorch وTensorFlow وJAX بيعملوه.
y = f(g(x)) ⇒ dy/dx = dy/dg · dg/dx = f′(g(x)) · g′(x)

مثال: y = sin(x²). جوه g = x² وg′ = 2x، وبرا f = sin(g) وf′ = cos(g)، يبقى dy/dx = cos(x²) · 2x.

y = f(g(h(x))) ⇒ dy/dx = f′(g(h(x))) · g′(h(x)) · h′(x)

كل layer في الشبكة حلقة في السلسلة دي، وكل حلقة بتساهم بالـ derivative المحلي بتاعها.

تشبيه: فكّر في تروس مترابطة. لو الترس الأول لف لفة، التاني بيلف 3 لفات، والتالت بيلف ضعف التاني. يبقى التالت بيلف 3 × 2 = 6 لفات لكل لفة من الأول. الـ chain rule هو بالظبط ضرب نسب التروس.
02

الـ Computational Graph: القيم لقدام، والـ gradients لورا

كل عملية بتبقى node. الداتا بتمشي forward في الـ graph، والـ gradients بترجع backward. مثال الدرس: y = relu(x1 · x2 + b) مع x1 = 2, x2 = 3, b = 1.

Forward: a = x1·x2 = 6 → c = a + b = 7 → y = relu(c) = 7 Backward: dy/dy = 1 → dy/dc = 1 (لأن c > 0) → dy/da = 1 ، dy/db = 1 → dy/dx1 = x2 = 3 ، dy/dx2 = x1 = 2

لاحظ القواعد المحلية: الـ جمع بيعدّي الـ gradient زي ما هو للاتنين. الـ ضرب بيدي كل طرف قيمة الطرف التاني مضروبة في الـ gradient اللي جاي. الـ relu بيعدّيه لو الدخل موجب، ويقفله (صفر) لو سالب.

معمل ١: امشي في الـ graph خطوة خطوة

دوس «خطوة forward» لحد ما الـ y تتحسب، وبعدين «خطوة backward» وشوف الـ gradient بيرجع node ورا node. الأزرق قيمة، والبرتقالي gradient.

غيّر الأرقام عشان c تبقى سالبة (مثلًا b = −10) وشوف الـ relu بيقفل كل الـ gradients: كلها بتبقى صفر. دي اسمها «dead ReLU».

03

Forward mode ضد Reverse mode

فيه طريقتين تطبق بيهم الـ chain rule على الـ graph:

الـ Modeالبذرة (seed)الاتجاهأحسن لما
Forwarddxᵢ/dxᵢ = 1من الدخل للخرجدخل قليل وخرج كتير
Reversedy/dy = 1من الخرج للدخلدخل كتير وخرج قليل (الـ neural nets)

على y = sin(x²) عند x = 2:

Forward: x = 2 (dx/dx = 1) → a = x² (da/dx = 2x = 4) → y = sin(a) (dy/dx = cos(4)·4 = −2.615) Reverse: y (dy/dy = 1) → a (dy/da = cos(4) = −0.654) → x (dy/dx = −0.654 · 4 = −2.615)

نفس الإجابة. الفرق في التكلفة: الشبكة فيها ملايين الدخل (الـ weights) وخرج واحد (الـ loss). الـ forward mode محتاج لفة لكل weight. الـ reverse محتاج لفة backward واحدة ويطلع كل الـ gradients. عشان كده الـ backpropagation هو reverse mode.

Dual numbers: طريقة أنيقة للـ forward mode

رقم dual شكله a + bε حيث ε² = 0. عمليًا هو زوج (قيمة، derivative):

(a, a′) + (b, b′) = (a + b, a′ + b′) (a, a′) · (b, b′) = (a·b, a′·b + a·b′) ← قاعدة الضرب sin(a, a′) = (sin a, cos a · a′)

ابدأ بالمتغير بـ derivative = 1، والـ derivative بيتحسب لوحده مع كل عملية.

معمل ٢: كام لفة محتاج؟

حرّك عدد الـ parameters. الـ forward mode محتاج لفة لكل parameter، والـ reverse لفة forward + لفة backward مهما كان العدد. (الـ numerical محتاج 2 forward لكل parameter.)

وتحت: آلة حاسبة بالـ dual numbers لـ sin(x²). غيّر x وشوف الزوج (قيمة، derivative) بيتنقل.

04

الـ Autograd engine محتاج ٣ حاجات

  1. Value wrapping: كل رقم جوه object شايل قيمته والـ gradient بتاعه.
  2. Graph recording: كل عملية بتسجل مين دخلها، ودالة صغيرة بتعرف تحسب الـ gradient المحلي.
  3. Backward pass: ترتيب topological للـ graph، وبعدين تمشي عليه بالعكس وتطبق الـ chain rule عند كل node.

الـ Topological sort: ليه الترتيب مهم؟

قبل ما node يبعت الـ gradient لولاده، لازم يكون استلم الـ gradient كامل من كل اللي بيستخدموه. الـ topological sort بيرتب الـ nodes بحيث كل node ييجي بعد كل اللي اعتمد عليهم. بنمشي عليه بالعكس، فكل node بيتعالج بعد ما كل الـ gradients بتاعته وصلت.

الـ += مش = (Gradient accumulation)

لو قيمة اتستخدمت في أكتر من عملية، الـ gradient بتاعها = مجموع كل المساهمات. لو كتبت = بدل += المساهمة الأخيرة هتمسح اللي قبلها.

معمل ٣: bug الـ = ضد +=

الدالة f = x·y + x. الـ x داخلة في عمليتين. الصح: df/dx = y + 1. بدّل بين الطريقتين وشوف الـ = بتضيّع مساهمة.

نفس الفكرة في PyTorch: الـ .grad بيتجمع عبر الندهات. عشان كده لازم optimizer.zero_grad() (أو p.grad = 0 في الكود بتاعنا) قبل كل backward، وإلا الـ gradients بتاعة الخطوة اللي فاتت هتتجمع على الجديدة.

PyTorch بيعمل إيه تحت الغطا؟

x = torch.tensor(2.0, requires_grad=True)
y = x ** 2 + 3 * x + 1
y.backward()
print(x.grad)     # 7.0 = 2*x + 3 = 2*2 + 3
  1. بيعمل node لـ x لأن requires_grad=True.
  2. كل عملية (** و* و+) بتعمل node جديد وبتسجل دالة الـ backward بتاعتها.
  3. y.backward() بيشغّل الـ reverse-mode على الـ graph المسجل.
  4. الـ grad_fn بتاع كل node بيحسب الـ gradients المحلية ويبعتها للآباء.
  5. الـ gradients بتتجمع في .grad بالجمع، مش بالاستبدال.

والـ graph dynamic (define-by-run): بيتبني من جديد في كل forward pass. عشان كده تقدر تحط if/else وloops جوه الموديل في PyTorch عادي.

خطوة ١: كلاس Value

class Value:
    def __init__(self, data, children=(), op=''):
        self.data = float(data)
        self.grad = 0.0                    # dL/d(هذه القيمة)، بيبدأ صفر
        self._backward = lambda: None      # هتتملي حسب العملية
        self._prev = set(children)         # مين عمل القيمة دي
        self._op = op

    def __repr__(self):
        return f"Value(data={self.data:.4f}, grad={self.grad:.4f})"

خطوة ٢: العمليات مع تسجيل الـ gradient

    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other), '+')
        def _backward():
            self.grad += out.grad          # الجمع بيعدّي الـ gradient زي ما هو
            other.grad += out.grad
        out._backward = _backward
        return out

    def __mul__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data * other.data, (self, other), '*')
        def _backward():
            self.grad += other.data * out.grad   # كل طرف ياخد قيمة التاني
            other.grad += self.data * out.grad
        out._backward = _backward
        return out

    def relu(self):
        out = Value(max(0, self.data), (self,), 'relu')
        def _backward():
            self.grad += (1.0 if out.data > 0 else 0.0) * out.grad
        out._backward = _backward
        return out

كل عملية بتعمل closure عارفة الـ gradient المحلي، وبتضربه في الـ gradient اللي جاي من فوق (out.grad). والـ += عشان القيمة ممكن تتستخدم أكتر من مرة.

خطوة ٣: الـ backward pass

    def backward(self):
        topo = []
        visited = set()
        def build_topo(v):                 # DFS: الولاد الأول وبعدين الأب
            if v not in visited:
                visited.add(v)
                for child in v._prev:
                    build_topo(child)
                topo.append(v)
        build_topo(self)

        self.grad = 1.0                    # البذرة: dy/dy = 1
        for v in reversed(topo):           # من الخرج للدخل
            v._backward()

خطوة ٤: باقي العمليات

    def __radd__(self, other): return self.__add__(other)    # 2 + v
    def __rmul__(self, other): return self.__mul__(other)    # 2 * v
    def __neg__(self):         return self * -1
    def __sub__(self, other):  return self + (-other)        # مبني من add + neg
    def __rsub__(self, other): return other + (-self)

    def __pow__(self, n):                                    # n ثابت مش Value
        out = Value(self.data ** n, (self,), f'**{n}')
        def _backward():
            self.grad += n * (self.data ** (n - 1)) * out.grad
        out._backward = _backward
        return out

    def __truediv__(self, other):                            # a / b = a * b**-1
        return self * (other ** -1) if isinstance(other, Value) else self * (Value(other) ** -1)

    def tanh(self):
        import math
        t = math.tanh(self.data)
        out = Value(t, (self,), 'tanh')
        def _backward():
            self.grad += (1 - t ** 2) * out.grad
        out._backward = _backward
        return out

    def exp(self):
        import math
        e = math.exp(self.data)
        out = Value(e, (self,), 'exp')
        def _backward():
            self.grad += e * out.grad          # exp مشتقتها هي نفسها
        out._backward = _backward
        return out

    def log(self):
        import math
        out = Value(math.log(self.data), (self,), 'log')
        def _backward():
            self.grad += (1.0 / self.data) * out.grad
        out._backward = _backward
        return out

خطوة ٦: MLP من الصفر

import random

class Neuron:
    def __init__(self, n_inputs):
        self.w = [Value(random.uniform(-1, 1)) for _ in range(n_inputs)]
        self.b = Value(0.0)
    def __call__(self, x):                   # tanh(w·x + b)
        act = sum((wi * xi for wi, xi in zip(self.w, x)), self.b)
        return act.tanh()
    def parameters(self):
        return self.w + [self.b]

class Layer:
    def __init__(self, n_inputs, n_outputs):
        self.neurons = [Neuron(n_inputs) for _ in range(n_outputs)]
    def __call__(self, x):
        return [n(x) for n in self.neurons]
    def parameters(self):
        return [p for n in self.neurons for p in n.parameters()]

class MLP:
    def __init__(self, sizes):               # [2, 4, 1]
        self.layers = [Layer(sizes[i], sizes[i + 1]) for i in range(len(sizes) - 1)]
    def __call__(self, x):
        for layer in self.layers:
            x = layer(x)
        return x[0] if len(x) == 1 else x
    def parameters(self):
        return [p for layer in self.layers for p in layer.parameters()]

خطوة ٧: درّبه على XOR

random.seed(42)
model = MLP([2, 4, 1])
xs = [[Value(0), Value(0)], [Value(0), Value(1)], [Value(1), Value(0)], [Value(1), Value(1)]]
ys = [-1.0, 1.0, 1.0, -1.0]

for step in range(100):
    preds = [model(x) for x in xs]                                     # ١. forward
    loss = sum((p + Value(-y)) ** 2 for p, y in zip(preds, ys))        # ٢. loss
    for p in model.parameters():
        p.grad = 0.0                                                   # ٣. صفّر!
    loss.backward()                                                    # ٤. backward
    for p in model.parameters():
        p.data -= 0.05 * p.grad                                        # ٥. حدّث
    if step % 20 == 0 or step == 99:
        print(f"  step {step:3d}  loss = {loss.data:.4f}")

for x, y in zip(xs, ys):
    print(f"  input=[{x[0].data:.0f},{x[1].data:.0f}]  target={y:+.0f}  pred={model(x).data:+.3f}")

خطوة ٨: Gradient checking

def gradient_check(build_expr, x_val, h=1e-7):
    x = Value(x_val)
    y = build_expr(x)
    y.backward()
    autodiff_grad = x.grad                                  # من الـ engine
    y_plus = build_expr(Value(x_val + h)).data
    y_minus = build_expr(Value(x_val - h)).data
    numerical_grad = (y_plus - y_minus) / (2 * h)           # من التعريف
    return autodiff_grad, numerical_grad, abs(autodiff_grad - numerical_grad)

ad, num, diff = gradient_check(lambda x: (x ** 3 + x * 2 + 1).tanh(), 0.5)
print(f"Autodiff:  {ad:.8f}")
print(f"Numerical: {num:.8f}")
print(f"Difference: {diff:.2e}")                            # لازم < 1e-5

التمارين

  1. ‎__pow__‎: اتأكد إن d/dx(x³) عند x = 2 = 12.
    تلميحالكلاس فيه __pow__ خلاص. اقرا الـ _backward بتاعها واتأكد إنها بتطبق n·xⁿ⁻¹ على الـ gradient الجاي. شغّل x = Value(2.0); y = x ** 3; y.backward(): لازم x.grad == 12.0.
  2. tanh: اتأكد إن tanh′(0) = 1 وtanh′(2) ≈ 0.0707.
    تلميحاستخدم 1 − tanh(x)² في الـ _backward، وقارن بـ (tanh(x+h) − tanh(x−h)) / 2h عند 0 و2. الرقم المظبوط عند 2 هو 0.07065.
  3. neuron كامل: y = relu(w1·x1 + w2·x2 + b). احسب الـ 5 gradients وقارن بـ PyTorch.
    تلميحقبل PyTorch اتأكد بإيدك: لو اللي داخل الـ relu موجب يبقى dy/dw1 = x1 وdy/dw2 = x2 وdy/dx1 = w1 وdy/dx2 = w2 وdy/db = 1. لو سالب، الخمسة = 0.
  4. Dual numbers: اعمل كلاس Dual للـ forward mode وتأكد إنه بيدي نفس derivatives الـ reverse mode.
    تلميحكل Dual فيه val وder. الضرب بقاعدة (a, a′)(b, b′) = (ab, a′b + ab′). ابدأ الدخل بـ der = 1 وقارن بـ x.grad لنفس الدالة. المعمل ٢ بيوريك الأرقام المتوقعة لـ sin(x²).
  5. إضافة مني · عملية جديدة زي شغل الـ frameworks: ضيف sigmoid() للـ Value بقاعدة σ′ = σ(1 − σ)، واكتب unit test بيعمل gradient_check عند 5 نقط مختلفة ويفشل لو أي فرق أكبر من 1e-5. ده بالظبط اللي بيحصل في PyTorch لما حد بيضيف operator جديد.
    تلميحاحسب s = 1 / (1 + math.exp(-self.data)) مرة واحدة واستخدمها جوه الـ closure. اختبر عند −5, −1, 0, 1, 5. عند الصفر لازم تطلع 0.25 بالظبط.
08

إضافة مني: اللي هيوجعك لو ما خدتش بالك

  • نسيت تصفّر الـ grads: أشهر bug. الـ loss بيتصرف غريب لأن كل خطوة بتاخد مجموع كل الـ gradients اللي فاتت. في PyTorch: optimizer.zero_grad() قبل loss.backward().
  • الـ graph بيستهلك ميموري: كل Value بيشيل أولاده لحد ما الـ backward يخلص. عشان كده الـ training أتقل في الميموري من الـ inference بكتير، وعشان كده فيه torch.no_grad() للـ inference: مش بيسجل graph خالص.
  • الـ engine بتاعنا scalar: كل رقم Value لوحده، فبطيء جدًا. PyTorch نفس الفكرة بالظبط بس كل node فيه tensor كامل، والـ backward بتاع الـ matmul بيستخدم الـ transpose (يوم ٢ ويوم ٤).
  • في الـ LLMs: الـ fine-tuning بالـ LoRA بيعتمد على إن الـ autograd بيحسب gradients للـ parameters اللي requires_grad=True بس، والباقي متجمد. وتقنية زي gradient checkpointing بتمسح قيم من الـ graph في الـ forward وترجع تحسبها في الـ backward عشان توفّر ميموري لما تدرّب موديلات كبيرة.

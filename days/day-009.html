المفاجأة (Information Content) والـ Entropy

تخيل صاحبك بعتلك رسالة «الشمس طلعت النهاردة». ولا معلومة، كنت عارف. لكن لو بعتلك «كسبت اليانصيب» دي مفاجأة ضخمة. يعني: كل ما الحدث يكون نادر، كل ما يشيل معلومات أكتر.

I(x) = −log p(x)

لو استخدمت log أساس 2 الوحدة اسمها bits، ولو استخدمت الـ ln (أساس e) اسمها nats. نفس الفكرة، وحدة مختلفة، زي متر وقدم.

الـ Entropy = متوسط المفاجأة

بدل ما نسأل عن حدث واحد، نسأل: في المتوسط، التوزيع ده بيفاجئني قد إيه؟

H(P) = −Σ p(x) · log p(x)

العملة العادلة أعلى entropy لمتغير بقيمتين: 1 bit. العملة المغشوشة (99% صورة) entropy بتاعتها 0.08 bit بس، لأنك عارف تقريبًا هيحصل إيه، فكل رمية مش بتقولك حاجة جديدة.

الـ entropy هي عدم اليقين اللي مينفعش تتخلص منه. ومينفعش تضغط الداتا لأقل منها (ده الـ limit بتاع أي zip).

الـ Cross-Entropy والـ KL Divergence

الـ Cross-Entropy: الحقيقة جاية من توزيع P، بس انت (أو الموديل) فاكرها جاية من Q. متوسط المفاجأة اللي هتحس بيها؟

H(P, Q) = −Σ p(x) · log q(x)

تشبيه: واحد مصري راح لندن ومتوقع الجو مشمس (Q). كل يوم المطر بيفاجئه أكتر من اللي عايش هناك وعارف (P). الفرق ده هو التمن اللي بيدفعه عشان توقعه غلط.

لو Q = P بالظبط، الـ cross-entropy = الـ entropy. أي اختلاف بيكبّرها.

في الـ classification الـ label الحقيقي one-hot (الكلاس الصح احتماله 1 والباقي 0)، فالمعادلة كلها بتختصر لـ:

H(P, Q) = −log q(true_class)

دي كل الـ cross-entropy loss: ارفع احتمال الكلاس الصح.

الـ KL Divergence: الزيادة اللي ملهاش لازمة

D_KL(P‖Q) = Σ p(x) · log(p(x)/q(x)) = H(P,Q) − H(P)

يعني cross-entropy = entropy + KL. والـ entropy بتاعة الـ labels الحقيقية ثابتة أثناء التدريب، فلما تنزّل الـ cross-entropy انت فعليًا بتنزّل الـ KL: بتزق توزيع الموديل ناحية الحقيقة.

خلي بالك: الـ KL مش متماثل: D_KL(P‖Q) ≠ D_KL(Q‖P)، فهو مش «مسافة» حقيقية.

جرب بإيدك: اسحب أعمدة الموديل Q (البرتقالي) لفوق ولتحت. الأزرق هو الحقيقة P. شوف الـ KL بيوصل صفر لما تطابقهم، ولاحظ إن الاتجاهين بتوع الـ KL مختلفين.

Joint و Conditional Entropy و Mutual Information

الـ Joint Entropy H(X,Y): عدم اليقين في الاتنين مع بعض.

H(X,Y) = −Σ Σ p(x,y) · log p(x,y) ≤ H(X) + H(Y)

بتتساوى لما يكونوا مستقلين. لو بينهم معلومة مشتركة، الـ joint بيبقى أقل من المجموع، والفرق ده بالظبط هو الـ mutual information.

الـ Conditional Entropy H(Y|X): عدم اليقين اللي فاضل في Y بعد ما شفت X.

H(Y|X) = H(X,Y) − H(X) 0 ≤ H(Y|X) ≤ H(Y)
  • لو X بيحدد Y تمامًا (درجة الحرارة بالـ Celsius وبالـ Fahrenheit) ⇐ H(Y|X) = 0.
  • لو X مالوش علاقة بـ Y (رمية عملة وطقس بكرة) ⇐ H(Y|X) = H(Y).

الـ decision trees بتستخدم ده: في كل split بتختار الـ feature اللي يقلل H(Y|X) أكتر حاجة.

الـ Mutual Information I(X;Y): معرفتك بواحد بتقلل عدم يقينك في التاني قد إيه.

I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X) = H(X) + H(Y) − H(X,Y) = Σ Σ p(x,y) · log( p(x,y) / (p(x)·p(y)) )

خواصها: دايمًا ≥ 0، بتساوي صفر بس لو مستقلين، متماثلة I(X;Y)=I(Y;X) (عكس الـ KL)، وI(X;X) = H(X).

جرب بإيدك: حرّك «قد إيه X وY متفقين». المصفوفة [[a, b], [b, a]] بتتغير، والأعمدة بتوريك العلاقات. عند 0.5 هما مستقلين، وعند 0.9 هي نفس مصفوفة الدرس «dependent».

الـ Softmax والـ Label Smoothing والـ Perplexity

الموديل بيطلّع أرقام خام اسمها logits. الـ softmax بيعمل لها exp ويقسم على المجموع، فتطلع توزيع احتمالات صحيح.

ليه الـ cross-entropy هي الـ loss بتاعة الـ classification؟ ٣ زوايا ونفس النتيجة

  1. نظرية المعلومات: بتقيس كام bit بتضيّعها لما تستخدم توزيع الموديل بدل الحقيقي. تقليلها = الموديل يبقى أكفأ «encoder» للواقع.
  2. Maximum likelihood: الـ likelihood = ∏ q(y_i)، الـ log بتاعه = Σ log q(y_i)، وسالبه −Σ log q(y_i) هو بالظبط الـ cross-entropy. يعني تقليل الـ CE = تعظيم احتمال الداتا تحت الموديل.
  3. الـ gradient: مشتقة الـ CE بالنسبة للـ logits هي ببساطة (predicted − true). نضيفة، مستقرة، وسريعة، وده سبب إنها ماشية مع الـ softmax زي السمنة على العسل.

Label Smoothing

بدل الـ target الحاد [0, 0, 1, 0] نستخدم target ناعم:

soft = (1 − ε) · hard + ε / num_classes

مع ε = 0.1 و٤ كلاسات: [0.025, 0.025, 0.925, 0.025]. الـ one-hot الـ entropy بتاعه صفر، والناعم entropy بتاعه موجبة. الفايدة:

  • بيمنع الموديل يزق الـ logits لقيم متطرفة (عشان تطابق one-hot بالظبط محتاج logit لا نهائي).
  • regularization: الموديل ميقدرش يبقى واثق ١٠٠٪.
  • calibration أحسن: الاحتمالات بتعبر عن عدم اليقين الحقيقي.
  • بيقلل الفرق بين سلوك التدريب والـ inference.
L = (1 − ε) · CE(hard, pred) + ε · H_uniform(pred)

الحد التاني بيعاقب التوقعات البعيدة عن الـ uniform، يعني regularization مباشر على الثقة.

Bits ولا Nats؟ والـ Perplexity

الفرق الوحيد أساس الـ log: 2 ⇐ bits، e ⇐ nats (عرف الـ ML)، 10 ⇐ hartleys (نادر). 1 nat = 1/ln(2) = 1.4427 bits. PyTorch وTensorFlow بيستخدموا nats افتراضيًا.

Perplexity = 2^H(P,Q) (bits) = e^H(P,Q) (nats)

الـ perplexity = «عدد الاختيارات المتساوية اللي الموديل محتار بينهم». perplexity 50 يعني كأنه بيختار عشوائي من 50 token في كل خطوة. أقل = أحسن. حسب الدرس: GPT-2 وصل لحوالي 30 على benchmarks مشهورة، والموديلات الحديثة بقت رقم واحد في المجالات المغطاة كويس.

import math

def information_content(p, base=2):
    if p <= 0 or p > 1:
        return float('inf') if p <= 0 else 0.0
    return -math.log(p) / math.log(base)     # -log p، بأي أساس

def entropy(probs, base=2):                  # متوسط المفاجأة
    return sum(
        p * information_content(p, base)
        for p in probs if p > 0                # 0·log0 = 0، فبنتجاهلها
    )

biased_coin = [0.99, 0.01]
fair_die = [1/6] * 6

خطوة ٢: الـ cross-entropy والـ KL

def cross_entropy(p, q, base=2):
    total = 0.0
    for pi, qi in zip(p, q):
        if pi > 0:
            if qi <= 0:
                return float('inf')          # الموديل قال مستحيل والحقيقة حصلت!
            total += pi * (-math.log(qi) / math.log(base))
    return total

def kl_divergence(p, q, base=2):             # CE - H
    return cross_entropy(p, q, base) - entropy(p, base)

true_dist = [0.7, 0.2, 0.1]

خطوة ٣: الـ cross-entropy كـ loss للـ classification

def softmax(logits):
    max_logit = max(logits)                  # نطرح الأكبر عشان الـ exp ميعملش overflow
    exps = [math.exp(z - max_logit) for z in logits]
    total = sum(exps)
    return [e / total for e in exps]

def cross_entropy_loss(true_class, logits):  # -log احتمال الكلاس الصح
    probs = softmax(logits)
    return -math.log(probs[true_class])

خطوة ٤: الـ cross-entropy = negative log-likelihood

import random

random.seed(42)

n_samples = 1000
n_classes = 3
true_labels = [random.randint(0, n_classes - 1) for _ in range(n_samples)]
model_logits = [[random.gauss(0, 1) for _ in range(n_classes)] for _ in range(n_samples)]

ce_loss = sum(                                # متوسط الـ CE على الداتا
    cross_entropy_loss(label, logits)
    for label, logits in zip(true_labels, model_logits)
) / n_samples

nll = -sum(                                   # سالب متوسط log-likelihood
    math.log(softmax(logits)[label])
    for label, logits in zip(true_labels, model_logits)
) / n_samples

print(f"Cross-entropy loss:      {ce_loss:.6f}")
print(f"Negative log-likelihood: {nll:.6f}")
print(f"Difference:              {abs(ce_loss - nll):.2e}")

خطوة ٥: الـ mutual information

def mutual_information(joint_probs, base=2):
    rows = len(joint_probs)
    cols = len(joint_probs[0])

    # الـ marginals: اجمع الصفوف والأعمدة
    margin_x = [sum(joint_probs[i][j] for j in range(cols)) for i in range(rows)]
    margin_y = [sum(joint_probs[i][j] for i in range(rows)) for j in range(cols)]

    mi = 0.0
    for i in range(rows):
        for j in range(cols):
            pxy = joint_probs[i][j]
            if pxy > 0:
                mi += pxy * math.log(pxy / (margin_x[i] * margin_y[j])) / math.log(base)
    return mi

independent = [[0.25, 0.25], [0.25, 0.25]]
dependent = [[0.45, 0.05], [0.05, 0.45]]

print(f"MI (independent): {mutual_information(independent):.4f} bits")

خطوة ٦: نفس الكلام بـ NumPy (بالـ nats)

import numpy as np

def np_entropy(p):
    p = np.asarray(p, dtype=float)
    mask = p > 0                              # نتجنب log(0)
    result = np.zeros_like(p)
    result[mask] = p[mask] * np.log(p[mask])
    return -result.sum()

def np_cross_entropy(p, q):
    p, q = np.asarray(p, dtype=float), np.asarray(q, dtype=float)
    mask = p > 0
    return -(p[mask] * np.log(q[mask])).sum()

def np_kl_divergence(p, q):
    return np_cross_entropy(p, q) - np_entropy(p)

true = np.array([0.7, 0.2, 0.1])
pred = np.array([0.6, 0.25, 0.15])
print(f"Entropy:    {np_entropy(true):.4f} nats")
print(f"Cross-ent:  {np_cross_entropy(true, pred):.4f} nats")
print(f"KL div:     {np_kl_divergence(true, pred):.4f} nats")

التمارين

  1. Entropy الحروف الإنجليزي: احسبها لو الـ ٢٦ حرف بنفس الاحتمال، وبعدين بتكرارات الحروف الحقيقية. أنهي أعلى وليه؟
    تلميح / إجابةنادي entropy([1/26]*26)، لازم تطلع log₂ 26 ≈ 4.70 bits. التكرارات الحقيقية مش متساوية (حروف زي e وt بتتكرر أكتر)، فالـ entropy لازم تطلع أقل. الـ uniform هو أعلى entropy ممكنة لعدد ثابت من النتائج.
  2. Loss بالإيد: موديل طلّع logits [5.0, 2.0, 0.5] والكلاس الصح 1. احسب الـ CE بالإيد واتأكد بالدالة. إيه الـ logits اللي تدي loss صفر؟
    تلميح / إجابةsoftmax الأول، وبعدين −ln الاحتمال في index 1. لازم تطلع حوالي 3.06. الـ loss بتقرب من صفر بس لما logit الكلاس 1 يبقى أكبر بكتير من الاتنين التانيين (مش بتوصل صفر بالظبط إلا في الـ limit). جربها في معمل ٠٤.
  3. الـ KL مش متماثل: اختار P وQ واحسب الاتجاهين.
    تلميح / إجابةجرب P = [0.9, 0.1] وQ = [0.5, 0.5]. هيطلعوا تقريبًا KL(P‖Q) ≈ 0.531 وKL(Q‖P) ≈ 0.737 bits. مختلفين لأن كل اتجاه بيوزن الـ log ratio بتوزيع مختلف (اللي قدام الـ ‖ هو اللي بيوزن).
  4. Perplexity لجملة: دالة تاخد list من (true_token_index, predicted_logits) وترجع الـ perplexity.
    تلميح / إجابةلكل زوج احسب cross_entropy_loss، خد المتوسط، وابعته لـ perplexity (يعني math.exp). اختبار: logits متساوية على V tokens لازم تدي perplexity = V بالظبط.
  5. إضافة مني · فلتر ثقة لـ RAG/agent: انت عامل classifier بيوجّه سؤال اليوزر لواحد من ٤ tools (search، calculator، calendar، chat). اكتب دالة route(logits, threshold) ترجع اسم الـ tool لو الـ entropy بتاعة الـ softmax أقل من threshold، وإلا ترجع "ask_user" عشان يوضح. جرب logits [4, 0, 0, 0] و[1, 1, 0.9, 1].
    تلميحأقصى entropy لـ ٤ اختيارات = log₂ 4 = 2 bits. ابدأ بـ threshold زي 1.0 bit. الأولى entropy صغيرة (واثق ⇐ search)، والتانية قريبة من 2 (محتار ⇐ ask_user). ده نفس المنطق اللي بيستخدموه عشان يقرروا امتى الـ agent يسأل بدل ما يخمّن.
07

إضافة مني: اللي الدرس ما قالهوش صريح

الحدس في جملة

الـ entropy = «قد إيه الدنيا فوضى». الـ cross-entropy = «قد إيه أنا متفاجئ لأن توقعاتي غلط». الـ KL = «الفرق بين الاتنين، يعني تمن غلطي بس». الـ MI = «قد إيه معلومة واحدة بتقصّر عليا الطريق للتانية».

أخطاء شائعة

  • تطبيق softmax مرتين: nn.CrossEntropyLoss في PyTorch بياخد logits خام وبيعمل الـ softmax جواه. لو عملت softmax قبله النتيجة بتبقى غلط والتدريب بيبقى أبطأ.
  • log(0): لو الموديل إدى احتمال صفر لحاجة حصلت، الـ CE = ما لا نهاية. عشان كده الدالة بترجع inf، وعشان كده الكود الحقيقي بيشتغل على الـ logits (log-softmax) مش على الاحتمالات.
  • خلط bits وnats: رقم الـ loss في PyTorch بالـ nats. لو قارنته برقم بالـ bits هتتلخبط (اضرب في 1.4427 للتحويل لـ bits).
  • مقارنة perplexity بين tokenizers مختلفة: الـ perplexity لكل token، فموديلين بـ vocab مختلف ومش بيقسموا النص بنفس الطريقة أرقامهم مش قابلة للمقارنة المباشرة.
  • عكس اتجاه الـ KL: لأنه مش متماثل، لازم تعرف مين P ومين Q في الكود اللي بتستخدمه.

بيظهر فين في الـ LLMs والـ Agents

  • Pretraining: كل LLM بيتدرب على cross-entropy للـ next token. الـ loss اللي بتشوفها في الـ logs هي بالظبط ده.
  • RLHF / الـ fine-tuning بالـ RL: فيه عادةً عقوبة KL بين الموديل الجديد والموديل المرجعي عشان ميبعدش أوي عنه.
  • Distillation: الطالب بيتعلم يقلل الـ KL بينه وبين توزيع المدرّس.
  • Sampling: الـ temperature بتغير الـ entropy بتاعة توزيع الـ next token: حرارة أعلى ⇐ entropy أعلى ⇐ كلام أكثر تنوعًا.
  • Agents: الـ entropy بتاعة توقعات الموديل ممكن تستخدمها كإشارة ثقة (زي تمرين ٥).

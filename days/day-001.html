المتجه: قايمة أرقام ليها معنى

المتجه ببساطة قايمة أرقام زي [3, 2]. الأرقام دي إحداثيات: امشي ٣ يمين و٢ فوق. السهم من نقطة الصفر لحد هناك هو المتجه.

طوله (magnitude) بنحسبه بفيثاغورس:

|a| = √(3² + 2²) = √13 ≈ 3.61

في الـ AI كل حاجة بتتحول لمتجه: الكلمة بتبقى متجه من 768 رقم بيمثل معناها، والصورة متجه من ملايين البيكسلز، واليوزر متجه من تفضيلاته.

جرب بإيدك: اسحب راس السهم الأزرق a والبرتقالي b. لاحظ الـ dot product بيبقى موجب لما يقربوا، صفر لما يبقوا متعامدين، وسالب لما يبقوا عكس بعض.

الـ Dot Product: مقياس التشابه

اضرب كل رقمين في نفس المكان واجمعهم. بس كده.

a · b = a₁b₁ + a₂b₂ + … + aₙbₙ
النتيجةالمعنىفي الـ AI
a·b > 0نفس الاتجاه → متشابهينكلمتين معناهم قريب
a·b = 0متعامدين → ملهمش علاقةموضوعين مختلفين تمامًا
a·b < 0عكس بعضمعنى مضاد

المشكلة إن الـ dot product بيكبر لو المتجهات طويلة. عشان كده بنقسم على الأطوال ونطلع الـ cosine similarity اللي دايمًا بين -1 و1:

cos θ = (a · b) / (|a| · |b|)

معمل: محرك بحث صغير بالـ embeddings

دي كلمات حطيتها كمتجهات في بُعدين (الحقيقي بيبقى مئات الأبعاد، بس الفكرة واحدة). اختار كلمة، وشوف الكلمات مترتبة حسب الـ cosine similarity.

ده بالظبط اللي بيحصل في الـ RAG لما بيدور على أقرب documents لسؤالك.

    المصفوفة: آلة بتحرك الفضاء

    المصفوفة مش جدول أرقام وخلاص. هي تحويل: بتاخد أي متجه وتطلّع متجه تاني. ممكن تلف، تمط، تميّل، أو تكبس الفضاء كله على خط.

    السر: العمود الأول في المصفوفة هو المكان اللي بيروحله السهم î = [1,0]، والعمود التاني مكان ĵ = [0,1]. أي حاجة تانية بتتبعهم.

    [[0, −1], [1, 0]] · [3, 1] = [−1, 3] ← لفة 90°
    ليه ده مهم؟ كل layer في الـ neural network هي حرفيًا y = W·x. الـ weights دي مصفوفة، والتدريب كله عبارة عن تعديل الأرقام دي لحد ما التحويل يبقى مفيد.

    الـ Rank: عدد الاتجاهات المستقلة اللي المصفوفة بتحافظ عليها. جرب زرار «Rank 1» وشوف الشبكة كلها بتتكبس على خط: معلومات ضاعت ومستحيل ترجعها، يعني المصفوفة ملهاش inverse.

    الاستقلال الخطي والإسقاط و Gram-Schmidt

    الاستقلال الخطي (Linear Independence)

    مجموعة متجهات مستقلة لو مفيش واحد فيهم تقدر تعمله من الباقيين. مثال:

    v1=[1,0,0] v2=[0,1,0] v3=[2,1,0] = 2·v1 + v2

    عندك ٣ متجهات في فضاء ٣ أبعاد، بس كلهم نايمين في مستوى xy. مستحيل توصل لـ [0,0,1]. يعني فعليًا عندك بُعدين بس.

    في الداتا: لو عندك feature_3 = 2×feature_1 + feature_2، الفيتشر التالت مش بيضيف أي معلومة، وكمان بيبوّظ الـ regression (اسمها multicollinearity): الأوزان بتبقى مش مستقرة وأي تغيير صغير بيقلب النتيجة.

    الإسقاط (Projection): ضل المتجه

    إسقاط a على b هو «الجزء من a اللي ماشي في اتجاه b». تخيل شمس فوق b بالظبط، والضل اللي a بيعمله على b هو الإسقاط. رجع للمعمل ٠١ وفعّل «ورّيني الإسقاط» وانت بتحرك.

    proj_b(a) = ((a·b) / (b·b)) · b

    والباقي a − proj بيبقى عمودي على b دايمًا. الـ Linear Regression نفسها عبارة عن إسقاط، والـ PCA إسقاط على أهم الاتجاهات.

    Gram-Schmidt: نضّف الاتجاهات

    عندك متجهات مستقلة بس مايلة على بعض. عايز تحولهم لمحاور نضيفة: كل واحد طوله ١ وعمودي على الباقي (orthonormal). الطريقة:

    1. خد أول متجه وخلّي طوله ١.
    2. خد التاني، اطرح منه ضله على الأول، وخلّي طوله ١.
    3. خد التالت، اطرح ضله على كل اللي قبله، وخلّي طوله ١. وهكذا.

    ده اللي جوه QR decomposition اللي NumPy بيستخدمها في حل المعادلات والـ least squares.

    خطوة ١: كلاس Vector

    class Vector:
    def __init__(self, components):
        self.components = list(components)
        self.dim = len(self.components)

    def __add__(self, other):          # جمع خانة بخانة
        return Vector([a + b for a, b in zip(self.components, other.components)])

    def __sub__(self, other):
        return Vector([a - b for a, b in zip(self.components, other.components)])

    def dot(self, other):              # اضرب واجمع
        return sum(a * b for a, b in zip(self.components, other.components))

    def magnitude(self):               # فيثاغورس
        return sum(x**2 for x in self.components) ** 0.5

    def normalize(self):               # نفس الاتجاه، طول = 1
        mag = self.magnitude()
        return Vector([x / mag for x in self.components])

    def cosine_similarity(self, other):
        return self.dot(other) / (self.magnitude() * other.magnitude())

    def __repr__(self):
        return f"Vector({self.components})"

a = Vector([1, 2, 3]); b = Vector([4, 5, 6])
print(a + b, a.dot(b), round(a.cosine_similarity(b), 4))

    خطوة ٢: Matrix × Vector = Neural Network Layer

    class Matrix:
    def __init__(self, rows):
        self.rows = [list(r) for r in rows]
        self.shape = (len(self.rows), len(self.rows[0]))

    def __matmul__(self, v):           # كل صف dot مع المتجه
        return Vector([
            sum(self.rows[i][j] * v.components[j] for j in range(self.shape[1]))
            for i in range(self.shape[0])
        ])

rotation_90 = Matrix([[0, -1], [1, 0]])
print(rotation_90 @ Vector([3, 1]))     # Vector([-1, 3])

import random
random.seed(42)
W = Matrix([[random.gauss(0, 0.1) for _ in range(3)] for _ in range(2)])
x = Vector([1.0, 0.5, -0.3])
print(W @ x)   # 3D دخل → 2D طلع: ده layer كامل

    خطوة ٣: الإسقاط و Gram-Schmidt

    def project(a, b):
    s = a.dot(b) / b.dot(b)
    return Vector([s * x for x in b.components])

def gram_schmidt(vectors):
    basis = []
    for v in vectors:
        w = v
        for u in basis:
            w = w - project(w, u)      # شيل الضل
        if w.magnitude() < 1e-10:      # متجه مش مستقل، اتجاهله
            continue
        basis.append(w.normalize())
    return basis

for u in gram_schmidt([Vector([1,1,0]), Vector([1,0,1]), Vector([0,1,1])]):
    print(u, round(u.magnitude(), 6))

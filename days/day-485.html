تسخين ٥ دقايق: افتكر الـ Scheduler

امبارح بنيت الـ Iteration Scheduler: طابور hypotheses بيغذّي slots شغالة بالتوازي، وكل نتيجة بترجع على الـ result bus وتحدّث درجة الـ UCB بتاعة الـ branch. النهاردة الـ report اللي بيطلّعه هو أول حاجة الديمو هيقراها. جاوب في دماغك الأول وبعدين افتح الإجابة:

١. الـ UCB بيدي درجة كام لـ branch عمره ما اتجرّب؟ وليه؟بيديله +inf، فأي branch جديد بيتجرّب الأول. ده بيضمن الاستكشاف (exploration) قبل ما نلزق في الـ leader.
٢. إمتى الـ scheduler بيطلّع paper.trigger؟لما متوسط الـ reward بتاع branch يعدّي paper_threshold (افتراضيًا 0.7) والـ branch ده لسه ما طلّعش ورقة قبل كده.
٣. إيه قيم stop_reason الممكنة؟queue_empty (الطابور خلص ومفيش حاجة شغالة)، max_experiments (عدد التجارب خلص)، وdeadline (الوقت خلص).

01

إيه اللي بيتركب هنا؟ ست مراحل

فكّر في الديمو زي خط إنتاج في مصنع: كل ماكينة اتصنعت واتجربت لوحدها في درس، والنهاردة بتحطهم جنب بعض على سير واحد. لو مقاس الحتة اللي طالعة من ماكينة مش مظبوط على الماكينة اللي بعدها، السير هيقف هنا بالظبط.

Seed → Scheduler ⇄ Experiment runner → Result bus → Paper trigger → Best picker → Critic loop → Paper writer → Demo report
  1. Seed: ليستة فيها ٣ hypotheses، واحدة لكل branch: alpha وbeta وgamma.
  2. Scheduler: بيشغّل ٦ تجارب على الـ branches دي بـ ٣ slots بالتوازي.
  3. Result bus: بيرجّع النتايج للـ scheduler، وبيطلّع paper trigger واحد أو أكتر.
  4. Best-result picker: بيختار أحسن نتيجة واحدة بس.
  5. Critic loop: بيلف على مسودة مبنية من النتيجة دي لحد ما توصل للهدف.
  6. Paper writer: بيطلّع الـ LaTeX والـ BibTeX والـ manifest النهائي.

أهداف الدرس بالترتيب: توصّل اللوب كله من الأول للآخر، تركّب الـ primitives بـ imports عادية مش framework، تشغّله لحد ما يقف لوحده ويطلّع تقرير واحد، تخليه deterministic عشان الـ tests تقدر تتأكد من شكل الناتج، وتخلي أي عقد يتكسر يطلّع خطأ واضح بدل ما المرحلة اللي بعده تشتغل على input بايظ.

def _load_module(name, file_path):
    # حمّل main.py بالمسار تحت اسم فريد عشان مفيش تصادم
    spec = importlib.util.spec_from_file_location(name, file_path)
    if spec is None or spec.loader is None:
        raise ImportError(f"cannot load {name} from {file_path}")
    mod = importlib.util.module_from_spec(spec)
    sys.modules[name] = mod
    spec.loader.exec_module(mod)
    return mod

Milestone 3: الـ picker والـ MiniPaper

MiniPaper = critic_loop_mod.MiniPaper
MiniSection = critic_loop_mod.MiniSection

def pick_best_branch(scheduler_report):
    if not scheduler_report.paper_triggers:
        raise NoTriggerError("no branch crossed the paper threshold")
    by_branch = {b.branch: b for b in scheduler_report.branches}
    triggered = [by_branch[n] for n in scheduler_report.paper_triggers if n in by_branch]
    if not triggered:                         # trigger لـ branch مش موجود
        raise BestResultError("trigger list empty after lookup")
    triggered.sort(key=lambda b: (-b.mean, b.branch))   # أعلى متوسط، والتعادل أبجدي
    best = triggered[0]
    return best.branch, best.mean

def _originality_for_reward(reward):
    if reward >= 0.8: return "high"
    if reward >= 0.6: return "medium"
    return "low"

def build_mini_paper(branch, reward):
    return MiniPaper(
        title=f"Auto-Research Findings on Branch {branch}",
        abstract=f"We summarise the best yielding branch {branch} from the auto-research loop.",
        sections=[
            MiniSection(id="intro", title="Introduction", body="initial observations"),
            MiniSection(id="results", title="Results", body=""),
        ],
        originality_tag=_originality_for_reward(reward),
    )

def mini_to_full_paper(mini, branch):
    cites = []
    for sec in mini.sections:                  # اتحاد كل الـ cites بدون تكرار
        for c in sec.cites:
            if c not in cites:
                cites.append(c)
    bib = [BibEntry(key=k, entry_type="article",
                    fields={"title": f"Source {k}", "author": "Synthesised", "year": "2026"})
           for k in cites]
    if not bib:                                # مفيش مراجع؟ ضيف baseline
        bib = [BibEntry(key=f"{branch}-baseline", entry_type="article",
                        fields={"title": "Baseline", "author": "Synthesised", "year": "2026"})]
        for sec in mini.sections:
            if sec.id == "intro":
                sec.cites.append(f"{branch}-baseline")
                break
    fig = Figure(id=f"{branch}-results", path=f"figs/{branch}.pdf",
                 caption=f"Reward trajectory on branch {branch}")
    sections = [Section(id=s.id, title=s.title, body=s.body, cites=list(s.cites),
                        figure_refs=[fig.id] if s.id == "results" else [])
                for s in mini.sections]
    return Paper(title=mini.title, authors=["Auto-Research Demo"], abstract=mini.abstract,
                 sections=sections, figures=[fig], bibliography=bib)

Milestone 5: وصّل كله في run_demo

import asyncio, tempfile

async def _run_demo_async(out_dir, seed=11):
    seed_list = make_seed_hypotheses()
    if not seed_list:
        raise BestResultError("seed list is empty")
    runner = scheduler_mod.make_deterministic_runner(
        base_rewards={"alpha": 0.82, "beta": 0.55, "gamma": 0.15},
        noise=0.04, delay_ms=2.0, seed=seed)
    sched = scheduler_mod.IterationScheduler(
        runner=runner, slots=3, max_experiments=6,
        paper_threshold=0.7, prune_floor=0.2, prune_after_runs=3,
        expander=scheduler_mod.deterministic_expander)
    sched_report = await sched.run(seed_list)            # مرحلة ١

    branch, reward = pick_best_branch(sched_report)      # مرحلة ٢ (ممكن ترمي)

    loop = critic_loop_mod.CriticLoop(                    # مرحلة ٣
        critic=critic_loop_mod.deterministic_critic,
        reviser=critic_loop_mod.deterministic_reviser,
        max_rounds=6, target_score=8.0)
    critic_result = loop.run(build_mini_paper(branch, reward))

    full_paper = mini_to_full_paper(critic_result.paper, branch)   # مرحلة ٤
    prose = paper_writer_mod.MockProseGenerator(outlines={
        "intro": f"motivation for branch {branch}",
        "results": f"summary of reward trajectory on branch {branch}",
        "method": "method description",
        "related-work": "related work survey"})
    manifest = paper_writer_mod.PaperWriter(prose=prose).write(full_paper, out_dir)

    return DemoReport(scheduler_report=sched_report.to_dict(), best_branch=branch,
                      best_reward=reward, critic_result=critic_result.to_dict(),
                      paper_manifest=manifest, stop_reason=sched_report.stop_reason)

def run_demo(out_dir=None, seed=11):
    if out_dir is None:
        out_dir = tempfile.mkdtemp(prefix="auto-research-demo-")
    return asyncio.run(_run_demo_async(out_dir, seed=seed))

خطوات أبعد من الدرس

الدرس بيقترح ٣ امتدادات تعملهم بعد ما الديمو يبقى أخضر:

  1. Persistent state: كل مرحلة تكتب ناتجها في JSON store صغير، فلو حصل restart تكمّل من غير ما تعيد المراحل الرخيصة.
  2. Dashboard: الـ trace events من الـ scheduler والـ critic loop تتعرض كـ timeline واحد.
  3. Real model calls: بدّل الـ mocked prose generator والـ deterministic critic بحاجات شغالة بموديل. الـ wiring مش بيتغير.

الفكرة الأساسية: التركيب هو الـ architecture. خمس دروس، أربع imports، تقرير واحد. وكل ما تضيف مرحلة، الـ wiring بيكبر سطر واحد بس.

التمارين

الدرس ما فيهوش تمارين مرقّمة، فالتمارين دي مبنية على الـ tests والامتدادات اللي في الدرس نفسه:

  1. اكسر الـ trigger: غيّر base_rewards بحيث مفيش branch يعدّي 0.7، وشغّل. إيه اللي بيحصل؟
    الإجابةNoTriggerError بيطلع من pick_best_branch، والـ critic والـ writer ما بيشتغلوش خالص. ده المقصود بالـ short-circuit.
  2. كسر التعادل: اعمل SchedulerReport فيه BranchStats لـ beta و alpha بنفس runs=2, reward_sum=1.6. مين بيكسب؟
    الإجابةalpha، لأن الـ sort key هو (-mean, branch) والتعادل بيتكسر أبجديًا. ده نفس test_ties_break_alphabetically.
  3. Orphan trigger: paper_triggers=["ghost"] و branches=[]. إيه الخطأ؟
    الإجابةBestResultError: فيه trigger بس مش لاقي الـ branch بتاعه بعد الـ lookup.
  4. Persistent state (امتداد ١): خلي كل مرحلة تكتب ناتجها في ملف JSON، ولو الملف موجود اقراه بدل ما تشغّل المرحلة.
    تلميحابدأ بالـ scheduler report: json.dump(sched_report.to_dict(), f). خلي بالك إن المرحلة اللي بعده محتاجة object مش dict، فإما تبني SchedulerReport تاني من الـ dict، أو تخزن بس الـ branch والـ reward المختارين.
  5. Timeline (امتداد ٢): اطبع كل events الـ trace اللي في scheduler_report بترتيبها، وبعدهم جولات الـ critic.
    تلميحافتح rep.scheduler_report["trace"] وبص على مفاتيح أول event الأول قبل ما تقرر تعرض إيه.
  6. إضافة مني · stage جديد في سطر واحد: ضيف مرحلة safety_check(full_paper) قبل الـ writer ترمي UnsafeClaimError لو الـ abstract فيه كلمة زي «guaranteed» أو «proves». اكتب test يتأكد إن الـ writer ما بيتنادش لما الكلمة موجودة. ده نفس اللي بيحصل في أي agent pipeline حقيقي: guardrail بين التوليد والنشر.
    تلميحاعمل exception class جديد، ونادي الدالة بين mini_to_full_paper و writer.write. في الـ test اعمل out_dir مؤقت واتأكد إنه فاضي بعد الـ exception.

الحدس: الديمو هو integration test

كل درس قبل كده كان unit tests لـ primitive واحد. الديمو هو أول مرة الحتت تتقابل. أغلب الـ bugs في أنظمة الـ agents الحقيقية مش جوه أي component، هي في الحدود بينهم: dict بدل object، مفتاح اسمه مختلف، قايمة فاضية محدش توقعها.

أخطاء شائعة

  1. ترجّع None بدل ما ترمي: لو الـ picker رجّع None، الـ writer هيقع بعدين بخطأ غامض بعيد عن السبب. الخطأ الـ typed بيشاور على المكان الصح.
  2. عشوائية مستخبية: random.choice في كسر تعادل، أو set بتلف عليه، أو وقت النظام في اسم ملف. أي واحدة فيهم بتبوّظ اختبار الـ determinism.
  3. تعديل الناتج في النص: لو الديمو «نضّف» ناتج مرحلة قبل ما يحطه في التقرير، الـ debugging بيبقى أصعب. خليه زي ما هو.
  4. تصادم أسماء الموديولات: تلات ملفات main.py + import main = هتاخد أول واحد بس من الـ cache بتاع sys.modules.

بيظهر فين في الـ LLMs والـ agents؟

أي agent framework بيعمل research أو coding بيمشي بنفس الشكل: planner → workers بالتوازي → aggregator → reviewer → writer. لما تبدّل الـ mocks بـ LLM calls حقيقية، الـ determinism بيقل (حتى مع temperature صغيرة)، فالعادة إنك تحتفظ بنسخة mocked من الـ pipeline للـ CI وتختبر الشكل (shape) مش النص بالحرف.

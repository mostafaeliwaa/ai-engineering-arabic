الأحداث، فضاء العينة، والاحتمال

فضاء العينة (sample space) S هو كل النتايج الممكنة. الحدث (event) مجموعة جزئية منه. والاحتمال بيدي كل حدث رقم بين 0 و1.

عملة: S = {H, T} P(H) = 0.5 ، P(T) = 0.5 زهرة: S = {1, 2, 3, 4, 5, 6} P(زوجي) = P({2, 4, 6}) = 3/6 = 0.5

تلات قواعد (axioms) بس، وكل الاحتمالات طالعة منهم:

  1. P(A) ≥ 0 لأي حدث.
  2. P(S) = 1: حاجة لازم تحصل.
  3. P(A أو B) = P(A) + P(B) لو مينفعش يحصلوا مع بعض.

الاحتمال الشرطي والاستقلال

P(A | B) = احتمال A بشرط إن B حصلت. بنضيّق العالم على B بس:

P(A | B) = P(A و B) / P(B) P(King | Face) = (4/52) / (12/52) = 4/12 = 1/3

حدثين مستقلين لو معرفة واحد مش بتقول أي حاجة عن التاني:

P(A | B) = P(A) يعني P(A و B) = P(A) · P(B)

رمي العملة مرتين مستقلين. سحب كروت من غير ما ترجعها مش مستقلين: كل كارت بيغير اللي فاضل.

تشبيه: الاحتمال الشرطي زي إنك تقلّب في الصور بفلتر. P(King | Face): فلتر «صور الوشوش بس» (12 كارت)، وبعدين تعد الملوك جوه الفلتر (4).

PMF ضد PDF، والتوزيعات المشهورة

المتغير المتقطع (discrete) ليه PMF: كل نتيجة ليها احتمال تقراه مباشرة، ومجموعهم = 1. زهرة عادلة: P(X = k) = 1/6 لكل k.

المتغير المتصل (continuous) ليه PDF: الكثافة عند نقطة واحدة مش احتمال. الاحتمال بييجي من الـ integral على فترة (فاكر معمل المستطيلات يوم ٤؟). والكثافة ممكن تبقى أكبر من 1، بس المساحة الكلية تحتها = 1.

P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx ∫ f(x) dx على كل الخط = 1

في الـ ML: خرج الـ classification هو PMF (اختيارات متقطعة)، والـ latent space في الـ VAE بيستخدم PDFs (متصل).

التوزيعالصيغةMean / Varianceبيمثّل إيه في الـ ML
BernoulliP(1) = p, P(0) = 1 − pp / p(1 − p)محاولة واحدة بنتيجتين: الـ binary classification
CategoricalP(X = i) = pᵢ, Σpᵢ = 1—محاولة واحدة بـ k نتيجة: خرج الـ softmax (قطة 0.7، كلب 0.2، عصفورة 0.1)
Uniform1/n أو 1/(b − a) على [a, b]—كله متساوي: الـ random initialization

Poissonλᵏ e^(−λ) / k!λ / λعدد الأحداث النادرة في فترة: معدلات الأحداث

Expected value والـ Variance

E[X] = Σ xᵢ · P(X = xᵢ) (متقطع) E[X] = ∫ x · f(x) dx (متصل) Var(X) = E[(X − E[X])²] = E[X²] − (E[X])² SD = √Var

الـ expected value هو المتوسط الموزون بالاحتمالات. الزهرة: E = 3.5، Var ≈ 2.9167، SD ≈ 1.7078. في الـ ML الـ loss هو expected value (متوسط الـ loss على توزيع الداتا)، والـ variance بتقولك عن الاستقرار: variance عالية في الـ gradients = تدريب مشوّش.

جرّب Normal بـ σ = 0.2: الكثافة بتعدي 1 بكتير، وده عادي لأنها مش احتمال.

الـ sampling في الـ ML: الـ dropout بيسحب عشوائي مين يتقفل، الـ augmentation بيسحب تحويلات عشوائية، الـ LLM بيسحب الكلمة الجاية من التوزيع، والـ diffusion بيسحب noise ويشيله تدريجيًا. وللتوزيعات المعقدة فيه تقنيات زي inverse transform وrejection sampling والـ reparameterization trick (في الـ VAEs).

الـ marginal بنجيبه بإننا «نجمع» المتغير التاني: P(X = x) = Σ_y P(X = x, Y = y). هما حرفيًا مجاميع الصفوف والأعمدة (اسمهم marginal عشان بيتكتبوا في هامش الجدول).

Log probabilities، Softmax، وCross-entropy

ليه الـ log؟

ضرب احتمالات صغيرة كتير بيوصل لـ underflow: الرقم بيصغر لدرجة إن الكمبيوتر يقربه لصفر. احتمال جملة = حاصل ضرب احتمالات كلماتها:

P(جملة) = 0.01 · 0.003 · 0.02 · … → 0.0 (underflow) log P(جملة) = −4.6 + −5.8 + −3.9 + … → رقم عادي
  • log(a · b) = log(a) + log(b): الضرب بقى جمع.
  • الـ log probability دايمًا ≤ 0 (لأن 0 < P ≤ 1). كل ما يبقى سالب أكتر يبقى أقل احتمالًا.
  • الـ cross-entropy loss = سالب الـ log probability بتاع الإجابة الصح.

الـ Softmax: من scores لاحتمالات

الشبكة بتطلّع أرقام خام اسمها logits (اسمها جاي من الـ logistic function). الـ softmax بيحولها لتوزيع احتمالي سليم:

softmax(zᵢ) = exp(zᵢ) / Σⱼ exp(zⱼ)

كل الخرج بين 0 و1، مجموعه 1، بيحافظ على ترتيب الـ logits، والـ exp بيكبّر الفروق بينهم.

الـ softmax trick: exp(102) ممكن يعمل overflow. اطرح أكبر logit الأول: [100, 101, 102] → [−2, −1, 0]. النتيجة نفسها بالظبط (الطرح بيتلغي في القسمة)، ومفيش overflow. والـ log-softmax بيجمع الـ softmax والـ log في خطوة واحدة مستقرة، وده اللي PyTorch بيستخدمه جوه الـ cross-entropy.

log_softmax(zᵢ) = zᵢ − ( m + log Σⱼ exp(zⱼ − m) ) حيث m = max(z)

والـ cross-entropy عمومًا −Σ p_true · log(p_pred). لما الإجابة الصح واحدة بس (one-hot) بتبقى −log(q_صح): لو الموديل قال 0.9 للصح، الـ loss = 0.105. لو قال 0.01، الـ loss = 4.6.

معمل ٤: softmax وcross-entropy قدامك

حرّك الـ logits واختار الإجابة الصح. الأعمدة هي الـ softmax، وتحت الـ loss. لاحظ: لما تعلي logit الإجابة الصح الـ loss بيقرب من صفر، ولما الموديل يبقى واثق في إجابة غلط الـ loss بيطير.

وفعّل «زوّد 1000 على الكل»: الـ softmax العادي بيطلّع NaN (overflow)، والـ stable مش بيتأثر خالص.

إضافة مني: الـ temperature T بتقسم الـ logits قبل الـ softmax. T صغيرة = توزيع حاد (الموديل «متأكد»)، T كبيرة = توزيع مفرود. ده نفس الـ temperature اللي في إعدادات أي LLM.

import math

def factorial(n):
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

def combinations(n, k):                      # n اختار k
    return factorial(n) // (factorial(k) * factorial(n - k))

def conditional_probability(p_a_and_b, p_b):
    return p_a_and_b / p_b

print(f"P(King | Face card) = {conditional_probability(4/52, 12/52):.4f}")   # 0.3333

خطوة ٢: PMF وPDF من الصفر

def bernoulli_pmf(k, p):
    return p if k == 1 else (1 - p)

def categorical_pmf(k, probs):
    return probs[k]

def poisson_pmf(k, lam):
    return (lam ** k) * math.exp(-lam) / factorial(k)

def uniform_pdf(x, a, b):
    return 1.0 / (b - a) if a <= x <= b else 0.0

def normal_pdf(x, mu, sigma):
    coeff = 1.0 / (sigma * math.sqrt(2 * math.pi))
    exponent = -0.5 * ((x - mu) / sigma) ** 2
    return coeff * math.exp(exponent)

print([round(poisson_pmf(k, 3), 4) for k in range(10)])
print([round(normal_pdf(x, 0, 1), 4) for x in range(-3, 4)])

خطوة ٣: Expected value والـ variance

def expected_value(values, probabilities):
    return sum(v * p for v, p in zip(values, probabilities))

def variance(values, probabilities):
    mu = expected_value(values, probabilities)
    return sum(p * (v - mu) ** 2 for v, p in zip(values, probabilities))

die, probs = [1, 2, 3, 4, 5, 6], [1/6] * 6
mu, var = expected_value(die, probs), variance(die, probs)
print(f"Die: E[X] = {mu:.4f}, Var(X) = {var:.4f}, SD = {var**0.5:.4f}")

خطوة ٤: الـ sampling

def sample_bernoulli(p, n=1):
    return [1 if random.random() < p else 0 for _ in range(n)]

def sample_categorical(probs, n=1):
    cumulative, total = [], 0
    for p in probs:                          # [0.1, 0.4, 0.8, 1.0]
        total += p
        cumulative.append(total)
    samples = []
    for _ in range(n):
        r = random.random()                  # رقم بين 0 و1
        for i, c in enumerate(cumulative):   # أول خانة تعدّيه
            if r <= c:
                samples.append(i)
                break
    return samples

def sample_normal_box_muller(mu, sigma, n=1):
    samples = []
    for _ in range(n):
        u1, u2 = random.random(), random.random()
        z = math.sqrt(-2 * math.log(u1)) * math.cos(2 * math.pi * u2)   # Box-Muller
        samples.append(mu + sigma * z)
    return samples

s = sample_categorical([0.1, 0.3, 0.4, 0.2], 1000)
print([s.count(i) / 1000 for i in range(4)])     # قريب من [0.1, 0.3, 0.4, 0.2]

الـ Box-Muller بياخد رقمين uniform ويحوّلهم لرقم normal بمعادلة مظبوطة. والـ categorical شغال بفكرة الـ «مسطرة»: بتقسم الخط من 0 لـ 1 لحتت طولها الاحتمالات، وترمي رقم عشوائي وتشوف وقع في أنهي حتة.

ملاحظة: random.random() ممكن نظريًا يطلّع 0 بالظبط، وlog(0) هيعمل إيرور. نسخة Julia بتحمي نفسها من ده بإنها تسحب تاني لو طلع صفر. احتمال نادر جدًا، بس كود production لازم يحسبه.

خطوة ٥: Softmax والـ log probabilities

def softmax(logits):
    max_logit = max(logits)
    shifted = [z - max_logit for z in logits]        # الـ trick
    exps = [math.exp(z) for z in shifted]
    total = sum(exps)
    return [e / total for e in exps]

def log_softmax(logits):
    max_logit = max(logits)
    shifted = [z - max_logit for z in logits]
    log_sum_exp = max_logit + math.log(sum(math.exp(z) for z in shifted))
    return [z - log_sum_exp for z in logits]

def cross_entropy_loss(logits, target_index):
    return -log_softmax(logits)[target_index]

print([round(p, 4) for p in softmax([2.0, 1.0, 0.1])])
print([round(p, 4) for p in softmax([100, 101, 102])])
print([round(p, 4) for p in log_softmax([2.0, 1.0, 0.1])])
print(round(cross_entropy_loss([2.0, 1.0, 0.1], 0), 4))
print(0.01 ** 50, 50 * math.log(0.01))

خطوة ٦: Joint وmarginals والـ CLT

def joint_to_marginals(joint):
    rows, cols = len(joint), len(joint[0])
    marginal_x = [sum(joint[i][j] for j in range(cols)) for i in range(rows)]   # مجموع الصف
    marginal_y = [sum(joint[i][j] for i in range(rows)) for j in range(cols)]   # مجموع العمود
    return marginal_x, marginal_y

def check_independence(joint, marginal_x, marginal_y, tol=1e-9):
    for i in range(len(marginal_x)):
        for j in range(len(marginal_y)):
            if abs(joint[i][j] - marginal_x[i] * marginal_y[j]) > tol:
                return False
    return True

joint = [[0.40, 0.10], [0.05, 0.45]]
mx, my = joint_to_marginals(joint)
print(mx, my, check_independence(joint, mx, my))   # [0.5, 0.5] [0.45, 0.55] False

def demonstrate_clt(dist_fn, n_per_sample, n_averages):
    return [sum(dist_fn() for _ in range(n_per_sample)) / n_per_sample
            for _ in range(n_averages)]

for n in [1, 2, 5, 30]:
    avgs = demonstrate_clt(random.random, n, 10000)
    m = sum(avgs) / len(avgs)
    sd = (sum((a - m) ** 2 for a in avgs) / len(avgs)) ** 0.5
    print(f"n={n:2d}: mean={m:.4f}, std={sd:.4f}")

    تلميحجدول 6×6 كل خانة فيه احتمال ومجموعه كله 1. استخدم joint_to_marginals وcheck_independence. لو عملت الجدول بإنك تضرب زهرة في زهرة (P(i)·P(j)) هيطلعوا مستقلين حتى لو مغشوشين. عشان تكسر الاستقلال لازم الزهرة التانية تعتمد على الأولى.
  3. Cross-entropy: logits [2.0, 0.5, −1.0, 3.0, 0.1] والإجابة الصح index 3. احسب الـ loss وقارنه بـ nn.CrossEntropyLoss.
    الإجابةsoftmax وبعدين −ln الاحتمال عند index 3. لازم يطلع حوالي 0.421، ونفس الرقم من PyTorch. لاحظ إن PyTorch بياخد الـ logits الخام مش الـ softmax.
  4. أكتر جملة محتملة: اكتب دالة بتاخد list من الـ log probabilities وترجع المجموع والاحتمال الخام المقابل. جربها على جملة 50 كلمة كل كلمة احتمالها 0.01.
    الإجابةاجمع الـ logs ومتضربش الاحتمالات. المجموع 50·ln(0.01) ≈ −230.26 والاحتمال الخام 10⁻¹⁰⁰. جرّب 200 كلمة وهتلاقي الضرب العادي صفر والـ log تمام.
  5. إضافة مني · sampler بتاع LLM: اكتب sample_next(logits, temperature, top_k): اقسم الـ logits على الـ temperature، خلي أعلى k بس (والباقي −∞)، softmax، وبعدين sample_categorical. اسحب 1000 مرة بـ T = 0.2 وT = 1.5 وقارن التنوع.
    تلميحده تقريبًا اللي بيحصل في كل API لما تحدد temperature وtop_k. T قريبة من الصفر بتقرب من اختيار الأعلى دايمًا (greedy). خلي بالك: الـ −∞ لازم تعديها في الـ softmax الـ stable من غير ما تعمل NaN (exp(−∞) = 0 عادي).
08

إضافة مني: أخطاء شائعة وفين في الـ LLMs

  • ‏Loss = NaN: أول مشتبه فيه log(0) أو softmax من غير الـ trick. عشان كده دايمًا ادّي PyTorch الـ logits الخام لـ CrossEntropyLoss، متحسبش softmax بنفسك وبعدين log.
  • الكثافة مش احتمال: قيمة normal_pdf ممكن تبقى 2 أو 5. لو قارنت كثافات من توزيعات مختلفة كأنها احتمالات هتوصل لاستنتاجات غلط.
  • الاستقلال افتراض: كتير من الموديلات بتفترضه عشان الحساب يبقى سهل (بكرة في الـ Naive Bayes). لازم تعرف امتى بتفترضه.
  • في الـ LLMs: الموديل بيطلّع logits على الـ vocabulary كله لكل token. الـ training loss هو متوسط الـ cross-entropy على كل token. والـ perplexity اللي بتشوفها في الـ papers هي exp(متوسط الـ cross-entropy)، يعني تقريبًا «الموديل محتار بين كام كلمة في المتوسط». والـ logprobs اللي بعض الـ APIs بترجعها هي نفس الـ log-softmax ده.

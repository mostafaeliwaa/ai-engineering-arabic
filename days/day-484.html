ليه scheduler مش worklist؟

الـ worklist العادية بتشغّل الشغل بترتيب ما اتبعت. ده كويس لو كل job مستقلة عن التانية. بس البحث مش كده: نتيجة التجربة رقم ٣ بتغيّر أولوية التجارب ٤ و٥. الـ scheduler اللي بيقرا النتايج اللي راجعة (الـ fan-in) ويعيد ترتيب الطابور بيطلّع شغل مفيد أكتر لنفس كمية الـ compute.

تخيّل إنك بتدوّر على أحسن مطعم كشري في منطقة جديدة. لو كل يوم رحت لأحسن واحد جربته لحد دلوقتي (greedy) عمرك ما هتكتشف المحل اللي في الشارع اللي ورا. لو كل يوم اخترت عشوائي (uniform) هتاكل وحش كتير ومش هتستفيد من اللي عرفته. الحل الوسط هو UCB: روح للأحسن غالبًا، بس سيب فرصة للمحلات اللي لسه ماجربتهاش كفاية.

شكل النظام

Hypothesis queue → Scheduler → Slot 1 / Slot 2 / Slot 3 → Result bus → UCB scorer → Queue Result bus → Paper write fan-out
  • • الطابور فيه الـ hypotheses.
  • • الـ scheduler بيختار الـ hypothesis صاحبة أعلى UCB كل ما slot يفضى.
  • • كل slot بيشغّل تجربة async.
  • • التجربة لما تخلص بترمي نتيجتها على الـ result bus.
  • • الـ bus بيحدّث إحصائيات الـ UCB للـ branch صاحب التجربة، وبيعمل fan-out للـ paper-write لما الـ yield بتاع الـ branch يعدّي threshold.

02

UCB1: المعادلة اللي بتوازن بين الاستغلال والاستكشاف

ucb(branch) = mean_reward(branch) + c · √( ln(total_runs) / runs(branch) )

الجزء الأول mean_reward هو «الفكرة دي جابت كام في المتوسط» = exploitation.

الجزء التاني هو مكافأة الاستكشاف (bonus): بيكبر لما runs بتاع الـ branch يبقى قليل، وبيكبر ببطء (log) مع إجمالي التجارب total_runs. يعني أي branch اتهمل هيرجع يطلع فوق مع الوقت.

  • • c = وزن الاستكشاف، الافتراضي في الدرس sqrt(2).
  • • branch عمره ما اتجرّب (runs = 0) بياخد +inf، فكل branch بيتجرب مرة على الأقل قبل ما أي branch يتكرر.
  • • branch الـ mean بتاعه عالي بيفضل score عالي لحد ما الباقيين يلحقوه. branch اتشغّل كتير من غير reward بيتغطى عليه من بدايل أقل تجربة.
جرب بإيدك: ثبّت الـ mean وحرّك runs. شوف الـ bonus بيقع بسرعة في الأول وبعدين يهدى. وبعدين كبّر c: الـ scheduler بقى «فضولي» أكتر.

الـ Fan-out: paper triggers والـ follow-ups

  
Paper trigger

  
لما الـ mean بتاع branch يعدّي (أو يساوي) paper_threshold (الافتراضي 0.7)، والـ branch ده لسه مطلّعش paper، الـ scheduler بيرمي event اسمه paper.trigger. بعد كده الـ paper writer بتاع درس ٥٤ هو اللي هيلقطه. في الدرس ده الـ trigger بيتسجل في list عشان الـ tests تقدر تتأكد منه. الـ flag paper_triggered في BranchStats بيمنع التكرار: مرة واحدة لكل branch.

  
Follow-up hypotheses

  
لما نتيجة قوية توصل، الـ scheduler ممكن ينادي expander اللي اليوزر بيديهوله عشان يطلّع hypothesis أو أكتر على نفس الـ branch. الـ expander دالة pure من Result لـ list[Hypothesis]. الدرس فيه expander deterministic بيطلّع اتنين follow-ups لأي نتيجة الـ reward بتاعها عدّى الـ paper threshold.

  
الـ Trace والتقرير النهائي

  
كل قرار (pick/dispatch، result، prune، fan-out) بيطلّع event واحد. التقرير النهائي بيلخّص إحصائيات كل branch، إجمالي التجارب، الوقت الكلي، والـ paper triggers اللي اتعملت. الدرس الجاي (الـ end-to-end demo) بيقرا التقرير ده عشان يشغّل الـ paper writer.

from __future__ import annotations
import asyncio, json, math, time
from dataclasses import dataclass, field
from typing import Awaitable, Callable
import numpy as np

@dataclass
class Hypothesis:
    id: str
    branch: str                      # اتجاه البحث = مفتاح الـ UCB
    payload: dict = field(default_factory=dict)

@dataclass
class Result:
    hypothesis_id: str
    branch: str
    reward: float                    # بين 0 و 1
    payload: dict = field(default_factory=dict)

@dataclass
class BranchStats:
    branch: str
    runs: int = 0
    reward_sum: float = 0.0
    pruned: bool = False
    paper_triggered: bool = False    # عشان الـ trigger ميتكررش

    @property
    def mean(self) -> float:
        return (self.reward_sum / self.runs) if self.runs else 0.0

@dataclass
class TraceEvent:
    kind: str                        # dispatch / result / prune / ...
    payload: dict

Runner = Callable[[Hypothesis], Awaitable[Result]]
Expander = Callable[[Result], list[Hypothesis]]


  
خطوة ٢: معادلة UCB1

  
def ucb_score(branch_stats: BranchStats, total_runs: int, c: float) -> float:
    if branch_stats.runs == 0:
        return float("inf")          # اللي ماتجربش ياخد الأولوية
    if total_runs == 0:
        return branch_stats.mean
    return branch_stats.mean + c * math.sqrt(
        math.log(max(total_runs, 1)) / branch_stats.runs)   # مكافأة الاستكشاف


  
خطوة ٣: الـ picker

  
class IterationScheduler:
    def __init__(self, runner, slots=3, max_experiments=50, max_seconds=30.0,
                 exploration_c=math.sqrt(2.0), paper_threshold=0.7,
                 prune_floor=0.2, prune_after_runs=3, expander=None):
        if slots < 1:
            raise ValueError("slots must be >= 1")
        if max_experiments < 1:
            raise ValueError("max_experiments must be >= 1")
        self.runner = runner; self.slots = slots
        self.max_experiments = max_experiments; self.max_seconds = max_seconds
        self.exploration_c = exploration_c; self.paper_threshold = paper_threshold
        self.prune_floor = prune_floor; self.prune_after_runs = prune_after_runs
        self.expander = expander

    def _pick_next(self, queue, stats):
        best_idx, best_score = None, -float("inf")
        total_runs = sum(s.runs for s in stats.values())
        for idx, hyp in enumerate(queue):
            bs = stats.get(hyp.branch)
            if bs is not None and bs.pruned:
                continue                 # الـ branch اتقص، فوّته
            score = ucb_score(bs or BranchStats(branch=hyp.branch),
                              total_runs, self.exploration_c)
            if score > best_score:       # > مش >= : التعادل يكسبه الأقدم في الطابور
                best_score, best_idx = score, idx
        return best_idx


  
خطوة ٤: الـ dispatch والـ loop الرئيسي

  
    async def run(self, seed):
        queue = list(seed)
        stats = {h.branch: BranchStats(branch=h.branch) for h in seed}
        in_flight = {}                   # task -> hypothesis
        trace, triggers = [], []
        experiments_run = 0
        stop_reason = "queue_empty"
        t0 = time.monotonic()

        def deadline_hit(): return (time.monotonic() - t0) >= self.max_seconds
        def budget_hit():   return experiments_run >= self.max_experiments

        def dispatch_until_full():
            nonlocal experiments_run
            while queue and len(in_flight) < self.slots and not budget_hit() and not deadline_hit():
                idx = self._pick_next(queue, stats)
                if idx is None:
                    return
                hyp = queue.pop(idx)
                stats.setdefault(hyp.branch, BranchStats(branch=hyp.branch))
                task = asyncio.create_task(self.runner(hyp))   # slot اتملى
                in_flight[task] = hyp
                experiments_run += 1     # بيتعد وقت الـ dispatch
                trace.append(TraceEvent("dispatch", {"hypothesis_id": hyp.id,
                             "branch": hyp.branch, "slot_count": len(in_flight)}))

        dispatch_until_full()
        while in_flight:
            done, _ = await asyncio.wait(in_flight.keys(),
                                         return_when=asyncio.FIRST_COMPLETED)
            for task in done:
                hyp = in_flight.pop(task)
                ...                      # خطوة ٥
            if budget_hit():
                stop_reason = "max_experiments"; break
            if deadline_hit():
                stop_reason = "deadline"; break
            dispatch_until_full()        # املا الـ slots اللي فضيت

                if (not bs.paper_triggered) and bs.mean >= self.paper_threshold and bs.runs >= 1:
                    bs.paper_triggered = True

                    trace.append(TraceEvent("paper.trigger", {"branch": result.branch, "mean": bs.mean}))

                # pruning: بعد عدد كافي من التجارب والـ mean واطي
                if (not bs.pruned) and bs.runs >= self.prune_after_runs and bs.mean < self.prune_floor:
                    bs.pruned = True
                    queue[:] = [h for h in queue if h.branch != bs.branch]
                    trace.append(TraceEvent("prune", {"branch": bs.branch,
                                 "mean": bs.mean, "runs": bs.runs}))

                # fan-out 2: follow-ups للنتايج القوية
                if self.expander is not None and result.reward >= self.paper_threshold:
                    followups = self.expander(result)
                    if followups:
                        queue.extend(followups)
                        trace.append(TraceEvent("expand", {"branch": result.branch,
                                     "added": [h.id for h in followups]}))

def make_deterministic_runner(base_rewards, noise=0.05, delay_ms=5.0, seed=0):
    rng = np.random.default_rng(seed)
    async def run(hyp):
        base = base_rewards.get(hyp.branch, 0.5)
        reward = max(0.0, min(1.0, base + float(rng.normal(0.0, noise))))  # احبس بين 0 و1
        await asyncio.sleep(delay_ms / 1000.0)    # عشان التوازي يبان
        return Result(hypothesis_id=hyp.id, branch=hyp.branch, reward=reward,
                      payload={"base": base, "noise": noise})
    return run

def deterministic_expander(result):
    return [Hypothesis(id=f"{result.hypothesis_id}-f{i}", branch=result.branch,
                       payload={"parent": result.hypothesis_id}) for i in (1, 2)]

async def demo_async():
    seed = [Hypothesis(id="h-a-1", branch="branch-a"), Hypothesis(id="h-b-1", branch="branch-b"),
            Hypothesis(id="h-c-1", branch="branch-c"), Hypothesis(id="h-d-1", branch="branch-d")]
    runner = make_deterministic_runner(
        base_rewards={"branch-a": 0.85, "branch-b": 0.55, "branch-c": 0.15, "branch-d": 0.40},
        seed=7, delay_ms=2.0)
    sched = IterationScheduler(runner=runner, slots=3, max_experiments=20,
                               paper_threshold=0.7, prune_floor=0.25, prune_after_runs=3,
                               expander=deterministic_expander)
    return (await sched.run(seed)).to_dict()

if __name__ == "__main__":
    r = asyncio.run(demo_async())
    print(json.dumps({k: r[k] for k in ["stop_reason", "experiments_run",
                      "wall_seconds", "paper_triggers", "branches"]}, indent=2))

التمارين

  
الدرس ملوش قسم تمارين منفصل، فالتمارين دي مبنية على الـ tests والتلات امتدادات اللي في «Going further».

  
    
    
  1. حساب UCB بالورقة: branch A: runs=5 وreward_sum=4.5. branch B: runs=5 وreward_sum=1.0. total_runs=10 وc=√2. مين أعلى؟ وبعدين: A runs=100 وsum=50، B runs=2 وsum=1، total=102.
      
    الإجابةالحالة الأولى: نفس الـ runs فنفس الـ bonus، فالـ mean الأعلى (A: 0.9) يكسب. الحالة التانية: الاتنين mean=0.5، بس bonus بتاع B أكبر بكتير لأن runs=2، فـ B يكسب. دول بالظبط أول تلات tests في TestUCB.
    2. 
    
  2. شغّل الـ tests وكسّر واحد عن قصد: غيّر > لـ >= في شرط الـ prune أو شيل bs.paper_triggered = True وشوف أنهي test بيقع.
      
    تلميحلو شلت الـ flag، test_paper_trigger_only_fires_once_per_branch هيلاقي ["b1","b1",...] بدل ["b1"].
    3. 
    
  3. امتداد ١ · UCB stats دايمة: الإحصائيات دلوقتي في الـ memory. اعمل checkpoint لـ stats في ملف JSON بعد كل result، وحمّلها في بداية run عشان الـ restart ميضيّعش ميزانية الاستكشاف اللي اتصرفت.
      
    تلميحBranchStats.to_dict() موجودة. للتحميل: BranchStats(**{k: d[k] for k in ["branch","runs","reward_sum","pruned","paper_triggered"]}). اختبر: run بـ max_experiments=5، وبعدين run تاني لازم يبدأ بـ total_runs=5.
    4. 
    
  4. امتداد ٢ · Multi-objective: خلّي الـ reward vector (مثلًا accuracy وcost) واعمل picker بيختار من الـ Pareto front.
      
    تلميحbranch «مغلوب» لو فيه branch تاني أحسن منه أو زيه في كل الأبعاد وأحسن في بُعد واحد على الأقل. احسب UCB لكل بُعد لوحده، شيل المغلوبين، واختار من الباقيين (مثلًا بالـ tie-break على أقل runs).
    5. 
    
  5. امتداد ٣ · Contextual bandits: خلّي الـ picker يعتمد على features في الـ hypothesis (طول، تعقيد) عشان الـ hypotheses المتشابهة تشارك الاستكشاف.
      
    تلميحأبسط بداية: اعمل bucket من الـ features (مثلًا payload["complexity"] low/high) واستخدم (branch, bucket) كمفتاح للإحصائيات بدل الـ branch لوحده.
    6. 
    
  6. إضافة مني · scheduler لـ eval jobs حقيقية: عندك ٤ prompt variants لـ agent وكل eval run بياخد API calls. استخدم IterationScheduler مع runner بيرجّع pass-rate على ٥ أسئلة عشوائية من eval set، slots=4، max_experiments=40. الـ paper.trigger هنا معناه «الـ variant ده يستاهل eval كامل».
      
    تلميحالـ runner لازم يبقى async؛ لو الـ client بتاعك sync لفّه بـ await asyncio.to_thread(...). حط max_seconds كحماية من الفلوس، وخلّي الـ prune_floor أقل من pass-rate الـ baseline بتاعك.

غلطات شائعة لما تقرا الكود

  
    
    
  • • الـ pruning محتاج hypotheses: الـ prune بيحصل بس لما الـ branch يوصل prune_after_runs. لو الـ branch عنده hypothesis واحدة والـ expander مش بيزوّد حاجة للنتايج الضعيفة، عمره ما هيوصل ٣ runs، فمش هيتعمله prune. في الـ demo الـ branch-c (0.15) عنده seed واحد بس. جرّب ده في المعمل ٠٣.
    • 
    
  • • experiments_run بيتعد وقت الـ dispatch مش وقت ما النتيجة توصل. فالتجارب اللي وقعت بـ exception محسوبة في الـ budget بس مش في runs.
    • 
    
  • • الـ +inf بيعمل round-robin في الأول: كل الـ branches الجديدة بتاخد inf، والـ > الصارمة معناها إن الأقدم في الطابور يكسب التعادل. فالـ follow-ups على branch جديد (لو الـ expander عمل branch جديد) هتتقدم على طول.
    • 
    
  • • الـ drain مبيعملش prune ولا expand: بس بيحدّث الإحصائيات وممكن يطلّع paper.trigger. منطقي: الـ budget خلص، مفيش داعي تزوّد في الطابور.
    • 
    
  • • الـ reward لازم يبقى في نفس الـ scale: UCB1 مفترض إن الـ reward بين 0 و1 تقريبًا (عشان كده الـ runner بيعمل clamp). لو الـ reward بتاعك loss من 0 لـ 50، الـ bonus هيبقى مالوش وزن. اعمل normalize الأول.

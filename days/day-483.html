clarity · novelty · evidence · methodology · related_work

شكل الـ Critique والـ Suggestion

كل جولة الناقد بيرجّع Critique فيه:

الحقلمعناه

scores: dictالدرجات الخمسة
suggestions: list[Suggestion]اقتراحات التعديل

وكل Suggestion شايل ٣ حاجات: الـ dimension اللي بيحسّنها، والـ section اللي بيستهدفها (target_section_id)، وتعليمة edit الـ reviser يقدر ينفذها. يعني كل اقتراح «مربوط» بحاجة محددة، مش كلام عائم.

الـ Reviser برضه callable. في الدرس فيه reviser deterministic بيفهم الـ edit كعملية «append على section». لو حطيت مكانه reviser بموديل، هيفهم نفس الحقل كـ prompt. الـ contract مابيتغيرش.

فصل المسؤوليات: الـ Harness بيملك عدّاد الجولات والـ trace والـ convergence check. الـ Critic بيملك الدرجة. الـ Reviser بيملك التعديل (diff). محدش فيهم بيلمس state التاني. والـ reviser بياخد (paper, suggestions) بس، ومابيشوفش الدرجات خالص، فتقدر تبدّل أي طرف من غير ما تلمس التاني.
Harness → critique(draft, round) → Critique{scores, suggestions} → revise(draft, suggestions) → convergence check → stop | next round
03

قواعد الوقوف، وبالترتيب ده

بعد كل جولة، اللوب بيقف لو أي شرط من دول اتحقق، وبيتشيّكوا بالترتيب:

  1. target: كل الأبعاد الخمسة ≥ target_score (الافتراضي 8.0). mean عالي وبُعد واحد ضعيف = مش كفاية. النتيجة converged / target.
  2. plateau: الـ mean بتاع الجولة الحالية مقارنة باللي قبلها زاد أقل من plateau_epsilon (الافتراضي 0.1) لمدة جولتين ورا بعض. النتيجة converged / plateau.
  3. budget: عدد الجولات وصل للسقف max_rounds (الافتراضي 5). النتيجة stopped / budget.

الترتيب مهم: target يكسب plateau، وplateau يكسب budget. لو جولة ٣ حققت الـ target في نفس الجولة اللي كان هيحصل فيها plateau، النتيجة target. ده بيخلي النتيجة deterministic لما أكتر من شرط يتحقق مع بعض.

ليه الـ plateau على جولتين مش جولة واحدة؟

جولة واحدة مسطحة = noise. حتى الـ scorer الـ deterministic بيطلّع رقم مختلف شوية كل جولة، لأن الدرجة بتعتمد على أنهي اقتراحات اتطبقت وبأي ترتيب. لما تشترط جولتين مسطحين ورا بعض بتفلتر الـ noise ده. فلو الـ harness قال plateau، يبقى المسودة فعلًا بطّلت تتحسن. زي ما تقيس وزنك: يوم واحد ثابت مش معناه إنك وقفت تخس، أسبوعين ثابتين يبقى فيه حاجة.

الـ budget بيحميك من ناقد بايظ

ناقد بيطلّع اقتراحات عمرها ما بتحسّن الدرجة هيحبس اللوب لحد السقف. الـ trace هنا بيوضح ده: ٥ جولات، الدرجات ثابتة، الـ verdict budget. اللي بيقرا ده بيفهم إن المشكلة في الـ critic مش في المسودة. لو كنت بترجّع المسودة النهائية بس، كنت هتخبّي التشخيص. ده معنى trace-first design.

معمل ٢: اسحب الأعمدة وشوف مين يقف اللوب

كل عمود هو الـ mean في جولة (افترضنا هنا إن الأبعاد الخمسة متساوية، فالـ target بيتحقق لما العمود يعدي الخط). اسحب الأعمدة لفوق وتحت، وغيّر الـ epsilon والـ window والـ budget. الجولة اللي اللوب وقف فيها بتنوّر، ومكتوب جنبها السبب.

جرب: خلّي جولة ٢ و٣ و٤ قريبين من بعض جدًا (فرق أقل من 0.1) وشوف plateau عند جولة ٤ مش ٣. وبعدين خلّي جولة ٤ تعدي الـ target في نفس الوقت: هتلاقي target كسب.

الناقد الـ deterministic في الدرس

الدرس مابيكلمش أي موديل. الـ critic دالة بتدي درجات من إشارات بسيطة في المسودة، والـ reviser عارف إزاي يرفع كل درجة:

البُعدبيزيد إمتىالمعادلة في الكود

والـ reviser بيترجم كل اقتراح لعملية محددة: expand-body بيزود ٨٠ حرف على آخر section، bump-originality بيطلّع الـ tag درجة (low→medium→high)، add-figure-and-cite بيضيف figure وcitation لأول section، وadd-method-section وadd-related-work-section بيضيفوا الـ section لو مش موجودة أو بيملوا الـ body لو فاضي. بعد أول جولة الدرجة بتطلع لفوق، والتستات بتستغل الخاصية دي عشان تتأكد إن اللوب بيقلّل الفجوة.

معمل ٣: شغّل الـ CriticLoop نفسه

ده port بالـ JavaScript لنفس منطق deterministic_critic وdeterministic_reviser وCriticLoop.run، على نفس مسودة الـ demo (section واحدة «short intro» والـ originality low). دوس «جولة واحدة» وتابع الخطوط، أو «شغّل للآخر».

غيّر الـ target لـ 9: novelty وmethodology وrelated_work سقفهم 9 بالظبط، وclarity بيطلع ~0.5 بس كل جولة، فاللوب بيخلص بـ budget. وبعدين خلّي epsilon = 0.5 مع target 9: الجولات ٣ و٤ و٥ بيزيدوا ~0.1 بس، فهتشوف plateau عند جولة ٥. ولو رجّعت الـ target لـ 8 مع epsilon 0.5، الـ target هيكسب في جولة ٥ قبل الـ plateau.

الـ Trace: سجل كل جولة

@dataclass
class Suggestion:
    dimension: str                   # البُعد اللي هيتحسن
    target_section_id: str | None    # الـ section المستهدفة
    edit: str                        # تعليمة الـ reviser

@dataclass
class Critique:
    round: int
    scores: dict[str, float]
    suggestions: list[Suggestion]
    reason: str

    def mean(self) -> float:
        return sum(self.scores.values()) / len(self.scores) if self.scores else 0.0

class Critic(Protocol):
    def __call__(self, paper: MiniPaper, round_: int) -> Critique: ...

class Reviser(Protocol):                 # مابياخدش scores خالص
    def __call__(self, paper: MiniPaper, suggestions: list[Suggestion]) -> MiniPaper: ...

@dataclass
class LoopTrace:
    round: int
    scores: dict[str, float]
    mean: float
    suggestions_applied: int
    verdict: str                     # continue / target / plateau / budget

خطوة ٣: الـ convergence checks

class CriticLoop:
    def __init__(self, critic, reviser, max_rounds=5, target_score=8.0,
                 plateau_epsilon=0.1, plateau_window=2):
        if max_rounds < 1:
            raise ValueError("max_rounds must be >= 1")
        self.critic, self.reviser = critic, reviser
        self.max_rounds = max_rounds
        self.target_score = target_score
        self.plateau_epsilon = plateau_epsilon
        self.plateau_window = plateau_window

    def _target_met(self, c: Critique) -> bool:   # كل الأبعاد، مش الـ mean
        return all(c.scores.get(d, 0.0) >= self.target_score for d in DIMENSIONS)

    def _plateau(self, trace) -> bool:
        if len(trace) < self.plateau_window + 1:   # محتاج window+1 نقط
            return False
        recent = trace[-(self.plateau_window + 1):]
        for i in range(1, len(recent)):
            if recent[i].mean - recent[i - 1].mean > self.plateau_epsilon:
                return False                      # فيه تحسن حقيقي
        return True

خطوة ٤: اللوب نفسه (target ← plateau ← budget)

    def run(self, paper):
        trace, critique = [], None
        for round_ in range(1, self.max_rounds + 1):
            critique = self.critic(paper, round_)
            if self._target_met(critique):                     # ١: target يكسب
                trace.append(LoopTrace(round_, dict(critique.scores),
                                       critique.mean(), 0, "target"))
                return {"status": "converged", "reason": "target",
                        "rounds_used": round_, "trace": trace}
            interim = LoopTrace(round_, dict(critique.scores), critique.mean(),
                                len(critique.suggestions), "continue")
            trace.append(interim)
            if self._plateau(trace):                           # ٢: plateau
                interim.verdict = "plateau"
                return {"status": "converged", "reason": "plateau",
                        "rounds_used": round_, "trace": trace}
            paper = self.reviser(paper, critique.suggestions)  # طبّق التعديل
        if trace:
            trace[-1].verdict = "budget"                       # ٣: السقف
        return {"status": "stopped", "reason": "budget",
                "rounds_used": self.max_rounds, "trace": trace}

def deterministic_score(paper):
    lens = [len(s.body) for s in paper.sections]
    avg_body = sum(lens) / len(lens) if lens else 0.0
    clarity = min(10.0, 3.0 + avg_body / 50.0)
    novelty = {"high": 9.0, "medium": 6.0}.get(paper.originality_tag, 3.0)
    figs = sum(len(s.figure_refs) for s in paper.sections)
    cites = sum(len(s.cites) for s in paper.sections)
    evidence = min(10.0, 2.0 + 2.0 * figs + 1.5 * cites)
    has_method = any(s.title.lower().startswith("method") and s.body for s in paper.sections)
    has_related = any(s.title.lower() == "related work" and s.body for s in paper.sections)
    return {"clarity": round(clarity, 2), "novelty": novelty, "evidence": round(evidence, 2),
            "methodology": 9.0 if has_method else 4.0,
            "related_work": 9.0 if has_related else 4.0}

EDITS = {"clarity": "expand-body", "novelty": "bump-originality",
         "evidence": "add-figure-and-cite", "methodology": "add-method-section",
         "related_work": "add-related-work-section"}

def deterministic_critic(paper, round_):
    scores = deterministic_score(paper)
    sugg = []
    for d in DIMENSIONS:
        if scores[d] < 8.0:                          # اقتراح لكل بُعد تحت 8
            target = None
            if d == "clarity" and paper.sections:
                target = paper.sections[-1].id      # آخر section
            if d == "evidence":
                target = paper.sections[0].id if paper.sections else "intro"
            sugg.append(Suggestion(d, target, EDITS[d]))
    reason = "fully-met" if not sugg else f"{len(sugg)} below target"
    return Critique(round_, scores, sugg, reason)

خطوة ٦: الـ reviser وتشغيل الـ demo

def deterministic_reviser(paper, suggestions):
    figs = sum(len(s.figure_refs) for s in paper.sections)
    cites = sum(len(s.cites) for s in paper.sections)
    for sug in suggestions:
        if sug.edit == "expand-body":
            for sec in paper.sections:
                if sec.id == sug.target_section_id:
                    sec.body = (sec.body + " " + "x" * 80).strip()
                    break
        elif sug.edit == "bump-originality":
            paper.originality_tag = {"low": "medium", "medium": "high"}.get(
                paper.originality_tag, paper.originality_tag)
        elif sug.edit == "add-figure-and-cite":
            for sec in paper.sections:
                if sec.id == sug.target_section_id:
                    figs += 1; cites += 1
                    sec.figure_refs.append(f"f{figs}")
                    sec.cites.append(f"c{cites}")
                    break
        elif sug.edit == "add-method-section":
            if not any(s.title.lower().startswith("method") for s in paper.sections):
                paper.sections.append(MiniSection("method", "Method",
                    "A description of the method follows. " + "x" * 200))
        elif sug.edit == "add-related-work-section":
            if not any(s.title.lower() == "related work" for s in paper.sections):
                paper.sections.append(MiniSection("related-work", "Related Work",
                    "We survey adjacent work. " + "x" * 200))
    return paper

paper = MiniPaper("Auto-Research Loop", "abstract",
                  [MiniSection("intro", "Introduction", "short intro")])
res = CriticLoop(deterministic_critic, deterministic_reviser, max_rounds=6).run(paper)
print(res["reason"], res["rounds_used"])
for t in res["trace"]:
    print(t.round, round(t.mean, 3), t.verdict)

  3. ناقد بايظ: اكتب stuck_critic بيرجّع 4.0 لكل الأبعاد دايمًا مع اقتراح "no-op"، وreviser مابيعملش حاجة. شغّل بـ max_rounds=3. إيه الـ verdict؟
      
    الإجابةالـ mean ثابت، فالفرق 0 ≤ epsilon. مع window=2 محتاج ٣ نقط، فعند جولة ٣ يتحقق plateau قبل ما الـ budget يتحسب. التست الأصلي بيقبل plateau أو budget، والاتنين بيكشفوا إن الناقد بايظ.
    4. 
    
  4. Regression flag: ضيف للـ LoopTrace حقل regressions: list[str] فيه الأبعاد اللي درجتها نزلت عن الجولة اللي قبلها (زي معمل ١).
      
    تلميحفي run احفظ prev_scores وقارن: [d for d in DIMENSIONS if cur[d] < prev[d]].
    5. 
    
  5. Target يكسب plateau: اكتب تست بيبني critic بيرجّع means: 5.0، 5.05، ثم 9.0 لكل الأبعاد في جولة ٣ مع target_score=9.0. اتأكد إن الـ reason = target.
      
    تلميحبص على test_plateau_detected_when_mean_stable في ملف التستات وعدّل الـ seq. في جولة ٣ الـ target بيتشيّك الأول فبيرجع قبل ما الـ plateau يتحسب أصلًا.
    6. 
    
  6. إضافة مني · LLM-as-judge حقيقي: حوّل الـ critic لـ prompt لموديل بيرجّع JSON بالشكل ده بالظبط: {"scores": {...5 أبعاد}, "suggestions": [{"dimension","target_section_id","edit"}]}. اكتب parse_critique(text, round_) بيعمل validation: الخمس أبعاد موجودين، كل درجة بين 0 و10، وكل dimension في الاقتراحات من الـ DIMENSIONS. لو الـ JSON بايظ ارجع Critique بدرجات 0 وreason "parse-error" بدل ما اللوب يقع.
      
    تلميحاختبره الأول بـ fake model (دالة بترجّع string ثابت) قبل أي API، بنفس روح الـ deterministic critic. الـ parse-error هيظهر في الـ trace بدل ما يختفي.
    7. 
  






  
08
إضافة مني: اللي الدرس مقالوش صراحة

  
الحدس: اللوب ده هو Evaluator-Optimizer pattern: واحد بيقيّم وواحد بيحسّن. نفس الشكل بتلاقيه في agents بتكتب كود وتشغّل التستات وتصلّح، أو في self-refine للـ LLMs. الفرق إن هنا التقييم structured، فالـ harness هو اللي بيحكم مش الموديل.

  
أخطاء شائعة

  
    
    
  • • تقف على الـ mean بس: ورقة 10/10 في كل حاجة ما عدا evidence 2 هتعدّي. عشان كده الكود بيستخدم all(...).
    • 
    
  • • تدّي الـ reviser الدرجات: هيبدأ «يلعب» على الأرقام بدل ما ينفذ الاقتراحات، وتفقد القدرة إنك تبدّل أي طرف لوحده.
    • 
    
  • • Goodhart: الناقد الـ deterministic بيكافئ الطول، فالـ reviser بيزود "x"*80 والـ clarity بتطلع. ده بيوضح إن الدرجة proxy: لو الـ proxy غلط، اللوب هيحسّن الحاجة الغلط بثقة. في الإنتاج راجع عينات بإيدك.
    • 
    
  • • نفس الموديل ناقد وكاتب: غالبًا بيبقى متساهل مع نفسه. الـ paired critic أو موديل مختلف بيقلل ده.
    • 
    
  • • epsilon صغير جدًا: مع ناقد فيه noise، الـ plateau مش هيتحقق أبدًا وهتصرف الـ budget كله. اختار الـ epsilon على مقاس الـ noise بتاع الناقد.

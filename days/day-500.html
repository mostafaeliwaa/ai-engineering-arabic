الـ Wall-clock timeout

  
كل subprocess له ٣ ثواني افتراضي. لو خلصوا، الـ runner بيقتل الـ process ويسجل timeout وscore صفر ويكمل للي بعده. ممكن تطلب وقت أطول للـ tests التقيلة، بس بيتعمله clamp بين 0.1 و30 ثانية عشان الـ suite كلها تفضل محدودة. في درس ٧٥ الـ runner بيظبطه مرة واحدة عن طريق code_exec_timeout_s.

  
الـ Output cap

  
كود بيطبع في loop لا نهائي ممكن يملا ذاكرة الـ host. فالـ runner بيقرا الـ stdout على دفعات (8192 byte) ولو المجموع عدّى 256 KB بيقتل الـ child فورًا ويسجل exit_code = error مع detail = "output overflow". مفيش exit code جديد للحالة دي.

Pass@k: لو سحبت k محاولات، إيه احتمال واحدة منهم تنجح؟

  
لما الموديل يولّد n حل لنفس المسألة ويكون c منهم صح، الـ unbiased estimator اللي HumanEval بيستخدمه:

  
pass@k(n, c, k) = 1 − C(n−c, k) / C(n, k)

  
المعنى: C(n−c,k)/C(n,k) هو احتمال إنك لو اخترت k من الـ n عشوائي، كلهم يطلعوا غلط. واحد ناقص ده = احتمال واحد على الأقل صح.

  
تشبيه: كيس فيه ١٠ كور، ٢ منهم دهب. لو سحبت ٥ مرة واحدة، إيه احتمال تطلع بدهباية؟ ده بالظبط pass@5 مع n=10 وc=2: 1 − C(8,5)/C(10,5) = 1 − 56/252 ≈ 0.778.

  
الحالة الطرفية: لو n − c < k يعني الغلط أقل من حجم السحبة، يبقى مستحيل تسحب k كلهم غلط، فالنتيجة 1. الكود بيتعامل معاها صريح. ولو k > n بيرجّع 1 لو c > 0 وإلا 0. وبيحسب الضرب في الـ log space عشان الأرقام ما تنفجرش.

  

    

      
معمل: حرّك n وc وk

      
الأعمدة هي pass@k لكل k من 1 لـ n. العمود المظلل هو k اللي اخترته. الخط البرتقالي هو التقدير الساذج 1−(1−c/n)^k (سحب مع إرجاع) للمقارنة.

      
لاحظ: pass@1 = c/n دايمًا، وpass@n = 1 لو c > 0.

import json, math, os, re, select, subprocess, sys, time
from dataclasses import dataclass, field
import numpy as np

CODE_BLOCK_RE = re.compile(r"```(?:[a-zA-Z0-9_]*)\n(.*?)```", re.DOTALL)
DEFAULT_TIMEOUT_S = 3.0
MAX_TIMEOUT_S = 30.0
OUTPUT_CAP_BYTES = 256 * 1024          # حد الخرج 256 KB

EXIT_PASS, EXIT_ASSERTION_FAIL = "pass", "assertion_fail"
EXIT_SYNTAX_ERROR, EXIT_TIMEOUT, EXIT_ERROR = "syntax_error", "timeout", "error"
EXIT_CODES = (EXIT_PASS, EXIT_ASSERTION_FAIL, EXIT_SYNTAX_ERROR, EXIT_TIMEOUT, EXIT_ERROR)

    total: int

def extract_code(text):
    m = CODE_BLOCK_RE.search(text)
    if m:
        return m.group(1)               # أول block مقفول
    if "```" in text:
        return None                     # block مفتوح ومش مقفول
    return text                         # مفيش backticks: النص كله كود

ده سكريبت كامل كـ string بيتبعت لـ Python جديد بـ -c. ركّز فيه لحد ما تقدر تتوقع الـ JSON اللي هيرجع.

  
RUNNER_TEMPLATE = r"""
import json, sys
import builtins as _builtins

_DENIED_MODULES = {
    'subprocess', 'socket', 'shutil', 'requests', 'urllib',
    'urllib.request', 'urllib.error', 'urllib.parse', 'ctypes',
    'http.client', 'asyncio.subprocess',
}
_real_import = _builtins.__import__
def _guarded_import(name, *args, **kwargs):
    base = name.split('.')[0]
    if name in _DENIED_MODULES or base in _DENIED_MODULES:
        raise ImportError("denied module: %s" % name)
    return _real_import(name, *args, **kwargs)
_builtins.__import__ = _guarded_import

import os as _os
def _denied_system(_cmd):
    raise OSError("os.system denied")
_os.system = _denied_system

CODE = __PLACEHOLDER_CODE__
ASSERTIONS = __PLACEHOLDER_ASSERTIONS__

ns = {}
status = {"exit_code": "pass", "results": [], "detail": ""}
try:
    compiled = compile(CODE, "<candidate>", "exec")
except SyntaxError as exc:
    status["exit_code"] = "syntax_error"
    status["detail"] = "SyntaxError: %s" % exc
    sys.stdout.write(json.dumps(status)); sys.exit(0)
except Exception as exc:
    status["exit_code"] = "error"
    status["detail"] = "compile error: %r" % exc
    sys.stdout.write(json.dumps(status)); sys.exit(0)

try:
    exec(compiled, ns)
except Exception as exc:
    status["exit_code"] = "error"
    status["detail"] = "exec error: %s" % exc
    sys.stdout.write(json.dumps(status)); sys.exit(0)

passed = 0
for assertion in ASSERTIONS:
    try:
        ok = bool(eval(assertion, ns))
    except Exception as exc:
        ok = False
        status["detail"] = "assertion error: %s" % exc
    status["results"].append(ok)
    if ok:
        passed += 1

if passed < len(ASSERTIONS):
    status["exit_code"] = "assertion_fail"
elif len(ASSERTIONS) > 0:
    status["exit_code"] = "pass"
sys.stdout.write(json.dumps(status))
""".strip()

def _build_runner(code, assertions):    # repr بيحوّل الكود لـ string literal آمن
    s = RUNNER_TEMPLATE.replace("__PLACEHOLDER_CODE__", repr(code))
    return s.replace("__PLACEHOLDER_ASSERTIONS__", repr(list(assertions)))

def run_candidate(code, assertions, timeout_s=DEFAULT_TIMEOUT_S):
    if not assertions:
        return ExecResult(0.0, EXIT_ERROR, 0, 0, detail="no assertions provided")
    timeout_s = min(max(0.1, float(timeout_s)), MAX_TIMEOUT_S)   # clamp
    script = _build_runner(code, assertions)
    try:
        proc = subprocess.Popen([sys.executable, "-I", "-c", script],   # -I: isolated mode
                                stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    except Exception as exc:
        return ExecResult(0.0, EXIT_ERROR, 0, len(assertions), detail=f"spawn error: {exc!r}")

    with proc:
        deadline = time.monotonic() + timeout_s
        chunks, nbytes, overflow, timed_out = [], 0, False, False
        fd = proc.stdout
        os.set_blocking(fd.fileno(), False)
        try:
            while True:
                remaining = deadline - time.monotonic()
                if remaining <= 0:
                    timed_out = True; break                     # الوقت خلص
                try:
                    r, _, _ = select.select([fd], [], [], min(remaining, 0.1))
                except (OSError, ValueError):
                    break
                if r:
                    chunk = fd.read(8192)
                    if chunk is None: continue
                    if chunk == b"": break                      # EOF
                    nbytes += len(chunk)
                    if nbytes > OUTPUT_CAP_BYTES:
                        overflow = True; break                  # طبع كتير
                    chunks.append(chunk)
                elif proc.poll() is not None:                   # خلص: اقرا الباقي
                    tail = fd.read()
                    if tail:
                        nbytes += len(tail)
                        if nbytes > OUTPUT_CAP_BYTES: overflow = True
                        else: chunks.append(tail)
                    break
        finally:
            if proc.poll() is None:
                proc.kill()                                     # اقتله لو لسه عايش
                try: proc.wait(timeout=1.0)
                except subprocess.TimeoutExpired: pass
            try: stderr_bytes = proc.stderr.read() if proc.stderr else b""
            except Exception: stderr_bytes = b""

    n = len(assertions)
    if timed_out:
        return ExecResult(0.0, EXIT_TIMEOUT, 0, n, detail=f"timeout after {timeout_s:.2f}s")
    if overflow:
        return ExecResult(0.0, EXIT_ERROR, 0, n, detail="output overflow")
    stdout = b"".join(chunks).decode("utf-8", errors="replace")
    if proc.returncode != 0:
        err = stderr_bytes.decode("utf-8", errors="replace")
        return ExecResult(0.0, EXIT_ERROR, 0, n, detail=f"subprocess exit {proc.returncode}: {err[:200]}")
    try:
        status = json.loads(stdout) if stdout else {}
    except json.JSONDecodeError:
        return ExecResult(0.0, EXIT_ERROR, 0, n, detail="non-json output")

    exit_code = status.get("exit_code", EXIT_ERROR)
    results = list(status.get("results", []))
    passed = sum(1 for r in results if r)
    score = passed / n
    if exit_code not in EXIT_CODES: exit_code = EXIT_ERROR        # تطبيع
    if exit_code == EXIT_PASS and passed < n: exit_code = EXIT_ASSERTION_FAIL
    if exit_code == EXIT_ASSERTION_FAIL and passed == n: exit_code = EXIT_PASS
    return ExecResult(score, exit_code, passed, n, status.get("detail", ""), results)

def score_code_exec(prediction, assertions, timeout_s=DEFAULT_TIMEOUT_S):
    code = extract_code(prediction)
    if code is None:
        return 0.0                              # block مش مقفول = صفر
    return run_candidate(code, assertions, timeout_s=timeout_s).score

def pass_at_k(n, c, k):
    if n < 0 or c < 0 or k <= 0:
        raise ValueError("n, c >= 0 and k > 0")
    if c > n:
        raise ValueError("c cannot exceed n")
    if k > n:
        return float(c > 0)
    if n - c < k:
        return 1.0                              # مستحيل تسحب k كلهم غلط
    log_prob = 0.0                              # C(n-c,k)/C(n,k) كحاصل ضرب في الـ log
    for i in range(k):
        log_prob += math.log(n - c - i) - math.log(n - i)
    return float(1.0 - math.exp(log_prob))

def pass_at_k_estimator(samples, ks):           # samples: list لكل مهمة فيها True/False
    out = {}
    for k in ks:
        per_task = [pass_at_k(len(s), sum(1 for x in s if x), k) for s in samples]
        out[k] = float(np.mean(per_task)) if per_task else 0.0
    return out

  4. Going further ١: حط الـ runner في Docker image عشان مشاكل SIGKILL على Windows تختفي.
      
    تلميحبدل [sys.executable, "-I", "-c", script] شغّل docker run --rm -i --network none python:3.12 python -I - وابعت السكريبت على الـ stdin. --network none بيقفل الشبكة بدل ما تعتمد على الـ denylist.
    5. 
    
  5. Going further ٢: بدّل الـ assertion strings بملف unit tests حقيقي.
      
    تلميحاكتب الكود في ملف مؤقت جوه tempfile.TemporaryDirectory() ومعاه test_candidate.py، وشغّل python -m unittest كـ subprocess، وعِد الـ tests اللي عدّت. الدرس بيقول صراحة إن الـ assertion strings «toy tests».
    6. 
    
  6. إضافة مني · تمرين شغل حقيقي: عندك موديل بيولّد ٢٠ حل لكل مسألة على ١٠٠ مسألة. اكتب سكريبت يقرا JSONL (سطر لكل generation: task_id، text)، ويشغّل score_code_exec، ويعتبر الـ sample ناجح لو score == 1.0، ويطلع pass@1 وpass@10 وجدول بعدد كل exit_code.
      
    تلميحاجمع لكل task_id list من booleans، وابعتها لـ pass_at_k_estimator(samples, [1, 10]). لعدّ الـ exit codes استخدم run_candidate مباشرة وcollections.Counter. لو نسبة timeout عالية، دي إشارة إن الـ timeout قصير أو الموديل بيكتب loops، والفرق ده بيبان من الـ detail.
    7.

إضافة مني: الحدس والأخطاء الشائعة وفين بيظهر ده

  
    
    
  • • pass@1 مش هو pass@k مقسوم: pass@k بيكبر بسرعة مع k. موديل pass@1 بتاعه 10% ممكن pass@10 بتاعه أعلى بكتير. لما تقارن موديلين اتأكد إن الـ k واحد.
    • 
    
  • • متستخدمش الصيغة الساذجة: 1−(1−c/n)^k بتفترض سحب مع إرجاع. الصيغة اللي في الدرس unbiased لأنها سحب من غير إرجاع من نفس الـ n samples. شوف الفرق في المعمل ٠٧.
    • 
    
  • • متحسبش C(n,k) مباشرة: مع n كبير الأرقام بتنفجر. عشان كده الكود بيجمع logs.
    • 
    
  • • الـ denylist مش أمان: __import__ ممكن يتلف عليه (مثلًا عن طريق importlib أو أوبجكتات موجودة). متشغّلش كود من الإنترنت بالـ runner ده من غير container.
    • 
    
  • • الـ timeout بيقيس وقت الـ host: على جهاز مشغول ممكن حل صح ياخد timeout. سجّل الـ exit code عشان تفرّق بين «غلط» و«بطيء».
    • 
    
  • • في الـ Agents: نفس الـ pattern (subprocess + timeout + output cap) هو اللي بيحمي أي agent عنده code interpreter tool، وهو أساس benchmarks زي SWE-bench اللي بتشغّل tests حقيقية.
    • 
    
  • • في الـ RL للكود: نسبة الـ assertions اللي عدّت بتستخدم كـ reward قابل للتحقق (verifiable reward) لما بيدربوا موديلات كود.

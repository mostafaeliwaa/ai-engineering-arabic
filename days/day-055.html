المشكلة والفلسفة: ليه JAX أصلًا؟

PyTorch بيشغّل العمليات واحدة واحدة من Python: كل tensor + tensor هي kernel launch لوحدها، وكل training step بيعيد تفسير نفس كود Python من الأول. ده ممتاز وانت بتجرّب، بس لما تيجي تدرب موديل بمئات المليارات من البارامترز على آلاف الـ TPUs، الـ overhead ده بيبقى مكلف جدًا.

الدرس بيقول إن Google DeepMind بتدرب Gemini على JAX، وإن Anthropic دربت Claude على JAX، والسبب إن JAX بيتعامل مع الـ training loop كـ برنامج يتعمله compile، مش سلسلة نداءات Python.

تشبيه: PyTorch زي مترجم فوري في مؤتمر: بيترجم كل جملة أول ما تتقال، مرن جدًا بس بيعيد الشغل كل مرة. JAX زي إنك تدي الخطبة لمترجم يترجمها مرة واحدة كاملة ويطبعها، وبعد كده أي حد يقراها بسرعة. بس عشان ده يشتغل، الخطبة لازم تبقى ثابتة: نفس الدخل يدي نفس الخرج.

JAX = NumPy + ٣ قوى خارقة: automatic differentiation، و JIT compilation لـ XLA، و automatic vectorization. بتكتب دالة لمثال واحد، و JAX يطلعلك منها دالة لـ batch، وبتحسب gradients، ومتكومبايلة، وبتشتغل على أجهزة كتير، من غير ما تغيّر الدالة الأصلية.

jax.numpy: نفس الوش اللي تعرفه

jax.numpy نفس أسماء دوال NumPy، ونفس قواعد الـ broadcasting، ونفس الـ slicing. الفرق إن الـ arrays عايشة على GPU/TPU، وكل عملية الكومبايلر يقدر يتتبعها.

import jax.numpy as jnp
a = jnp.array([1.0, 2.0, 3.0])
b = jnp.array([4.0, 5.0, 6.0])
c = jnp.dot(a, b)

# a[0] = 5          ← ممنوع! الـ arrays في JAX immutable
a = a.at[0].set(5)  # ← بيرجع array جديدة، والقديمة زي ما هي

الـ immutability دي هتضايقك أول أسبوع، وبعدين هتفهم إنها هي اللي بتخلي grad وjit وvmap يتركبوا فوق بعض من غير مفاجآت.

02

jax.grad: الـ gradient دالة، مش خانة في tensor

في PyTorch الـ gradient بيتلزق في الـ tensor (x.grad). في JAX الـ gradient بيتلزق في الدالة: jax.grad(f) بياخد دالة ويرجعلك دالة جديدة بتحسب المشتقة. مفيش .backward()، ومفيش graph متخزن على الـ tensors.

import jax
def f(x):
    return x ** 2

df  = jax.grad(f)           # دالة جديدة
df(3.0)                     # 6.0
d2f = jax.grad(jax.grad(f)) # المشتقة التانية بالتركيب
d2f(3.0)                    # 2.0

تقدر تركّب grad زي ما تحب: مشتقة تانية، تالتة، Jacobians، Hessians. PyTorch يقدر يعمل ده برضه (torch.autograd.functional.hessian) بس كإضافة، أما في JAX فهو الأساس.

القيد: grad بيشتغل على دوال pure بس. مفيش print جوه (هيتنفذ وقت الـ tracing مش وقت التنفيذ)، مفيش تعديل في state برا الدالة، ومفيش random من غير key صريح.
جرّب: اختار دالة وحرّك x. الخط البرتقالي هو المماس (ميله = f′)، والمنحنيات الباهتة هي f′ و f″ اللي طالعين من تركيب grad.
f(x)8
grad(f)(x)12
grad(grad(f))(x)12
03

jit: اعمل compile مرة، وشغّل ألف مرة

أول ما تنادي دالة عليها @jax.jit، JAX بيعمل tracing: بيشغّلها بقيم «وهمية» (abstract) عشان يسجّل العمليات اللي بتحصل من غير ما يحسب نتايج حقيقية. بعدين بيدّي التسجيل ده لـ XLA (Accelerated Linear Algebra)، الكومبايلر بتاع Google للـ TPUs والـ GPUs، اللي بيدمج العمليات (fusion)، ويشيل نسخ الذاكرة الزيادة، ويطلّع machine code متظبط.

المرات اللي بعد كده Python مش بيتلمس خالص: الكود المتكومبايل بيشتغل على الـ accelerator مباشرة.

الـ JIT بيفيدالـ JIT بيضر
training steps (نفس الحساب آلاف المرات)control flow بيعتمد على القيم (if x > 0 و x traced)
inference (نفس الموديل، دخل مختلف)حسابة بتتعمل مرة واحدة (الـ compile أغلى من التشغيل)
أي دالة بتتنادى كذا مرة بـ shapes شبه بعضالـ debugging (الـ tracing بيخبي التنفيذ الحقيقي)

بدل if/else بتستخدم jax.lax.cond، وبدل for بتستخدم jax.lax.scan (أو jax.lax.fori_loop). دول مش اختياريين؛ ده تمن الـ compilation.

المعمل ده توضيحي: الأرقام مش قياس حقيقي، هي موديل بسيط للفكرة: eager = تكلفة ثابتة كل نداء (overhead + تشغيل)، و jit = تكلفة compile كبيرة أول مرة وبعدين نداء رخيص. حرّك وشوف نقطة التعادل. قِس الرقم الحقيقي بنفسك في التمرين ٤.

vmap: اكتب لمثال واحد، واشتغل على batch

def predict(params, x):            # مثال واحد بس
    return jnp.dot(params['w'], x) + params['b']

batch_predict = jax.vmap(predict, in_axes=(None, 0))

in_axes=(None, 0) معناها: params متقسمهاش (مشتركة بين كل الأمثلة)، وx قسّمها على المحور 0. مفيش loop يدوي، ومفيش reshape، ومفيش إنك تمرر batch dimension في كل حتة.

ده مش سكر في الكتابة: vmap بيطلّع كود vectorized مدموج، والدرس بيقول إنه أسرع من loop في Python بـ 10-100 مرة. وكمان بيتركب مع jit وgrad:

per_example_grads = jax.vmap(jax.grad(loss_fn), in_axes=(None, 0, 0))

gradient لكل مثال لوحده في سطر واحد. الدرس بيقول إن ده تقريبًا مستحيل في PyTorch من غير حيل.

جرّب: شغّل «Python loop» وشوف الأمثلة بتعدي واحد واحد، وبعدين «vmap» وشوفهم بيعدوا مرة واحدة. غيّر in_axes للـ params لـ 0 وشوف إيه اللي بيبوظ.
x.shape = (5, 3) ← out.shape = (5,)

pmap و pytrees والـ random keys

pmap: نفس الدالة على كل الأجهزة

parallel_step = jax.pmap(train_step, axis_name='devices')

pmap بينسخ الدالة على كل الأجهزة المتاحة (GPUs/TPUs) ويقسم الـ batch عليهم. جوه الدالة، jax.lax.pmean وjax.lax.psum بيوحّدوا الـ gradients بين الأجهزة. الدرس بيذكر إن خليفته اسمه shard_map. الطريقة: اكتب نسخة لجهاز واحد، لفّها بـ pmap، وخلاص.

تشبيه: عندك ٨ طباخين وكل واحد معاه نفس الوصفة (نفس الدالة)، وقسمت الطلبات عليهم. في الآخر كلهم بيتفقوا على متوسط واحد للتعديلات (pmean) عشان الوصفة تفضل واحدة عند الكل.

Pytrees: الموديل هو الشجرة

الـ pytree هو أي تركيبة متداخلة من lists و tuples و dicts و arrays. بارامترات الموديل pytree:

params = {
    'layer1': {'w': jnp.zeros((784, 256)), 'b': jnp.zeros(256)},
    'layer2': {'w': jnp.zeros((256, 128)), 'b': jnp.zeros(128)},
    'layer3': {'w': jnp.zeros((128, 10)),  'b': jnp.zeros(10)},
}
# تحديث كل الأوراق مرة واحدة = SGD كامل
params = jax.tree.map(lambda p, g: p - lr * g, params, grads)

كل تحويلات JAX عارفة تمشي على الـ pytrees. jax.tree.map(f, tree) بيطبّق f على كل ورقة. مفيش .parameters() ومفيش تسجيل للبارامترز: شكل الشجرة هو الموديل.

جرّب: اضغط «خطوة SGD» وشوف كل ورقة في الشجرة اتحدثت بنفس القاعدة، وإن الشجرة القديمة فضلت زي ما هي (immutable): بيطلع params جديدة.

خطوة ١: الداتا

import jax
import jax.numpy as jnp
from jax import random
import optax

def get_mnist_data():
    from sklearn.datasets import fetch_openml
    mnist = fetch_openml('mnist_784', version=1, as_frame=False, parser='auto')
    X = mnist.data.astype('float32') / 255.0   # البيكسلز من 0 لـ 1
    y = mnist.target.astype('int')
    X_train, X_test = X[:60000], X[60000:]
    y_train, y_test = y[:60000], y[60000:]
    return X_train, y_train, X_test, y_test

خطوة ٢: init_params — مفيش class، دالة بترجع pytree

def init_params(key):
    k1, k2, k3 = random.split(key, 3)          # ٣ مفاتيح من seed واحد
    scale1 = jnp.sqrt(2.0 / 784)               # He init بإيدنا (درس ٥١)
    scale2 = jnp.sqrt(2.0 / 256)
    scale3 = jnp.sqrt(2.0 / 128)
    params = {
        'layer1': {'w': scale1 * random.normal(k1, (784, 256)), 'b': jnp.zeros(256)},
        'layer2': {'w': scale2 * random.normal(k2, (256, 128)), 'b': jnp.zeros(128)},
        'layer3': {'w': scale3 * random.normal(k3, (128, 10)),  'b': jnp.zeros(10)},
    }
    return params

خطوة ٣: forward و loss — دوال pure

def forward(params, x):
    x = jnp.dot(x, params['layer1']['w']) + params['layer1']['b']
    x = jax.nn.relu(x)
    x = jnp.dot(x, params['layer2']['w']) + params['layer2']['b']
    x = jax.nn.relu(x)
    x = jnp.dot(x, params['layer3']['w']) + params['layer3']['b']
    return x                                    # logits

def loss_fn(params, x, y):
    logits = forward(params, x)
    one_hot = jax.nn.one_hot(y, 10)
    # cross-entropy من الصفر: log_softmax × one_hot، وبعدين سالب المتوسط
    return -jnp.mean(jnp.sum(jax.nn.log_softmax(logits) * one_hot, axis=-1))

خطوة ٤: train_step متكومبايل

optimizer = optax.adam(learning_rate=1e-3)

@jax.jit
def train_step(params, opt_state, x, y):
    loss, grads = jax.value_and_grad(loss_fn)(params, x, y)        # الـ loss والـ grads في لفة واحدة
    updates, opt_state = optimizer.update(grads, opt_state, params) # Adam يحوّل الـ grads
    params = optax.apply_updates(params, updates)                   # params جديدة، مش تعديل في المكان
    return params, opt_state, loss

@jax.jit
def accuracy(params, x, y):
    preds = jnp.argmax(forward(params, x), axis=-1)
    return jnp.mean(preds == y)

خطوة ٥: الـ training loop

X_train, y_train, X_test, y_test = get_mnist_data()
X_train, X_test = jnp.array(X_train), jnp.array(X_test)
y_train, y_test = jnp.array(y_train), jnp.array(y_test)

key = random.PRNGKey(0)
params = init_params(key)
opt_state = optimizer.init(params)
batch_size, n_epochs = 128, 10

for epoch in range(n_epochs):
    key, subkey = random.split(key)                     # مفتاح جديد كل epoch للـ shuffle
    perm = random.permutation(subkey, len(X_train))
    X_shuffled, y_shuffled = X_train[perm], y_train[perm]
    epoch_loss = 0.0
    n_batches = len(X_train) // batch_size
    for i in range(n_batches):
        start = i * batch_size
        xb = X_shuffled[start:start + batch_size]
        yb = y_shuffled[start:start + batch_size]
        params, opt_state, loss = train_step(params, opt_state, xb, yb)
        epoch_loss += loss
    train_acc = accuracy(params, X_train[:5000], y_train[:5000])
    test_acc = accuracy(params, X_test, y_test)
    print(f"Epoch {epoch + 1:2d} | Loss: {epoch_loss / n_batches:.4f} | "
          f"Train Acc: {train_acc:.4f} | Test Acc: {test_acc:.4f}")

لاحظ اللي مش موجود: لا .zero_grad() ولا .backward() ولا .step(). التحديث كله نداء واحد متركب جوه train_step. أول epoch بطيء (الـ JIT بيكومبايل) والباقي سريع.

# Flax: رجّع nn.Module بس الـ params برا الموديل
import flax.linen as nn
class MLP(nn.Module):
    @nn.compact
    def __call__(self, x):
        x = nn.relu(nn.Dense(256)(x))
        x = nn.relu(nn.Dense(128)(x))
        return nn.Dense(10)(x)

model = MLP()
params = model.init(jax.random.PRNGKey(0), jnp.ones((1, 784)))  # بيعمل الـ params
logits = model.apply(params, x_batch)                            # الموديل نفسه ملوش state

# Equinox: الموديل نفسه pytree، من غير apply
import equinox as eqx
model = eqx.nn.MLP(in_size=784, out_size=10, width_size=256, depth=2,
                   activation=jax.nn.relu, key=jax.random.PRNGKey(0))
logits = model(x)

# Optax: warmup + cosine + clipping + weight decay في سلسلة واحدة (درس ٥٢)
schedule = optax.warmup_cosine_decay_schedule(
    init_value=0.0, peak_value=1e-3, warmup_steps=1000, decay_steps=50000)
optimizer = optax.chain(
    optax.clip_by_global_norm(1.0),
    optax.adamw(learning_rate=schedule, weight_decay=0.01))

التمارين

اعمل ٢ على الأقل النهاردة (أنصحك بـ ٢ و ٤).

  1. Dropout: ضيف dropout للـ MLP. في JAX الـ dropout محتاج PRNG key: مرّر key في الـ forward، واقسمه لكل dropout layer. قارن الـ test accuracy بيه ومن غيره.
    تلميحforward(params, x, key, train=True). جوه: k1, k2 = random.split(key)، والماسك random.bernoulli(k1, keep, x.shape)، وx = jnp.where(mask, x / keep, 0) (inverted dropout من درس ٥٠). في الـ accuracy شغّل من غير dropout. في الـ loop اعمل key, sub = random.split(key) كل step ومتعيدش نفس الـ key.
  2. Per-example gradients: استخدم jax.vmap عشان تحسب gradient لكل صورة في batch من 32. احسب الـ norm لكل واحد. أنهي أمثلة الـ gradient بتاعها أكبر، وليه؟
    تلميحloss_fn متعمول لـ batch، فاعمل نسخة لمثال واحد بتعمل x[None] وy[None]. g = jax.vmap(jax.grad(single_loss), in_axes=(None,0,0))(params, xb, yb). الـ norm: jnp.sqrt(sum(jnp.sum(l**2, axis=tuple(range(1,l.ndim))) for l in jax.tree.leaves(g))). هتلاقي الأكبر غالبًا الأمثلة اللي الموديل غلطان فيها أو مش واثق، لأن الـ cross-entropy gradient بيكبر لما الاحتمال الصح يبقى صغير.
  3. MLP عام: بدّل الـ forward اليدوي بـ mlp_forward(params, x) يشتغل مع أي عدد طبقات. استخدم jax.tree.leaves عشان تعرف العمق.
    تلميحخلي params list من dicts. n = len(jax.tree.leaves(params)) // 2 (كل طبقة w و b). اعمل loop على أول n−1 طبقة بـ relu والأخيرة من غير. الـ Python loop هنا تمام جوه jit لأن عدد الطبقات ثابت وقت الـ tracing (مش قيمة traced).
  4. Benchmark: قِس train_step بـ @jax.jit ومن غيره لـ 100 step. السرعة اتضاعفت كام مرة عندك؟ وتكلفة الـ compile في أول نداء قد إيه؟
    تلميحاستخدم time.perf_counter()، وقيس أول نداء لوحده. لازم تعمل .block_until_ready() على الناتج، لأن JAX بيشتغل asynchronous ومن غيرها هتقيس وقت الإرسال بس (زي demo_jit في ملف الدرس). قارن رقمك بالمعمل ٠٣.
  5. Gradient clipping: استخدم optax.chain(optax.clip_by_global_norm(1.0), optax.adam(1e-3)). درّب بيه ومن غيره، وارسم الـ gradient norm على مدار التدريب.
    تلميحرجّع optax.global_norm(grads) من train_step كقيمة رابعة، واجمعهم في list وارسمهم بـ matplotlib. لاحظ إن الـ norm اللي بتحسبه هو قبل القص.
  6. إضافة مني · تقييم embeddings بـ vmap: في شغل RAG بتحتاج تحسب cosine similarity بين سؤال و1000 document. اكتب cos(q, d) لمتجهين بس، وبعدين jax.vmap(cos, in_axes=(None, 0)) على مصفوفة documents (1000, 384) عشوائية، ولفّها بـ jax.jit، وطلّع أعلى ٥ بـ jnp.argsort. خطوة كمان: vmap تاني بـ in_axes=(0, None) عشان 50 سؤال مرة واحدة ← مصفوفة (50, 1000).
    تلميحcos = lambda q, d: jnp.dot(q, d) / (jnp.linalg.norm(q) * jnp.linalg.norm(d)). all_q = jax.vmap(jax.vmap(cos, (None, 0)), (0, None)). اتأكد إن الناتج بيساوي Qn @ Dn.T بعد ما تعمل normalize للصفوف (jnp.allclose).

إضافة مني: اللي الدرس ما قالهوش صريح

الحدس: JAX «بيقرا» دالتك مرة واحدة بس

أهم فكرة تمسكها: جوه jit، الـ Python بيتنفذ مرة واحدة وقت الـ tracing بقيم وهمية (shape و dtype بس). أي حاجة Python عادية (print، append في list برا الدالة، if على قيمة) بتحصل في اللحظة دي وخلاص، ومش هتتكرر في كل نداء. عشان كده:

  • • غلطة: print(loss) جوه train_step بيطبع حاجة زي Traced<...> مرة واحدة وبعدين يسكت. الحل: jax.debug.print("{}", loss) أو اطبع برا.
  • • غلطة: if x > 0: على array traced بيضرب error. الحل: jnp.where أو jax.lax.cond.
  • • غلطة: تغيير الـ shape كل نداء (batch آخره أصغر مثلًا) بيعمل re-compile جديد لكل shape. خلي الـ batches بنفس الحجم (الكود بتاعنا بيرمي آخر batch ناقص بـ // batch_size).
  • • غلطة: استخدام نفس الـ key مرتين = نفس الأرقام العشوائية بالظبط (نفس ماسك الـ dropout كل step!). دايمًا split.
  • • غلطة: القياس من غير block_until_ready() بيديك أرقام سريعة بشكل كاذب.

فين ده بيظهر في الـ LLMs والـ agents؟

تدريب الموديلات الكبيرة هو أكتر مكان الـ jit و pmap/sharding بيفرقوا فيه، لأن نفس الـ step بيتكرر ملايين المرات على آلاف الشرايح. والـ per-example gradients (vmap+grad) هي حجر أساس في تقنيات زي differential privacy (قص gradient كل مثال لوحده) وتحليل أنهي أمثلة في الداتا مأثرة على الموديل. وحتى لو هتفضل PyTorch، الأفكار دي دخلت هناك: torch.compile فكرته compile للدالة، وtorch.func فيه vmap وgrad بأسلوب functional. فاللي اتعلمته النهاردة طريقة تفكير، مش مكتبة وبس.

قاعدة عملية: اكتب الدالة لمثال واحد ← اتأكد إنها صح من غير jit ← ضيف vmap ← ضيف grad ← ضيف jit في الآخر. لو حاجة باظت، شيل الـ jit الأول وابدأ debug.

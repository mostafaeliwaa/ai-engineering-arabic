مشكلة التماثل: ٥١٢ نيورون بيشتغلوا كأنهم واحد

كل نيورون في الـ layer ليه نفس الشكل: يضرب الـ inputs في weights، يزوّد bias، ويعدّي على activation. لو كل الـ weights بدأت بنفس القيمة (والصفر هو أبسط مثال)، كل النيورونز هتطلّع نفس الناتج.

وقت الـ backpropagation كل واحد هياخد نفس الـ gradient، فيتعدّل بنفس المقدار. يعني هيفضلوا توأم للأبد. بعد ١٠٬٠٠٠ epoch، الـ hidden layer اللي فيها ٥١٢ نيورون لسه ٥١٢ نسخة من نفس النيورون. دفعت تمن ٥١٢ وخدت واحد.

ده اسمه symmetry، والحل البدائي هو symmetry breaking: نبدأ عشوائي، فكل نيورون يبتدي من نقطة مختلفة ويتعلم feature مختلفة.

تشبيه: تخيل ٤ طلبة بيحلّوا نفس المسألة، بنفس الكراسة، وبيصححلهم نفس المدرس بنفس الملاحظة. عمرهم ما هيطلعوا بأفكار مختلفة. لازم كل واحد يبدأ من زاوية مختلفة.
جرب بإيدك: شغّل التدريب بـ «كله صفر» وشوف الـ ٤ خطوط (weights النيورونز) فوق بعض طول الوقت. بعدين جرب «عشوائي» وشوفهم بيتفرقوا وكل واحد بيروح لحتة.

02

العشوائية مش كفاية: الـ scale هو اللي بيحكم

خد layer واحدة فيها fan_in input:

z = w₁x₁ + w₂x₂ + … + wₙxₙ

لو كل weight ليها variance Var(w) وكل input ليه Var(x)، فالـ variance بتاعة الناتج:

Var(z) = fan_in · Var(w) · Var(x)

يعني كل layer بتضرب الإشارة في رقم ثابت = fan_in · Var(w). ومع ٥٠ layer بنضرب في نفس الرقم ٥٠ مرة:

الحالةالمضاعف لكل layerبعد ١٠ layers
Var(w)=1, fan_in=512512512¹⁰ ≈ 1.2×10²⁷ → انفجار
Var(w)=0.001, fan_in=5120.5120.512¹⁰ ≈ 0.00013 → اختفاء
الهدف11¹⁰ = 1 → ثابتة

الهدف إذن: نختار Var(w) بحيث Var(z) = Var(x). الإشارة تفضل نفس الحجم في كل layer. والمسافة بين «شغال» و«بايظ» رفيعة جدًا: N(0,1) ممكن تشتغل في ٣ layers، لكن في ٥٠ يا بتنفجر يا بتموت.

تشبيه: لعبة التليفون المكسور بين ٥٠ واحد. لو كل واحد بيعلّي صوته شوية عن اللي قبله، الأخير هيزعق. لو كل واحد بيوطّي شوية، الأخير مش هيسمع حاجة. لازم كل واحد يقول بنفس الصوت بالظبط.

Xavier / Glorot (2010): للـ sigmoid والـ tanh

Glorot و Bengio عايزين الـ variance تفضل ثابتة في الاتجاهين: الـ forward (بيعتمد على fan_in) والـ backward (الـ gradients بتعتمد على fan_out). فخدوا حل وسط:

Var(w) = 2 / (fan_in + fan_out)

وفي التطبيق بنسحب الأرقام من واحد من التوزيعين دول:

Uniform(−limit, limit), limit = √(6 / (fan_in + fan_out))
Normal(0, std = √(2 / (fan_in + fan_out)))

ليه بيشتغل مع sigmoid و tanh؟ لأنهم تقريبًا خطيين جنب الصفر، وده بالظبط المكان اللي الـ activations بتعيش فيه لو الـ init مظبوط.

منين جه الـ 6 في الـ Uniform؟الـ variance بتاعة Uniform(−a, a) هي a²/3. عايزينها تساوي 2/(fan_in+fan_out)، يبقى a² = 6/(fan_in+fan_out).

Kaiming / He (2015): للـ ReLU والـ GELU

الـ ReLU بيصفّر كل حاجة سالبة، يعني في المتوسط نص الـ inputs بتبقى صفر. كأن الـ fan_in الفعلي اتقسم على ٢. Xavier مش واخد باله من ده، فبيدي variance أقل من اللازم والإشارة بتنكمش للنص تقريبًا كل layer. مع ٥٠ layer: 0.5⁵⁰ ≈ 8.8×10⁻¹⁶.

Var(w) = 2 / fan_in w ~ Normal(0, √(2 / fan_in))

الـ 2 دي بالظبط بتعوّض النص اللي الـ ReLU بيرميه. ونفس الكلام بيتطبق على GELU و Swish.

معمل: عدّي إشارة في ٥٠ layer

ده نفس تجربة الكود: داتا عشوائية N(0,1) بتعدّي في شبكة عميقة، وبنقيس متوسط |activation| في كل layer. المحور الرأسي log scale، والشريط الأخضر هو المنطقة الصحية (0.5 لـ 2) اللي الدرس بيقول تتأكد إن الإشارة جواها.

جرب كده:

  1. N(0,1) + ReLU → شوفها بتطير.
  2. N(0,0.01) + ReLU → شوفها بتموت.
  3. Xavier + ReLU → بتنكمش ببطء (الـ 2 ناقصة).
  4. Kaiming + ReLU و Xavier + Tanh → ثابتة.

الـ Transformers: كل جمعة بتكبّر الـ variance

الـ Transformer فيه residual connections: ناتج كل sub-layer بيتجمع على الـ input بتاعه:

x = x + sublayer(x)

كل جمعة بتزوّد الـ variance. مع N residual layer الـ variance بتكبر بشكل متناسب مع N. الـ GPT-2 حل ده إنه بيضرب weights الـ residual layers في 1/√(2N) (N = عدد الـ layers)، فالإشارة المتراكمة تفضل مستقرة.

Llama 3 (405B parameter و 126 layer) بيستخدم فكرة شبيهة. من غير الـ scaling ده، الـ residual stream كان هيكبر من غير حد عبر ١٢٦ layer من attention و feedforward.

تشبيه: حصّالة كل يوم بتحط فيها فلوس. بعد ١٢٦ يوم هتبقى مليانة على الآخر. الـ 1/√(2N) كأنك بتقول: كل يوم حط فكة صغيرة بحيث المجموع في الآخر يبقى معقول.
جرب: كبّر عدد الـ layers وقارن الخطين. المعمل بيعمل pre-LayerNorm زي GPT-2: كل sublayer بتاخد LN(x) وتطلّع حاجة variance بتاعتها ثابتة، فالـ std بتاع الـ stream بيزيد مع الجذر التربيعي لعدد الجمعات.

في PyTorch

import torch
import torch.nn as nn

layer = nn.Linear(512, 256)

nn.init.xavier_uniform_(layer.weight)                         # Xavier بتوزيع uniform
nn.init.xavier_normal_(layer.weight)                          # Xavier بتوزيع normal

nn.init.kaiming_uniform_(layer.weight, nonlinearity='relu')   # Kaiming للـ ReLU

nn.init.zeros_(layer.bias)                                    # الـ bias صفر عادي

خطوة ١: الـ ٤ استراتيجيات

import math
import random

# كل دالة بترجع مصفوفة: fan_out صف × fan_in عمود
def zero_init(fan_in, fan_out):
    return [[0.0 for _ in range(fan_in)] for _ in range(fan_out)]

def random_init(fan_in, fan_out, scale=1.0):          # scale ثابت مش بيبص على fan_in
    return [[random.gauss(0, scale) for _ in range(fan_in)] for _ in range(fan_out)]

def xavier_init(fan_in, fan_out):
    std = math.sqrt(2.0 / (fan_in + fan_out))          # Var = 2/(in+out)
    return [[random.gauss(0, std) for _ in range(fan_in)] for _ in range(fan_out)]

def kaiming_init(fan_in, fan_out):
    std = math.sqrt(2.0 / fan_in)                      # Var = 2/in  (الـ 2 عشان ReLU)
    return [[random.gauss(0, std) for _ in range(fan_in)] for _ in range(fan_out)]

خطوة ٢: الـ activations

def sigmoid(x):
    x = max(-500, min(500, x))      # نمنع overflow في exp
    return 1.0 / (1.0 + math.exp(-x))

def tanh_act(x):
    return math.tanh(x)

def relu(x):
    return max(0.0, x)

خطوة ٣: الـ forward في ٥٠ layer وقياس الحجم

def forward_deep(init_fn, activation_fn, n_layers=50, width=64, n_samples=100):
    random.seed(42)
    layer_magnitudes = []
    inputs = [[random.gauss(0, 1) for _ in range(width)] for _ in range(n_samples)]

    for layer_idx in range(n_layers):
        weights = init_fn(width, width)            # layer جديدة بـ init جديد
        biases = [0.0] * width
        new_inputs = []
        for sample in inputs:
            output = []
            for neuron_idx in range(width):
                z = sum(weights[neuron_idx][j] * sample[j] for j in range(width)) + biases[neuron_idx]
                output.append(activation_fn(z))
            new_inputs.append(output)
        inputs = new_inputs

        # متوسط |activation| على كل العينات
        magnitudes = [sum(abs(v) for v in s) / width for s in inputs]
        layer_magnitudes.append(sum(magnitudes) / len(magnitudes))

    return layer_magnitudes

خطوة ٤: التجربة الكبيرة

def run_experiment():
    configs = [
        ("Zero + Sigmoid", lambda fi, fo: zero_init(fi, fo), sigmoid),
        ("Random N(0,1) + ReLU", lambda fi, fo: random_init(fi, fo, 1.0), relu),
        ("Random N(0,0.01) + ReLU", lambda fi, fo: random_init(fi, fo, 0.01), relu),
        ("Xavier + Sigmoid", xavier_init, sigmoid),
        ("Xavier + Tanh", xavier_init, tanh_act),
        ("Kaiming + ReLU", kaiming_init, relu),
    ]
    print(f"\n{'Strategy':<30} {'L1':>10} {'L5':>10} {'L10':>10} {'L25':>10} {'L50':>10}")
    print("-" * 80)
    all_results = {}
    for name, init_fn, act_fn in configs:
        mags = forward_deep(init_fn, act_fn)
        all_results[name] = mags
        row = f"{name:<30}"
        for idx in [0, 4, 9, 24, 49]:              # layers 1, 5, 10, 25, 50
            val = mags[idx]
            if val > 1e6:
                row += f" {'EXPLODED':>10}"
            elif val < 1e-6:
                row += f" {'VANISHED':>10}"
            else:
                row += f" {val:>10.4f}"
        print(row)
    return all_results

def symmetry_demo():
    weights = zero_init(2, 4)       # ٤ نيورونز، كل واحد ليه ٢ inputs
    biases = [0.0] * 4
    inputs = [0.5, -0.3]
    outputs = []
    for neuron_idx in range(4):
        z = sum(weights[neuron_idx][j] * inputs[j] for j in range(2)) + biases[neuron_idx]
        outputs.append(sigmoid(z))

    print("Symmetry Demo (4 neurons, zero init):")
    for i, out in enumerate(outputs):
        print(f"  Neuron {i}: output = {out:.6f}")
    all_same = all(abs(outputs[i] - outputs[0]) < 1e-10 for i in range(len(outputs)))
    print(f"  All identical: {all_same}")
    print(f"  Effective parameters: 1 (not {len(weights) * len(weights[0])})")

خطوة ٦: تحليل الـ variance لـ layer واحدة

الملف الأصلي فيه variance_analysis(): بتعمل ١٠٬٠٠٠ تجربة بـ fan_in=64، وتحسب متوسط z² لكل استراتيجية. المتوقع من المعادلة: Var(z) ≈ 64 · Var(w)، يعني حوالي 64 لـ N(0,1)، وحوالي 0.0064 لـ N(0,0.01)، وحوالي 1 لـ Xavier (لأن fan_in = fan_out)، وحوالي 2 لـ Kaiming. قارن الأرقام اللي هتطلعلك بالتوقع ده.

def variance_analysis():
    fan_in, n_trials = 64, 10000
    configs = [
        ("Random N(0,1)", 1.0),
        ("Random N(0,0.01)", 0.01),
        ("Xavier std", math.sqrt(2.0 / (fan_in + fan_in))),
        ("Kaiming std", math.sqrt(2.0 / fan_in)),
    ]
    for name, std in configs:
        random.seed(42)
        output_vars = []
        for _ in range(n_trials):
            inputs = [random.gauss(0, 1) for _ in range(fan_in)]     # Var(x)=1
            weights = [random.gauss(0, std) for _ in range(fan_in)]
            z = sum(w * x for w, x in zip(weights, inputs))
            output_vars.append(z * z)                                 # المتوسط صفر، فـ E[z²] = Var(z)
        print(f"  {name:<25} {std*std:>12.6f} {sum(output_vars)/n_trials:>12.4f}")

def magnitude_report(name, magnitudes):
    print(f"\n{name}:")
    for i, mag in enumerate(magnitudes):
        if i % 5 == 0 or i == len(magnitudes) - 1:     # كل ٥ layers + الأخيرة
            if mag > 1e6:
                bar = "X" * 50 + " EXPLODED"
            elif mag < 1e-6:
                bar = "." + " VANISHED"
            else:
                bar = "#" * min(50, max(1, int(mag * 10)))
            print(f"  Layer {i+1:3d}: {bar} ({mag:.6f})")

التمارين

اعمل ٢ على الأقل النهاردة، والباقي في التسخين بكرة.

  1. LeCun init: ضيف Var = 1/fan_in (اتعملت للـ SELU). شغّل تجربة الـ ٥٠ layer بـ LeCun + tanh وقارن بـ Xavier + tanh.
    تلميحstd = math.sqrt(1.0 / fan_in). لما fan_in = fan_out (زي التجربة، width=64) الاتنين بيطلعوا نفس الـ variance بالظبط: 2/(64+64) = 1/64. فالفرق هيبان بس لو الـ layers مش مربعة. جربها في المعمل ٠٢ (اختار LeCun).
  2. GPT-2 residual scaling: اضرب ناتج كل layer في 1/√(2N) قبل ما تجمعه على الـ residual stream. شغّل ٥٠ layer بالـ scaling ومن غيره وقيس سرعة كبر الحجم.
    تلميحx = [xi + s * oi for xi, oi in zip(x, layer_out)] و s = 1/math.sqrt(2*N) أو s = 1. اطبع std الـ stream كل ٥ layers. المعمل ٠٣ هيوريك الشكل المتوقع.
  3. Init health check: دالة بتاخد أبعاد الـ layers ونوع الـ activation، وترشّح الـ init الصح، وتحذّر لو الـ init الحالي هيعمل مشكلة.
    تلميحاحسب لكل layer gain = fan_in · Var(w) (واضرب في 0.5 لو ReLU). لو gain^عدد_الـlayers بره [0.5, 2] اطبع تحذير. والترشيح من جدول المحطة ٠٤.
  4. fan_in = 16 مقابل 1024: شغّل التجربة بالحجمين. Xavier و Kaiming بيتأقلموا مع fan_in، الـ random لأ. ورّي إن الفجوة بين «شغال» و«بايظ» بتوسع مع الـ layers الأكبر.
    تلميحمع N(0,1) المضاعف لكل layer = fan_in، يعني 16 مقابل 1024. جرب في المعمل ٠٢ بين width=16 و width=128 وشوف الانفجار بيبدأ إمتى. (1024 بـ pure Python هتبقى بطيئة، قلّل n_samples.)
  5. Orthogonal init: اعمل مصفوفة عشوائية، خد الـ SVD بتاعها، واستخدم المصفوفة الـ orthogonal U. قارنها بـ Kaiming في شبكة ReLU بـ ٥٠ layer.
    تلميحبـ NumPy: U, _, _ = np.linalg.svd(np.random.randn(n, n)). المصفوفة الـ orthogonal بتحافظ على طول المتجه بالظبط. بس مع ReLU هتلاقي نفس مشكلة النص، فجرب تضربها في √2 وقارن.
  6. إضافة مني · فحص init حقيقي بالـ hooks: اعمل في PyTorch شبكة nn.Sequential فيها ٣٠ Linear(256,256) + ReLU. سجّل register_forward_hook على كل Linear يطبع std الناتج لـ batch عشوائي. جرب الـ init الافتراضي، وبعدين kaiming_normal_، وبعدين xavier_normal_. ده نفس الفحص اللي بتعمله قبل ما تصرف ساعات GPU على تدريب.
    تلميحh = lambda m, i, o: stds.append(o.std().item()) ثم for m in net: if isinstance(m, nn.Linear): m.register_forward_hook(h). شغّل with torch.no_grad(): net(torch.randn(512, 256)) وارسم stds.

إضافة مني: اللي الدرس ماقالوش صريح

الـ intuition في سطر

كل layer عبارة عن «مكبّر صوت» معامله fan_in · Var(w) (ونص ده لو ReLU). الشبكة العميقة = مكبّرات ورا بعض. أي معامل مختلف عن 1 حتى بشوية، بيتضرب في نفسه ٥٠ مرة. 1.1⁵⁰ ≈ 117 و 0.9⁵⁰ ≈ 0.005. عشان كده الـ init «الصح» مش رفاهية.

أخطاء شائعة

  • • تستخدم Xavier مع ReLU: الإشارة بتنكمش ببطء، ومش هتاخد بالك في ٣ layers بس هتلاحظ في ٣٠.
  • • تصفّر الـ weights وتقول «الـ bias هيكسر التماثل»: لأ، لو الـ biases كمان متساوية الـ gradients هتفضل متساوية.
  • • تفتكر إن الإشارة الثابتة = شبكة صحية: zero + sigmoid ثابتة عند 0.5 وهي ميتة (شفتها في المعمل ٠٢).
  • • تبني Transformer من الصفر وتنسى الـ residual scaling: الـ loss بيبقى غريب أو بينفجر في أول التدريب.
  • • تفتكر إن الـ PyTorch default دايمًا كفاية: هو Kaiming uniform بس بمعامل خاص (a=√5) بيخلّي الحد 1/√fan_in، يعني أصغر من Kaiming الكامل للـ ReLU. للشبكات العميقة اختار بنفسك صراحة.

فين بيظهر في الـ LLMs والـ Agents؟

لما تعمل fine-tuning بـ LoRA (Day 1)، مصفوفة B بتبدأ صفر و A عشوائية. ده مش غلط تماثل: الهدف إن ΔW = B·A = 0 في البداية، فالموديل يبدأ بالظبط زي الأصلي، والعشوائية في A كفاية تكسر التماثل لما B تبدأ تتحرك. ده مثال إن «الصفر» أحيانًا اختيار مقصود لما في layer تانية عشوائية.

ولما بتضيف head جديدة (classifier أو reward head) فوق موديل متدرب، الـ init بتاعها بيحدد هل أول خطوات التدريب هتبوّظ الـ features المتعلمة ولا لأ. فبنبدأها بأرقام صغيرة عشان التأثير يبقى هادي في الأول.

الشجرة = سلسلة أسئلة أيوه/لأ

تخيل موظف بنك بيقرر يدي قرض ولا لأ. بيسأل: «سنك أقل من ٣٠؟» لو أيوه: «دخلك فوق ٥٠ ألف؟» لو لأ: «الـ credit score فوق ٧٠٠؟». كل سؤال بيوديك فرع، وفي الآخر بتوصل لورقة (leaf) فيها القرار.

Age < 30? ─yes→ Income > 50k? ─yes→ Approve / ─no→ Deny └─no→ Credit > 700? ─yes→ Approve / ─no→ Deny
  • كل node داخلية بتختبر feature واحدة قصاد threshold: x[j] <= t؟
  • كل leaf فيها التوقع.
  • عشان تصنّف نقطة جديدة: ابدأ من الـ root وامشي مع الإجابات لحد ورقة.

هندسيًا، كل سؤال بيقطع الفضاء بخط موازي لمحور. فالشجرة كلها بتقسم الفضاء لـ مستطيلات، وكل مستطيل ليه لون (class). الشجرة بتتبني من فوق لتحت: في كل node بتختار الـ feature والـ threshold اللي بيفصلوا الداتا «أحسن» فصل. طب يعني إيه أحسن؟ ده الجاي.

ليه الأشجار مهمة؟ على الـ tabular data (صفوف وأعمدة) الـ trees والـ forests والـ gradient boosting (XGBoost, LightGBM) بيكسبوا الـ neural networks باستمرار. مسابقات Kaggle على الداتا المنظمة بيكسبها XGBoost و LightGBM مش الـ transformers.
02

قياس «الخلطة»: Gini و Entropy

عايزين كل node بعد التقسيم تبقى نقية (pure)، يعني فيها class واحد تقريبًا. محتاجين رقم يقيس قد إيه الـ node «مخلوطة».

Gini impurity

لو سحبت عينة عشوائية من الـ node وأديتها label عشوائي حسب نسب الـ classes اللي فيها، إيه احتمال إنك تغلط؟

Gini(S) = 1 − Σ p_k²

مثال: ٦ قطط و٤ كلاب: 1 − (0.6² + 0.4²) = 1 − 0.52 = 0.48. node نقية = 0. نص ونص (class اتنين) = 0.5.

Entropy

نفس اللي اتعلمته في Information Theory: قد إيه فيه «لخبطة/مفاجأة».

Entropy(S) = − Σ p_k · log₂(p_k)

نفس المثال: −(0.6·log₂0.6 + 0.4·log₂0.4) = 0.442 + 0.529 = 0.971 bits. نقية = 0، نص ونص = 1.0. الاتنين: الأقل أحسن.

جرب: غيّر عدد القطط والكلاب في الـ node. لاحظ إن المنحنيين شكلهم شبه بعض جدًا، والقمة في النص عند 50/50.
p(cat)0.6
Gini0.48
Entropy0.971

Information Gain: قد إيه السؤال ده نضّف الدنيا؟

الـ gain = الخلطة قبل التقسيم − متوسط الخلطة بعده (موزون بعدد العينات في كل ابن):

IG = Impurity(parent) − [ n_L/n · Impurity(left) + n_R/n · Impurity(right) ]

مثال الريبو: أب فيه ٤ قطط و٣ كلاب و٣ عصافير (Gini = 0.66). تلات طرق للتقسيم:

التقسيمIG (Gini)IG (Entropy)
A: [cat,cat,cat,dog] | [cat,dog,dog,bird,bird,bird]0.14330.3710
B: [cat×4] | [dog×3, bird×3]0.36000.9710
C: [cat,cat,dog,bird] | [cat,cat,dog,dog,bird,bird]0.01000.0200

B فصل القطط كلها لوحدها، فكسب. و C تقريبًا ما عملش حاجة. لاحظ إن المقياسين متفقين على الترتيب.

إزاي الشجرة بتدوّر على أحسن سؤال (Greedy)

  1. لكل feature: رتّب العينات حسب قيمتها.
  2. جرّب كل نقطة نص بين قيمتين متتاليتين مختلفتين كـ threshold، واحسب الـ IG.
  3. اختار الـ (feature, threshold) اللي ليهم أعلى IG.
  4. قسّم: شمال x[j] <= t ويمين x[j] > t، وكرر على كل ابن (recursion).

ده greedy: بياخد أحسن حاجة دلوقتي من غير ما يبص لقدام، فمش مضمون يطلع أحسن شجرة في الدنيا. لقي أحسن شجرة ممكنة مشكلة NP-hard. بس عمليًا الـ greedy شغال كويس جدًا.

شروط الوقف (Pruning)

من غير وقف، الشجرة هتكبر لحد ما كل ورقة تبقى نقية أو مفيش سؤال يفصل عيناتها، وغالبًا ده معناه عينة واحدة في كل ورقة: حفظت الداتا صم ومش هتعمم.

Pre-pruning (وقف بدري): max_depth، أقل عدد عينات في الورقة min_samples_leaf، أقل gain مقبول، أقصى عدد أوراق.

Post-pruning (قص بعدين): تكبّر الشجرة كاملة وبعدين تقص. زي cost-complexity pruning في scikit-learn: غرامة بتزيد مع عدد الأوراق، كل ما تزود الغرامة الشجرة تصغر. أو reduced error pruning: شيل subtree لو الـ validation error ما زادش.

شجرة للـ Regression

  
لو الهدف رقم مش class: الورقة بتتوقع متوسط قيم الـ targets اللي فيها. ومعيار التقسيم بيتغير لـ Variance Reduction:

  
VR = Var(parent) − [ n_L/n · Var(left) + n_R/n · Var(right) ]

  
يعني اختار السؤال اللي بيخلّي الأرقام في كل ناحية قريبة من بعض. النتيجة: دالة «سلالم» (piecewise constant): الفضاء متقسم مناطق، وفي كل منطقة رقم ثابت. في الريبو بيجرب ده على y = sin(x)·x + noise.

مين الـ feature المهمة؟ MDI و Permutation

  
Mean Decrease in Impurity (MDI): لكل feature، اجمع كل الـ impurity اللي نقصتها في كل الـ nodes في كل الشجر، موزونة بنسبة العينات اللي وصلت الـ node:

  
importance(j) = Σ_(nodes using j) (n_node / n_total) · impurity_decrease

  
الـ features اللي بتعمل تقسيمات كبيرة بدري (قريب من الـ root) بتطلع مهمة. ميزته إنه بيتحسب ببلاش أثناء التدريب. عيبه: منحاز للـ features اللي ليها قيم كتير (high cardinality)، زي ID أو رقم عشوائي بقيم كتير، لأنها بتدي فرص تقسيم كتير فممكن تنقص الـ impurity بالحظ.

  
Permutation importance: اخلط (shuffle) قيم feature واحدة بس وشوف الدقة وقعت قد إيه. لو ما وقعتش، الـ feature دي مش فارقة. أدق، بس أبطأ.

  
في الريبو: الـ target هو 1 if f0 + f1 > 0، و f2 و f3 noise. الغابة بتدي f0 و f1 أغلب الأهمية.

خطوة ١: مقاييس الخلطة

  
import math, random

def gini_impurity(labels):
    n = len(labels)
    if n == 0:
        return 0.0
    counts = {}
    for label in labels:                 # عدّ كل class
        counts[label] = counts.get(label, 0) + 1
    return 1.0 - sum((c / n) ** 2 for c in counts.values())

def entropy(labels):
    n = len(labels)
    if n == 0:
        return 0.0
    counts = {}
    for label in labels:
        counts[label] = counts.get(label, 0) + 1
    return -sum((c / n) * math.log2(c / n) for c in counts.values() if c > 0)

print(gini_impurity(["cat"]*6 + ["dog"]*4))   # 0.48
print(round(entropy(["cat"]*6 + ["dog"]*4), 3))  # 0.971


  
خطوة ٢: Information Gain

  
def information_gain(parent, left, right, criterion="gini"):
    measure = gini_impurity if criterion == "gini" else entropy
    n, nl, nr = len(parent), len(left), len(right)
    if nl == 0 or nr == 0:               # تقسيم فاضي = مفيش مكسب
        return 0.0
    child = (nl / n) * measure(left) + (nr / n) * measure(right)
    return measure(parent) - child


  
خطوة ٣: كلاس DecisionTree (القلب: _build)

  
class DecisionTree:
    def __init__(self, max_depth=None, min_samples_split=2,
                 min_samples_leaf=1, criterion="gini", max_features=None):
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.min_samples_leaf = min_samples_leaf
        self.criterion = criterion
        self.max_features = max_features

    def fit(self, X, y):
        self.n_features = len(X[0])
        self.n_samples = len(X)
        self.feature_importances_ = [0.0] * self.n_features
        self.tree = self._build(X, y, depth=0)
        total = sum(self.feature_importances_)
        if total > 0:                    # خلّي مجموع الأهمية = 1
            self.feature_importances_ = [f / total for f in self.feature_importances_]

    def predict(self, X):
        return [self._predict_one(x, self.tree) for x in X]

    def _build(self, X, y, depth):
        if len(set(y)) == 1:                         # نقية خلاص
            return {"leaf": True, "value": y[0]}
        if self.max_depth is not None and depth >= self.max_depth:
            return self._make_leaf(y)                # pre-pruning: العمق
        if len(y) < self.min_samples_split:
            return self._make_leaf(y)
        f, t, gain = self._best_split(X, y)
        if f is None or gain <= 0:
            return self._make_leaf(y)
        lX, ly, rX, ry = self._split_data(X, y, f, t)
        if len(ly) < self.min_samples_leaf or len(ry) < self.min_samples_leaf:
            return self._make_leaf(y)
        self.feature_importances_[f] += (len(y) / self.n_samples) * gain   # MDI
        return {"leaf": False, "feature": f, "threshold": t,
                "left": self._build(lX, ly, depth + 1),
                "right": self._build(rX, ry, depth + 1)}

    def _make_leaf(self, y):                         # أغلبية الأصوات
        counts = {}
        for label in y:
            counts[label] = counts.get(label, 0) + 1
        return {"leaf": True, "value": max(counts, key=counts.get)}


  
خطوة ٤: البحث عن أحسن split + التقسيم + التوقع

  
    def _best_split(self, X, y):
        best_f, best_t, best_gain = None, None, -1.0
        if self.max_features == "sqrt":              # عشوائية الغابة
            k = max(1, int(math.sqrt(self.n_features)))
            feats = random.sample(range(self.n_features), k)
        elif isinstance(self.max_features, int):
            if self.max_features < 1:
                raise ValueError("max_features must be at least 1 when given as an integer")
            k = min(self.max_features, self.n_features)
            feats = random.sample(range(self.n_features), k)
        else:
            feats = list(range(self.n_features))
        for j in feats:
            values = sorted(set(row[j] for row in X))
            for i in range(len(values) - 1):
                t = (values[i] + values[i + 1]) / 2.0     # نقطة النص
                ly = [y[k] for k in range(len(X)) if X[k][j] <= t]
                ry = [y[k] for k in range(len(X)) if X[k][j] > t]
                if len(ly) < self.min_samples_leaf or len(ry) < self.min_samples_leaf:
                    continue
                g = information_gain(y, ly, ry, self.criterion)
                if g > best_gain:
                    best_f, best_t, best_gain = j, t, g
        return best_f, best_t, best_gain

    def _split_data(self, X, y, f, t):
        lX, ly, rX, ry = [], [], [], []
        for row, label in zip(X, y):
            if row[f] <= t:
                lX.append(row); ly.append(label)
            else:
                rX.append(row); ry.append(label)
        return lX, ly, rX, ry

    def _predict_one(self, x, node):
        if node["leaf"]:
            return node["value"]
        nxt = node["left"] if x[node["feature"]] <= node["threshold"] else node["right"]
        return self._predict_one(x, nxt)


  
خطوة ٥: RandomForest

  
class RandomForest:
    def __init__(self, n_trees=100, max_depth=None, min_samples_split=2,
                 max_features="sqrt", criterion="gini"):
        self.n_trees, self.max_depth = n_trees, max_depth
        self.min_samples_split = min_samples_split
        self.max_features, self.criterion = max_features, criterion
        self.trees = []

    def fit(self, X, y):
        n = len(X)
        for _ in range(self.n_trees):
            idx = [random.randint(0, n - 1) for _ in range(n)]   # bootstrap: مع الإرجاع
            tree = DecisionTree(max_depth=self.max_depth,
                                min_samples_split=self.min_samples_split,
                                max_features=self.max_features,
                                criterion=self.criterion)
            tree.fit([X[i] for i in idx], [y[i] for i in idx])
            self.trees.append(tree)

    def predict(self, X):
        all_preds = [t.predict(X) for t in self.trees]
        out = []
        for i in range(len(X)):
            votes = {}
            for preds in all_preds:                              # تصويت
                votes[preds[i]] = votes.get(preds[i], 0) + 1
            out.append(max(votes, key=votes.get))
        return out

rf.fit(X_train, y_train)
print(f"Accuracy: {rf.score(X_test, y_test):.4f}")
print(f"Feature importances: {rf.feature_importances_}")   # دي MDI

  
عمليًا الـ gradient boosted trees (XGBoost, LightGBM, CatBoost) غالبًا أقوى من الـ random forest لأنها بتبني الشجر ورا بعض وكل شجرة بتصلّح غلط اللي قبلها. بس الـ random forest صعب تظبطه غلط ومحتاج tuning قليل جدًا.

  
Ship It: الدرس بيطلّع outputs/prompt-tree-interpreter.md: prompt بتديه هيكل شجرة متدربة (العمق، الـ features، الـ thresholds، الدقة) فيترجمها لقواعد بلغة بسيطة لأي حد مش بيقرا كود، ويرتب الأهمية، وينبهك لو فيه overfitting أو leakage.

التمارين

  
اعمل ٢ على الأقل النهاردة. الباقي كمّله في التسخين بكرة.

  
    
    
  1. ارسم الحدود بإيدك: درّب شجرة على داتا 2D بـ 3 classes، وتتبّع الـ splits وارسم المستطيلات. قارن max_depth=2 بـ max_depth=10.
      
    تلميحاستخدم print_tree(). كل سطر Feature 0 <= t = خط رأسي عند x=t، و Feature 1 = خط أفقي. نفس اللي في المعمل ٣. عند 10 هتلاقي مستطيلات صغيرة حوالين نقط منفردة: دي noise اتحفظت.
    2. 
    
  2. Regression tree: اعمل variance reduction، وولّد y = sin(x) + noise لـ 200 نقطة، وارسم التوقع قصاد المنحنى الحقيقي.
      
    تلميحبدّل information_gain بـ Var(parent) − weighted Var(children)، والورقة ترجع sum(y)/len(y). هتشوف سلالم. عمق أكبر = سلالم أصغر لحد ما تمشي ورا الـ noise.
    3. 
    
  3. عدد الشجر: غابة بـ 1, 5, 10, 50, 200 شجرة. ارسم train و test accuracy.
      
    المتوقعالـ test بيعلى وبعدين بيثبت، وما بيقعش. زيادة الشجر بتقلل الـ variance بس، فمش بتعمل overfit (بتكلفك وقت بس).
    4. 
    
  4. Gini ولا Entropy؟ قارنهم على 5 datasets في الدقة والعمق. فسّر ليه النتايج شبه بعض.
      
    الإجابةالاتنين صفر عند النقاء وأقصى قيمة عند التساوي، ومنحنياتهم بنفس الشكل تقريبًا (شوفهم في المعمل ٢)، فبيختاروا نفس الـ splits في أغلب الأحوال. Gini أسرع شوية لأن مفيهوش log.
    5. 
    
  5. Permutation importance: اعملها وقارنها بالـ MDI على داتا فيها feature عشوائية بقيم كتير (high cardinality).
      
    تلميحلكل feature: انسخ X_test، اعمل random.shuffle على العمود ده بس، واحسب الدقة. الأهمية = الدقة الأصلية − الدقة بعد الخلط. الـ MDI هيدي الـ noise أهمية ملحوظة، والـ permutation هيديها حوالي صفر.
    6. 
    
  6. إضافة مني · فلتر طلبات لـ LLM: عندك log فيه لكل request: طول الـ prompt، عدد الـ tool calls، هل فيه كود (0/1)، والـ label هل اتعمله escalation لموديل أكبر. ولّد 300 صف بقاعدة بسيطة من عندك + noise، ودرّب شجرة عمقها 3، واطبعها كقواعد if/else. ده بالظبط نوع الـ router الرخيص اللي ينفع تحطه قبل الـ LLM وتقدر تشرحه للفريق.
      
    تلميحمثال قاعدة: escalate لو prompt_len > 2000 and has_code == 1 أو tool_calls > 3. شوف الشجرة لقت الـ thresholds قريبة من اللي انت حاطتها ولا لأ، وبص على feature_importances_.
    7.

إضافة مني: اللي الدرس ما قالوش صريح

  
الحدس

  
الشجرة مش بتحسب «مسافة» ولا «وزن». هي بس بتسأل «أكبر ولا أصغر من كذا؟». عشان كده مش محتاجة scaling: لو ضربت عمود المرتب في 1000 الشجرة هتطلع نفس الأسئلة بأرقام مختلفة. وعشان كده كمان ما بتعرفش تعمل extrapolation: لو كل الأسعار في التدريب أقل من 100، الشجرة عمرها ما هتتوقع 150.

  
غلطات شائعة

  
    
    
  • تسيب max_depth=None في شجرة واحدة وتفرح بـ train acc = 100%.
    • 
    
  • تصدّق الـ MDI على عمود زي user_id أو timestamp. اتأكد بالـ permutation.
    • 
    
  • Leakage: لو الشجرة لقت split واحد بيدي دقة 99%، غالبًا فيه عمود بيسرّب الإجابة (زي «تاريخ الإلغاء» في مشكلة churn).
    • 
    
  • تفتكر الغابة بتحتاج tuning كتير. ابدأ بالافتراضي وبعدين ظبّط.
    • 
  

  
بيظهر فين في شغل الـ LLMs والـ Agents؟

  
الـ LLM مش بيحل كل حاجة. في الـ production كتير بتلاقي موديل شجر خفيف جنب الـ LLM: يتوقع هل الطلب محتاج موديل كبير ولا صغير (routing)، أو يقيّم risk score من features منظمة، أو يرتّب نتايج بـ features زي الـ freshness والـ clicks. والـ gradient boosted trees أداة أساسية في ranking أنظمة البحث اللي الـ RAG بيعتمد عليها.

الـ Sigmoid: عصّارة بتكبس أي رقم بين 0 و1

σ(z) = 1 / (1 + e^(−z))

خواصها:

  1. لما z كبير وموجب → σ(z) بتقرب من 1.
  2. لما z كبير وسالب → σ(z) بتقرب من 0.
  3. عند z = 0 → σ = 0.5 بالظبط.
  4. الناتج دايمًا بين 0 و1، والـ function ناعمة وليها derivative في كل حتة.

والـ derivative شكلها لطيف جدًا وبيوفر حسابات:

σ'(z) = σ(z) · (1 − σ(z))

الموديل كله: احسب z = wx + b زي امبارح بالظبط، وعدّيه على الـ sigmoid. الناتج p هو P(y=1 | x): احتمال إن الحاجة دي من كلاس 1. لو p ≥ 0.5 قول 1، غير كده قول 0.

التشبيه: تخيل منظم صوت (dimmer). الخط المستقيم زي سلك بيوصل أي جهد مهما كان. الـ sigmoid زي منظم بيقص الجهد: مهما زودت، مش هيعدي 100٪، ومهما قللت، مش هينزل تحت 0٪. وفي النص بالظبط بيتحرك بسرعة.
جرب بإيدك: حرّك w وb وشوف المنحنى البرتقالي (logistic) بيفضل جوه [0, 1] والخط الأزرق (linear) بيطلع بره. دوس «ضيف outlier 50 ساعة» وشوف الخط بيتشد وبيغير قراره لناس كتير.

Binary Cross-Entropy: عقاب الغلطة الواثقة

ليه منستخدمش الـ MSE بتاعة امبارح؟ لأن الـ MSE مع الـ sigmoid بتعمل سطح cost مش convex، فيه وديان صغيرة كتير (local minima) ممكن الـ gradient descent يقع فيها. بدلها بنستخدم الـ binary cross-entropy (اسمها كمان log loss):

Loss = −(1/n) Σ [ y·log(p) + (1−y)·log(1−p) ]
الحقيقةالتوقعاللي بيحصلالـ loss
y = 1p ≈ 1log(1) = 0قريبة من صفر (صح)
y = 1p ≈ 0log(0) → −∞ضخمة (غلط بثقة)
y = 0p ≈ 0log(1−0) = 0قريبة من صفر (صح)
y = 0p ≈ 1log(1−1) → −∞ضخمة (غلط بثقة)

الـ loss دي convex بالنسبة للـ logistic regression: أي قاع محلي هو القاع الكبير، فالـ gradient descent مستحيل يتزنق في وادي وحش.

تفصيلة الدرس قالها: لو الداتا منفصلة تمامًا (في خط بيفصل الكلاسين من غير ولا غلطة)، الـ loss بتفضل تنزل كل ما الأوزان تكبر، فمفيش minimum محدود أصلًا: الأوزان بتجري لما لا نهاية. الحل: L2 regularization (اللي شفتها امبارح في الـ Ridge) بتخلي فيه minimum واحد ووحيد.

معمل: قارن الـ BCE بالـ MSE لتوقع واحد

اختار الحقيقة (y = 1 أو 0) وحرّك الاحتمال p. لاحظ إن الـ MSE أقصى عقاب ليها 1 بس حتى لو الموديل غلطان بثقة 99.9٪، لكن الـ BCE بتضرب في السما. ده اللي بيخلي الموديل «يخاف» يبقى واثق وغلطان.

الـ Gradient: نفس شكل امبارح

∂L/∂w = (1/n) Σ (p − y)·x
∂L/∂b = (1/n) Σ (p − y)

نفس معادلات الـ linear regression بالظبط! الفرق الوحيد إن p = σ(wx + b) بدل p = wx + b. الـ sigmoid جابت الـ nonlinearity، بس قاعدة التحديث فضلت زي ما هي. الـ (p − y) هي ببساطة «الغلطة»: لو موجبة الموديل متفائل زيادة، لو سالبة متشائم زيادة.

ابدأ w=0, b=0 → z = wx+b, p = σ(z) → احسب BCE → احسب dw, db → w −= lr·dw, b −= lr·db → كرر لحد ما يتقارب

الـ Decision Boundary والـ Threshold والـ Metrics

لو عندك feature-ين، الحدود بين الكلاسين هي الخط اللي عنده:

w₁x₁ + w₂x₂ + b = 0 ⇔ p = 0.5

النقط على ناحية بتتصنف 1، والناحية التانية 0. الـ logistic regression دايمًا بتعمل حدود خطية. لو محتاج حدود منحنية، يا تضيف polynomial features (زي x₁², x₂², x₁x₂)، يا تستخدم موديل nonlinear.

الـ Accuracy لوحدها بتكدب

داتا فيها 95٪ سالب و5٪ موجب: موديل بيقول «سالب» على طول ياخد 95٪ accuracy وهو ملوش أي لازمة. عشان كده بنبص على الـ confusion matrix:

توقع موجبتوقع سالب
موجب فعلًاTrue Positive (TP)False Negative (FN)
سالب فعلًاFalse Positive (FP)True Negative (TN)
Precision = TP / (TP + FP) Recall = TP / (TP + FN)
F1 = 2 · P · R / (P + R)
  1. Precision: من كل اللي قلت عليهم موجب، كام فعلًا موجب؟ مهمة لما الـ false positive غالية: فلتر spam مش عايزه يبلوك إيميل مهم.
  2. Recall (اسمها كمان sensitivity): من كل الموجب الحقيقي، مسكت كام؟ مهمة لما الـ false negative غالية: فحص سرطان مش عايزه يفوّت ورم.
  3. F1: المتوسط التوافقي (harmonic mean) للاتنين، لما تحتاج رقم واحد متوازن.

الـ Threshold: الـ 0.5 مش قانون. لو نزّلته الموديل بيقول «موجب» أكتر: الـ recall بيطلع والـ precision غالبًا بتنزل. لو طلّعته العكس. ده آخر جزء في الكود (threshold tuning).

أكتر من كلاسين: Softmax

الـ binary logistic regression بتتعامل مع كلاسين بس. لو عندك k كلاسات، كل كلاس بياخد weight vector خاص بيه، والموديل بيحسب score zᵢ لكل كلاس، وبعدين الـ softmax بتحول الـ scores لاحتمالات مجموعها 1:

softmax(zᵢ) = e^(zᵢ) / Σⱼ e^(zⱼ)

الكلاس المتوقع هو اللي احتماله أعلى. والـ loss بتبقى categorical cross-entropy:

Loss = −(1/n) Σ Σₖ yₖ · log(pₖ)

وyₖ هنا one-hot: متجه أصفار فيه 1 في مكان الكلاس الصح بس. يعني عمليًا الـ loss = −log احتمال الكلاس الصح.

شفتها قبل كده: في الكود، الـ softmax بتطرح max(scores) قبل الـ exp. دي حيلة الـ stable softmax من يوم ١٣ (Numerical Stability) بالظبط، عشان الـ exp ما يعملش overflow.

حرّك الـ scores (اسمها logits) وشوف: لما تزود score كلاس، احتماله بيطلع واحتمال الباقيين بينزل، لأن المجموع لازم يفضل 1.

def sigmoid(z):
    z = max(-500, min(500, z))          # نحبس z عشان exp ما تعملش overflow
    return 1.0 / (1.0 + math.exp(-z))

خطوة ٢: الـ LogisticRegression من الصفر

class LogisticRegression:
    def __init__(self, n_features, learning_rate=0.01):
        self.weights = [0.0] * n_features   # نبدأ من صفر
        self.bias = 0.0
        self.lr = learning_rate
        self.loss_history = []

    def predict_proba(self, x):            # z = w·x + b ← sigmoid
        z = sum(w * xi for w, xi in zip(self.weights, x)) + self.bias
        return sigmoid(z)

    def predict(self, x, threshold=0.5):
        return 1 if self.predict_proba(x) >= threshold else 0

    def compute_loss(self, X, y):          # binary cross-entropy
        n = len(y)
        total = 0.0
        for i in range(n):
            p = self.predict_proba(X[i])
            p = max(1e-15, min(1 - 1e-15, p))   # نمنع log(0)
            total += y[i] * math.log(p) + (1 - y[i]) * math.log(1 - p)
        return -total / n

    def fit(self, X, y, epochs=1000, print_every=200):
        n = len(y)
        n_features = len(X[0])
        for epoch in range(epochs):
            dw = [0.0] * n_features
            db = 0.0
            for i in range(n):
                p = self.predict_proba(X[i])
                error = p - y[i]               # الغلطة (p − y)
                for j in range(n_features):
                    dw[j] += error * X[i][j]
                db += error
            for j in range(n_features):        # خطوة عكس الـ gradient
                self.weights[j] -= self.lr * (dw[j] / n)
            self.bias -= self.lr * (db / n)
            loss = self.compute_loss(X, y)
            self.loss_history.append(loss)
            if epoch % print_every == 0:
                print(f"  Epoch {epoch:4d} | Loss: {loss:.4f} | w: [{self.weights[0]:.3f}, {self.weights[1]:.3f}] | b: {self.bias:.3f}")
        return self

    def accuracy(self, X, y):
        correct = sum(1 for i in range(len(y)) if self.predict(X[i]) == y[i])
        return correct / len(y)


split = int(0.8 * N)                       # 80% train و 20% test

خطوة ٣: الـ confusion matrix والـ metrics

class ClassificationMetrics:
    def __init__(self, y_true, y_pred):    # نعد الأربع خانات
        self.tp = sum(1 for t, p in zip(y_true, y_pred) if t == 1 and p == 1)
        self.tn = sum(1 for t, p in zip(y_true, y_pred) if t == 0 and p == 0)
        self.fp = sum(1 for t, p in zip(y_true, y_pred) if t == 0 and p == 1)
        self.fn = sum(1 for t, p in zip(y_true, y_pred) if t == 1 and p == 0)

    def accuracy(self):
        total = self.tp + self.tn + self.fp + self.fn
        return (self.tp + self.tn) / total if total > 0 else 0

    def precision(self):                   # من اللي قلت عليهم 1
        denom = self.tp + self.fp
        return self.tp / denom if denom > 0 else 0

    def recall(self):                      # من الـ 1 الحقيقيين
        denom = self.tp + self.fn
        return self.tp / denom if denom > 0 else 0

    def f1(self):
        p = self.precision()
        r = self.recall()
        return 2 * p * r / (p + r) if (p + r) > 0 else 0

    def print_confusion_matrix(self):
        print(f"\n  Confusion Matrix:")
        print(f"                  Predicted")
        print(f"                  Pos   Neg")
        print(f"  Actual Pos     {self.tp:4d}  {self.fn:4d}")
        print(f"  Actual Neg     {self.fp:4d}  {self.tn:4d}")

    def print_report(self):
        self.print_confusion_matrix()
        print(f"\n  Accuracy:  {self.accuracy():.4f}")
        print(f"  Precision: {self.precision():.4f}")
        print(f"  Recall:    {self.recall():.4f}")
        print(f"  F1 Score:  {self.f1():.4f}")

class SoftmaxRegression:
    def __init__(self, n_features, n_classes, learning_rate=0.01):
        self.n_features = n_features
        self.n_classes = n_classes
        self.lr = learning_rate
        self.weights = [[0.0] * n_features for _ in range(n_classes)]  # vector لكل كلاس
        self.biases = [0.0] * n_classes

    def softmax(self, scores):
        max_score = max(scores)                       # stable softmax
        exp_scores = [math.exp(s - max_score) for s in scores]
        total = sum(exp_scores)
        return [e / total for e in exp_scores]

    def predict_proba(self, x):
        scores = [
            sum(self.weights[k][j] * x[j] for j in range(self.n_features)) + self.biases[k]
            for k in range(self.n_classes)
        ]
        return self.softmax(scores)

    def predict(self, x):
        probs = self.predict_proba(x)
        return probs.index(max(probs))                 # أعلى احتمال

    def fit(self, X, y, epochs=1000, print_every=200):
        n = len(y)
        for epoch in range(epochs):
            grad_w = [[0.0] * self.n_features for _ in range(self.n_classes)]
            grad_b = [0.0] * self.n_classes
            total_loss = 0.0
            for i in range(n):
                probs = self.predict_proba(X[i])
                for k in range(self.n_classes):
                    target = 1.0 if y[i] == k else 0.0  # one-hot
                    error = probs[k] - target           # نفس (p − y)
                    for j in range(self.n_features):
                        grad_w[k][j] += error * X[i][j]
                    grad_b[k] += error
                true_prob = max(probs[y[i]], 1e-15)
                total_loss -= math.log(true_prob)      # categorical CE
            for k in range(self.n_classes):
                for j in range(self.n_features):
                    self.weights[k][j] -= self.lr * (grad_w[k][j] / n)
                self.biases[k] -= self.lr * (grad_b[k] / n)
            if epoch % print_every == 0:
                print(f"  Epoch {epoch:4d} | Loss: {total_loss / n:.4f}")
        return self

    def accuracy(self, X, y):
        correct = sum(1 for i in range(len(y)) if self.predict(X[i]) == y[i])
        return correct / len(y)

التمارين

التلاتة الأولانيين من الدرس. اعمل واحد على الأقل النهاردة، والتاني والتالت ينفعوا warm-up بكرة.

  1. داتا مش منفصلة خطيًا: اعمل dataset على شكل دايرتين جوه بعض (concentric circles). درّب logistic regression وشوفها بتفشل. بعدين زوّد features x₁², x₂², x₁x₂ ودرّب تاني، وبيّن إن الـ accuracy اتحسنت.
    تلميحنقطة على دايرة نصف قطرها r: a = random.uniform(0, 2*math.pi)، [r*math.cos(a), r*math.sin(a)]. خلي الداخلية r حوالي 1 والخارجية حوالي 3 مع شوية noise. بعدها حوّل كل نقطة لـ [x1, x2, x1*x1, x2*x2, x1*x2] واعمل LogisticRegression(n_features=5). الفكرة: x₁² + x₂² = r²، فالحدود بقت خطية في الـ features الجديدة. جرب «داتا دواير» في المعمل ٠٣ الأول عشان تشوف الفشل بعينك.
  2. Confusion matrix لـ ٣ كلاسات: اعمل confusion matrix 3×3 للـ softmax model، واحسب precision وrecall لكل كلاس. أنهي كلاس أصعب؟
    تلميحcm = [[0]*3 for _ in range(3)] وcm[true][pred] += 1. الـ precision لكلاس k = cm[k][k] / sum(cm[i][k] for i in range(3)) (العمود)، والـ recall = cm[k][k] / sum(cm[k]) (الصف). فكّر قبل ما تشغل: المراكز (1,1) و(5,1) و(3,5)، أنهي اتنين أقرب لبعض؟ احسب المسافات واتأكد بالأرقام.
  3. ROC curve من الصفر: لـ 100 قيمة threshold من 0 لـ 1، احسب الـ true positive rate والـ false positive rate، واحسب الـ AUC بقاعدة شبه المنحرف (trapezoidal rule).
    تلميحTPR = TP/(TP+FN) (هو نفسه الـ recall)، FPR = FP/(FP+TN). رتّب النقط حسب الـ FPR، وبعدين auc += (fpr[i]-fpr[i-1]) * (tpr[i]+tpr[i-1]) / 2. موديل عشوائي AUC بتاعه حوالي 0.5، والمثالي 1.0. لما الكلاسين بعاد عن بعض زي داتا الدرس، استنى رقم عالي.
  4. إضافة مني · فلتر تذاكر دعم: عندك تذاكر support، وعايز تعلّم «urgent» عشان تروح لإنسان فورًا. اعمل ٣ features بسيطة لكل رسالة (فيها كلمة زي "down" أو "refund"؟ عدد علامات التعجب، طول الرسالة)، وداتا صغيرة ٢٠ رسالة بإيدك، ودرّب موديلك. بعدين اختار threshold: لو تفويت تذكرة urgent أغلى من إن موظف يقرا تذكرة عادية، تركز على precision ولا recall؟ ونزّل الـ threshold ولا طلّعه؟
    الإجابةتفويت urgent = false negative، فأنت عايز recall عالي، يعني تنزّل الـ threshold (مثلًا 0.3) وتقبل شوية false positives. وده نفس اللي بيحصل في أنظمة الـ routing والـ guardrails في الـ agents: classifier صغير بيقرر يعدّي الطلب لإنسان ولا لأ، والـ threshold بيتحدد حسب تكلفة كل نوع غلطة، مش 0.5 وخلاص.

إضافة مني: اللي الدرس ما قالهوش صريح

الـ logistic regression = neuron واحد

linear + sigmoid، وتتدرب بـ gradient descent على cross-entropy. ده بالظبط neuron واحد في neural network. لما نوصل للـ Deep Learning، الـ neural net هتبقى ببساطة طبقات كتير من الحاجة دي فوق بعض. والـ softmax + categorical cross-entropy هي حرفيًا الطبقة الأخيرة في أي LLM: الموديل بيطلّع score (logit) لكل token في الـ vocabulary، والـ softmax بتحولها لاحتمالات، والـ loss وقت التدريب هي −log احتمال الـ token الصح.

الـ z اسمه log-odds

لو p = σ(z)، يبقى z = log(p / (1 − p)). يعني الموديل الخطي فعليًا بيتوقع log-odds (اسمها كمان logit)، والـ sigmoid بترجعها احتمال. ده اللي بيخلي كل وزن ليه تفسير: زيادة x بوحدة بتزود الـ log-odds بمقدار w. وعشان كده الـ logits اسمها logits.

غلطات شائعة

  1. تحكم بالـ accuracy على داتا مش متوازنة. بص على الـ precision والـ recall والـ confusion matrix، وقارن دايمًا بموديل غبي بيقول الكلاس الأكتر على طول.
  2. تنسى تحبس p قبل الـ log. log(0) = -inf وكل التدريب يبقى nan. الكود بيحبسها بين 1e-15 و1 - 1e-15 لنفس السبب ده (افتكر يوم ١٣).
  3. تعامل p على إنها احتمال مضبوط وخلاص. الـ BCE بتشجع إن الاحتمالات تبقى معقولة، بس مع regularization قوية أو داتا متغيرة ممكن الـ 0.8 متبقاش فعلًا ٨٠٪. اتأكد بمقارنة التوقعات بالواقع على داتا test.
  4. تختار الـ threshold على الـ test set. ده تسريب: اختاره على validation set، وسيب الـ test للتقييم الأخير بس.
  5. تعمل fit للـ scaler على الداتا كلها. لاحظ إن كود الـ scikit-learn بيعمل fit_transform على الـ train وtransform بس على الـ test.

ليه الـ Ensembles بتشتغل أصلًا؟

تخيل لجنة امتحان فيها ٢١ مصحح، كل واحد فيهم بيصيب في ٦٠٪ بس من الحالات. لو كل واحد بيغلط في حاجات مختلفة عن التاني، ورأي الأغلبية هو اللي بيمشي، عشان القرار يطلع غلط لازم أكتر من النص يغلطوا في نفس الوقت. ودي حاجة صعبة.

لو عندك N classifiers مستقلين، كل واحد accuracy بتاعه p > 0.5، دقة تصويت الأغلبية:

P(majority correct) = Σ_{k > N/2} C(N,k) · p^k · (1−p)^(N−k)

الأخطاء بتلغي بعضها لما الموديلات تغلط غلطات مختلفة. الشرط الأساسي اسمه diversity (التنوع): لو كلهم بيغلطوا نفس الغلطة، تجميعهم مش هيفيد بحاجة.

بنعمل التنوع ده بـ ٤ طرق:

  • داتا تدريب مختلفة لكل موديل ← Bagging
  • features مختلفة لكل موديل ← Random Forests
  • تصحيح الأخطاء واحد ورا التاني ← Boosting
  • عائلات موديلات مختلفة ← Stacking
جرب بإيدك: خلي الـ correlation = 0 وزوّد عدد الموديلات: الدقة بتطلع لفوق. بعدين زوّد الـ correlation وشوف المكسب بيتبخر. ولو خليت p أقل من 0.5، التصويت بيخليها أوحش!
موديل واحد0.600
الأغلبية (ρ الحالي)0.826
الأغلبية لو مستقلين0.826

الخط المتقطع = موديلات مستقلة تمامًا (ρ=0). الخط الملون = الـ ρ اللي اخترته. الـ correlation هنا معناها: كل موديل بنسبة ρ بينقل نفس «الرأي المشترك»، وبنسبة 1−ρ بيفكر لوحده.

ملاحظة على الأرقام: الدرس الأصلي بيقول إن ٢١ موديل بدقة ٦٠٪ بيوصلوا لحوالي ٧٤٪، و١٠١ لحوالي ٨٤٪. لو حسبت المعادلة اللي فوق بالظبط لموديلات مستقلة تمامًا هتطلع ≈ ٨٢.٦٪ و≈ ٩٧.٩٪ (المعمل بيحسبها بالظبط). الفكرة واحدة: الدقة بتطلع مع N. والدرس العملي: في الحقيقة الموديلات عمرها ما بتبقى مستقلة تمامًا، فالمكسب الفعلي أقل من الرقم النظري. حرّك ρ وشوف بنفسك.
02

Bagging: نفس الموديل، داتا مختلفة شوية

Bagging = Bootstrap Aggregating. بتدرّب كل موديل على bootstrap sample مختلفة، وفي الآخر تاخد المتوسط (regression) أو تصويت الأغلبية (classification).

الـ bootstrap sample: تخيل كيس فيه N كرة (صفوف الداتا). تسحب كرة، تكتب رقمها، وترجعها الكيس. تكرر N مرة. النتيجة: نفس الحجم، بس فيه صفوف متكررة وصفوف مااتسحبتش خالص.

Data → Bootstrap 1..N → Model 1..N → Average / Vote → Prediction

في المتوسط حوالي 63.2٪ من الصفوف الفريدة بتظهر في كل sample. الـ 36.8٪ الباقيين اسمهم out-of-bag (OOB) وبيدّوك validation set ببلاش من غير ما تقتطع holdout.

كل شجرة لوحدها بتعمل overfit على الـ sample بتاعتها، بس الـ overfit ده مختلف من شجرة للتانية، فلما تاخد المتوسط الضوضاء بتلغي بعضها. النتيجة: variance أقل من غير ما الـ bias يزيد كتير.

Random Forest

Bagging لأشجار القرار + حركة زيادة: عند كل split، الشجرة بتبص على مجموعة عشوائية من الـ features بس. ده بيجبر الأشجار تختلف عن بعض أكتر (diversity أعلى). العدد المعتاد: sqrt(n_features) للـ classification وn_features / 3 للـ regression.

03

Boosting و AdaBoost: كل موديل بيصلّح غلط اللي قبله

الـ Boosting بيدرّب الموديلات ورا بعض (sequential) مش بالتوازي. كل موديل جديد بيركز على الأمثلة اللي الموديلات اللي قبله غلطت فيها. التوقع النهائي = مجموع موزون لكل الموديلات، والموديل الأحسن وزنه أعلى.

زي مدرس خصوصي: أول حصة بيشرح كل حاجة، تاني حصة بيركز على الحاجات اللي الطالب غلط فيها، تالت حصة على اللي لسه غلط فيها… كده الـ bias بيقل خطوة بخطوة.

التمن: الـ boosting ممكن يعمل overfit لو زودت الجولات أوي، لأنه بيفضل يجري ورا الأمثلة الصعبة، وبعضها أصلًا noise.

AdaBoost (Adaptive Boosting)

أول خوارزمية boosting عملية. بتشتغل مع أي base learner، والمعتاد decision stump: شجرة بعمق 1، يعني سؤال واحد بس زي «x أصغر من 0.3؟».

1. Initialize sample weights: w_i = 1/N for all i          # أوزان متساوية

2. For t = 1 to T:
   a. Train weak learner h_t on weighted data              # stump على الداتا الموزونة
   b. err_t = sum(w_i * I(h_t(x_i) != y_i)) / sum(w_i)     # الغلط الموزون
   c. alpha_t = 0.5 * ln((1 - err_t) / err_t)              # وزن الموديل
   d. w_i = w_i * exp(-alpha_t * y_i * h_t(x_i))           # حدّث أوزان الأمثلة
   e. Normalize weights to sum to 1                        # نرمل

3. H(x) = sign(sum(alpha_t * h_t(x)))                      # التوقع النهائي

لاحظ في (d): لو التوقع صح، y·h = +1 فالوزن بيتضرب في e^(−α) ويصغر. لو غلط، y·h = −1 فالوزن بيتضرب في e^(+α) ويكبر. والموديل اللي غلطه قليل بياخد α أكبر.

معمل: شوف الأوزان بتكبر

النقط الزرقا +1 (جوه دايرة) والبرتقاني −1. stump واحد يقدر يرسم خط مستقيم أفقي أو رأسي بس، فمستحيل لوحده يحيط بالدايرة.

دوس «جولة جاية»: الخط المتقطع هو الـ stump الجديد، وحجم كل نقطة = وزنها. النقط اللي اتغلط فيها بتكبر عشان الـ stump اللي بعده ياخد باله منها. الخلفية الملونة = قرار الـ ensemble كله، والنقطة اللي حواليها حلقة حمرا = لسه غلط.

لاحظ: بعد كام جولة الـ ensemble بيعمل شكل «صندوق» حوالين الدايرة من خطوط مستقيمة بس. ده معنى «weak learners بيعملوا strong learner».

Gradient Boosting: اتعلم الـ residuals

الـ Gradient Boosting بيعمّم الفكرة لأي loss function. بدل ما يغيّر أوزان الأمثلة، كل موديل جديد بيتدرب على الـ residuals (بالظبط: سالب الـ gradient بتاع الـ loss) للـ ensemble الحالي.

1. F_0(x) = argmin_c sum(L(y_i, c))                # ابدأ بثابت

2. For t = 1 to T:
   a. r_i = -dL(y_i, F_{t-1}(x_i)) / dF_{t-1}(x_i) # pseudo-residuals
   b. Fit a tree h_t to the residuals r_i          # شجرة على الغلط
   c. gamma_t = argmin_gamma sum(L(y_i, F_{t-1}(x_i) + gamma * h_t(x_i)))
   d. F_t(x) = F_{t-1}(x) + learning_rate * gamma_t * h_t(x)

3. Final prediction: F_T(x)

مع الـ squared error، الـ pseudo-residuals هي نفسها الـ residuals العادية: r_i = y_i − F_{t-1}(x_i). يعني كل شجرة حرفيًا بتتعلم «الغلط اللي فاضل».

تشبيه: بتحاول تصيب هدف بالجولف. أول ضربة بتقربك. التانية هدفها المسافة اللي فاضلة. التالتة المسافة اللي فاضلة بعد كده…

الـ learning rate (shrinkage) بيتحكم قد إيه كل شجرة بتساهم. أصغر = محتاج أشجار أكتر بس بيعمم أحسن غالبًا. القيم المعتادة: 0.01 لحد 0.3.

جرب بإيدك: بـ lr = 1 الخط بيقفز بسرعة. بـ lr = 0.1 بيقرب بالراحة. الخطوط الرأسية الرفيعة هي الـ residuals اللي الشجرة الجاية هتتعلمها، وبتقصر مع كل جولة.

XGBoost و Stacking و Voting

XGBoost: ليه مسيطر على الداتا الجدولية؟

XGBoost (eXtreme Gradient Boosting) هو gradient boosting ومعاه تحسينات هندسية خلته سريع ودقيق وصعب يعمل overfit:

التحسينيعني إيه ببساطة
Regularized objectiveعقوبات L1 و L2 على أوزان الأوراق، عشان مفيش شجرة تبقى واثقة زيادة
Second-order approximationبيستخدم المشتقة الأولى والتانية للـ loss، فقرارات الـ split أحسن
Sparsity-aware splitsبيتعامل مع الـ missing values لوحده: بيتعلم أحسن اتجاه للقيمة الناقصة عند كل split
Column subsamplingزي الـ random forest، بياخد features عشوائية للتنوع
Weighted quantile sketchبيلاقي نقط الـ split للـ features المستمرة بكفاءة على داتا موزعة
Cache-aware block structureترتيب الذاكرة متظبط على الـ CPU cache

على الداتا الجدولية، XGBoost (واللي جه بعده LightGBM) بيغلبوا الـ neural networks باستمرار. لو داتاك جدول rows و columns، ابدأ بالـ gradient boosting.

Stacking (Meta-Learning)

بتدرّب كذا base model مختلفين (مثلًا Random Forest و SVM و Logistic Regression)، وتستخدم توقعاتهم كـ features لموديل فوقيهم اسمه meta-learner.

RF, SVM, LogReg → predictions → Meta-Learner → Final

الـ meta-learner بيتعلم يثق في مين في أنهي منطقة: لو الـ RF أحسن في حتة والـ SVM أحسن في حتة تانية، هيتعلم يوزّع على حسب كده. زي مدير فريق عارف مين شاطر في إيه.

فخ الـ leakage: توقعات الـ base models اللي بتدرب بيها الـ meta-learner لازم تطلع بالـ cross-validation على الـ training set. عمرك ما تدرب الـ base models وتطلع منهم الـ meta-features على نفس الداتا، وإلا الـ meta-learner هيشوف توقعات «حافظة» الداتا وهيثق فيها زيادة.

Voting: أبسط ensemble

  • Hard voting: تصويت أغلبية على الـ labels.
  • Soft voting: متوسط الـ probabilities وتختار الـ class صاحبة أعلى متوسط. غالبًا أحسن لأنه بيستخدم معلومة «قد إيه الموديل واثق».

مثال: ٣ موديلات بيدّوا احتمال class A = 0.9, 0.4, 0.45. hard voting: ٢ من ٣ قالوا B ← B. soft voting: المتوسط 0.583 ← A. الموديل الأول كان واثق جدًا والاتنين التانيين مترددين.

إضافة مني: اللي الدرس ما قالوش صريح

الحدس في جملة

Bagging = «اسأل ناس كتير مستقلين وخد المتوسط» (بيعالج التذبذب). Boosting = «اسأل واحد ورا التاني وكل واحد يصلّح اللي قبله» (بيعالج القصور). قاعدة الدرس اللي فات بتلخصها: base model عنده variance عالي (شجرة عميقة) ← bagging. base model عنده bias عالي (stump) ← boosting.

أخطاء شائعة

  • تعمل ensemble من ٥ نسخ من نفس الموديل بنفس الداتا ونفس الـ seed: correlation = 1، يعني صفر مكسب. ارجع للمعمل ٠١ وحط ρ=1.
  • تفتكر إن الـ random forest هيعمل overfit لو زودت الأشجار: لأ، زيادة الأشجار مش بتعمل overfit، بس المكسب بيقف عند حد. الـ boosting بقى هو اللي ممكن يعمل overfit مع جولات أكتر، فبتحتاج early stopping.
  • AdaBoost على labels فيها noise كتير: هيكبّر وزن الأمثلة الغلط ويجري وراها. جرّب في المعمل ٠٣: نقطة غلط في النص بتكبر كل جولة.
  • Stacking من غير cross-validation: leakage. الأرقام بتبان حلوة في التدريب وتقع في الـ production.
  • الـ OOB score بيتحسب على الأشجار اللي ماشافتش الصف بس: مش على كل الغابة.

فين ده في الـ LLMs والـ Agents؟

  • Self-consistency: تسأل الـ LLM نفس السؤال كذا مرة بـ temperature أعلى من صفر وتاخد الإجابة الأكتر تكرارًا. ده hard voting بالظبط، وبيشتغل بس لأن الـ samples مختلفة عن بعض (diversity).
  • LLM-as-judge panel: بدل حكم واحد، كذا موديل مختلف يقيّموا وتاخد الأغلبية أو المتوسط. موديلات من عائلات مختلفة = correlation أقل.
  • Dropout: الدرس اللي فات وصفه كـ «implicit bagging»: كل خطوة تدريب بتدرب شبكة فرعية مختلفة شوية.
  • Router في الـ agents: فكرة الـ stacking (موديل بيتعلم يثق في مين في أنهي حالة) قريبة من agent بيختار أنهي tool أو أنهي موديل يرد. التشابه في الفكرة مش في التفاصيل.
  • شغلك الحقيقي: أي classifier جدولي جنب الـ LLM (fraud، churn، ranking features قبل الـ RAG) غالبًا الحل الأول فيه هو LightGBM/XGBoost.

import numpy as np

def make_classification_data(n_samples=300, n_features=5, noise=0.1, seed=42):
    rng = np.random.RandomState(seed)
    X = rng.randn(n_samples, n_features)
    # حدود غير خطية: فيها x1 تربيع، يعني stump واحد مش هيكفي
    boundary = 0.5 * X[:, 0] + 0.3 * X[:, 1] ** 2 - 0.2 * X[:, 2]
    y = np.where(boundary + rng.normal(0, noise, n_samples) > 0, 1, -1)   # labels = +1 / -1
    return X, y

def make_regression_data(n_samples=300, n_features=5, noise=0.3, seed=42):
    rng = np.random.RandomState(seed)
    X = rng.randn(n_samples, n_features)
    y = 2.0 * X[:, 0] + np.sin(3 * X[:, 1]) - 0.5 * X[:, 2] ** 2 + rng.normal(0, noise, n_samples)
    return X, y

def train_test_split(X, y, test_ratio=0.2, seed=42):
    rng = np.random.RandomState(seed)
    idx = rng.permutation(len(y))                 # لخبط الترتيب
    split = int(len(y) * (1 - test_ratio))
    return X[idx[:split]], X[idx[split:]], y[idx[:split]], y[idx[split:]]

خطوة ٢: الـ Decision Stump (الـ weak learner)

class DecisionStump:
    def __init__(self):
        self.feature_idx = None
        self.threshold = None
        self.polarity = 1
        self.alpha = None

    def fit(self, X, y, weights):
        n_samples, n_features = X.shape
        best_error = float("inf")
        for f in range(n_features):                       # جرّب كل feature
            for thresh in np.unique(X[:, f]):             # وكل threshold
                for polarity in [1, -1]:                  # والاتجاهين
                    pred = np.ones(n_samples)
                    pred[polarity * X[:, f] < polarity * thresh] = -1
                    error = np.sum(weights[pred != y])    # غلط موزون، مش عدد
                    if error < best_error:
                        best_error = error
                        self.feature_idx, self.threshold, self.polarity = f, thresh, polarity

    def predict(self, X):
        pred = np.ones(X.shape[0])
        idx = self.polarity * X[:, self.feature_idx] < self.polarity * self.threshold
        pred[idx] = -1
        return pred

خطوة ٣: AdaBoost من الصفر

class AdaBoostScratch:
    def __init__(self, n_estimators=50):
        self.n_estimators = n_estimators
        self.stumps, self.alphas = [], []

    def fit(self, X, y):
        n = X.shape[0]
        weights = np.full(n, 1 / n)                       # أوزان متساوية في الأول
        for t in range(self.n_estimators):
            stump = DecisionStump()
            stump.fit(X, y, weights)
            pred = stump.predict(X)
            err = np.sum(weights[pred != y])
            err = np.clip(err, 1e-10, 1 - 1e-10)          # نحمي الـ log من القسمة على صفر
            alpha = 0.5 * np.log((1 - err) / err)         # غلط أقل = صوت أعلى
            weights *= np.exp(-alpha * y * pred)          # الغلط يكبر، الصح يصغر
            weights /= weights.sum()
            stump.alpha = alpha
            self.stumps.append(stump)
            self.alphas.append(alpha)

    def predict(self, X):
        total = sum(a * s.predict(X) for a, s in zip(self.alphas, self.stumps))
        return np.sign(total)                             # تصويت موزون

    def accuracy(self, X, y):
        return np.mean(self.predict(X) == y)

خطوة ٤: Regression Tree بسيطة (هنحتاجها للـ boosting والـ bagging)

class TreeNode:
    def __init__(self, value=None):
        self.feature_idx = None; self.threshold = None
        self.left = None; self.right = None
        self.value = value                                # لو ورقة: التوقع

class SimpleRegressionTree:
    def __init__(self, max_depth=3, min_samples_split=2):
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.root = None

    def fit(self, X, y):
        self.root = self._build(X, y, depth=0)

    def _build(self, X, y, depth):
        n_samples, n_features = X.shape
        if depth >= self.max_depth or n_samples < self.min_samples_split:
            return TreeNode(value=np.mean(y))             # وقف: ورقة = المتوسط
        best_gain, best_feature, best_threshold = -float("inf"), None, None
        current_var = np.var(y) * n_samples
        for f in range(n_features):
            thresholds = np.unique(X[:, f])
            if len(thresholds) > 20:                      # نقلل المحاولات لـ 20 percentile
                thresholds = np.percentile(X[:, f], np.linspace(0, 100, 20))
            for thresh in thresholds:
                left_mask = X[:, f] <= thresh
                right_mask = ~left_mask
                if left_mask.sum() < 1 or right_mask.sum() < 1:
                    continue
                left_var = np.var(y[left_mask]) * left_mask.sum()
                right_var = np.var(y[right_mask]) * right_mask.sum()
                gain = current_var - left_var - right_var  # قد إيه الـ split قلل التشتت
                if gain > best_gain:
                    best_gain, best_feature, best_threshold = gain, f, thresh
        if best_feature is None or best_gain <= 0:
            return TreeNode(value=np.mean(y))
        left_mask = X[:, best_feature] <= best_threshold
        node = TreeNode()
        node.feature_idx, node.threshold = best_feature, best_threshold
        node.left = self._build(X[left_mask], y[left_mask], depth + 1)
        node.right = self._build(X[~left_mask], y[~left_mask], depth + 1)
        return node

    def predict(self, X):
        return np.array([self._predict_one(x, self.root) for x in X])

    def _predict_one(self, x, node):
        if node.value is not None:
            return node.value
        if x[node.feature_idx] <= node.threshold:
            return self._predict_one(x, node.left)
        return self._predict_one(x, node.right)

خطوة ٥: Gradient Boosting من الصفر

class GradientBoostingScratch:
    def __init__(self, n_estimators=100, learning_rate=0.1, max_depth=3):
        self.n_estimators = n_estimators
        self.lr = learning_rate
        self.max_depth = max_depth
        self.trees = []
        self.initial_pred = None

    def fit(self, X, y):
        self.initial_pred = np.mean(y)                    # F_0 = المتوسط (أحسن ثابت للـ MSE)
        current_pred = np.full(len(y), self.initial_pred)
        for _ in range(self.n_estimators):
            residuals = y - current_pred                  # الغلط اللي فاضل
            tree = SimpleRegressionTree(max_depth=self.max_depth)
            tree.fit(X, residuals)                        # الشجرة بتتعلم الغلط
            current_pred += self.lr * tree.predict(X)     # خطوة صغيرة ناحيته
            self.trees.append(tree)

    def predict(self, X):
        pred = np.full(X.shape[0], self.initial_pred)
        for tree in self.trees:
            pred += self.lr * tree.predict(X)
        return pred

    def mse(self, X, y):
        return np.mean((self.predict(X) - y) ** 2)

خطوة ٦: Bagging

class BaggingClassifier:
    def __init__(self, n_estimators=20, max_depth=5):
        self.n_estimators = n_estimators
        self.max_depth = max_depth
        self.trees = []

    def fit(self, X, y):
        rng = np.random.RandomState(42)
        n = len(y)
        for _ in range(self.n_estimators):
            idx = rng.choice(n, size=n, replace=True)     # bootstrap: سحب مع الإرجاع
            tree = SimpleRegressionTree(max_depth=self.max_depth)
            tree.fit(X[idx], y[idx])
            self.trees.append(tree)

    def predict(self, X):
        predictions = np.array([tree.predict(X) for tree in self.trees])
        return np.sign(np.mean(predictions, axis=0))      # متوسط ثم إشارة = تصويت

    def accuracy(self, X, y):
        return np.mean(self.predict(X) == y)

خطوة ٧: Stacking (القلب بس)

الفكرة المهمة في الـ fit: الـ meta-features بتطلع من folds، كل موديل بيتوقع على الجزء اللي ماشافهوش. بعدين meta-learner بسيط (tanh + gradient descent) بيتعلم وزن لكل base model، وفي الآخر الـ base models بتتدرب تاني على الداتا كلها.

class StackingClassifier:
    def __init__(self, base_models, meta_lr=0.1, n_folds=5):
        self.base_models = base_models                    # list of factories: lambda: Model()
        self.meta_lr, self.n_folds = meta_lr, n_folds
        self.meta_weights = None; self.meta_bias = None
        self.fitted_models = []

    def fit(self, X, y):
        n = len(y)
        meta_features = np.zeros((n, len(self.base_models)))
        fold_size = n // self.n_folds
        indices = np.arange(n)
        for fold in range(self.n_folds):
            val_start = fold * fold_size
            val_end = val_start + fold_size if fold < self.n_folds - 1 else n
            val_idx = indices[val_start:val_end]
            train_idx = np.concatenate([indices[:val_start], indices[val_end:]])
            for m_idx, model_class in enumerate(self.base_models):
                model = model_class()
                model.fit(X[train_idx], y[train_idx])     # اتدرب من غير الـ fold ده
                meta_features[val_idx, m_idx] = model.predict(X[val_idx])   # واتوقع عليه: مفيش leakage

        self.meta_weights = np.zeros(len(self.base_models)); self.meta_bias = 0.0
        for _ in range(200):                              # meta-learner صغير
            preds = np.tanh(meta_features @ self.meta_weights + self.meta_bias)
            errors = y - preds
            self.meta_weights -= self.meta_lr * (-2 * meta_features.T @ errors / n)
            self.meta_bias -= self.meta_lr * (-2 * np.sum(errors) / n)

        self.fitted_models = []
        for model_class in self.base_models:              # درّب تاني على كله للاستخدام
            model = model_class(); model.fit(X, y)
            self.fitted_models.append(model)

    def predict(self, X):
        meta_features = np.column_stack([m.predict(X) for m in self.fitted_models])
        return np.sign(meta_features @ self.meta_weights + self.meta_bias)

  1. منحنى AdaBoost: عدّل الـ AdaBoost يسجل الـ training accuracy بعد كل جولة. ارسم accuracy مقابل عدد الـ estimators. بيستقر إمتى؟
    تلميحجوه الـ loop بعد ما تضيف الـ stump، احسب np.sign(sum(a*s.predict(X) for ...)) وخزّن الدقة في list. ارسم بـ matplotlib. هتلاقي الـ train accuracy بتطلع بسرعة في الأول وبعدين المكسب بيقل. قارنه بالـ test accuracy عشان تشوف هل في overfit.
  2. Random Forest من الصفر: ضيف random feature subsampling للـ regression tree. درّب 100 شجرة بـ max_features=sqrt(n_features) وخد المتوسط. قارن الـ variance reduction بشجرة واحدة.
    تلميحفي _build بدل for f in range(n_features) استخدم rng.choice(n_features, k, replace=False) مع k = max(1, int(np.sqrt(n_features)))، واختار مجموعة جديدة عند كل split مش مرة لكل شجرة. عشان تقيس الـ variance: درّب على كذا bootstrap مختلفة وقارن تشتت التوقعات على نفس نقط الـ test.
  3. Early stopping: في الـ gradient boosting، تابع الـ validation loss بعد كل جولة ووقف لو ماتحسنش ١٠ جولات ورا بعض. هو محتاج كام شجرة فعلًا؟
    تلميحقسّم الـ train لـ train/val. خزّن best_loss و best_round و عدّاد patience. لما العداد يوصل 10 اعمل break وقص self.trees = self.trees[:best_round+1]. جرّبها مع lr مختلفة: الأصغر هيحتاج أشجار أكتر.

لحد دلوقتي عشان تدرّب شبكة كنت بتعمل copy-paste من ٥ دروس: الـ Value من هنا، الـ training loop من هناك، الـ init في ملف، والـ schedule في ملف تاني. ده بالظبط اللي الـ frameworks بتحلّه. PyTorch بيديك nn.Module وnn.Sequential وoptim.Adam وDataLoader، وTensorFlow بيديك keras.Layer وkeras.Sequential وkeras.optimizers.Adam.

الفكرة المهمة: الحاجات دي مش سحر. هي أنماط تنظيم (organizational patterns) بتخليك تعرّف وتدرّب وتقيّم شبكة من غير ما تعيد بناء «السباكة» كل مرة. لما تخلّص النهاردة هتفهم ليه model.train() وmodel.eval() موجودين، وليه optimizer.zero_grad() نداء لوحده.

الـ Module: الواجهة الموحدة

فكّر في الـ Module زي فيشة الكهربا الموحّدة: أي جهاز (Linear، ReLU، Dropout، BatchNorm) لازم يبقى ليه نفس الفيشة عشان يدخل في أي بريزة. عند كل Module ٣ مسؤوليات:

  1. forward(): احسب الخرج من الدخل.
  2. parameters(): رجّع كل الأوزان اللي تتدرب.
  3. backward(): احسب الـ gradients. في PyTorch الـ autograd بيعملها لوحده، عندنا هنكتبها بإيدنا.

وكمان كل Module عنده flag اسمه training بيتقلب بـ train() وeval().

الـ Sequential: موديول جواه موديولز

الـ Sequential زي خط إنتاج في مصنع: الحاجة بتعدّي على محطة ١ وبعدين ٢ وبعدين ٣ (forward). ولما تلاقي عيب في الآخر، بترجع تسأل المحطات بالعكس: ٣ وبعدين ٢ وبعدين ١ (backward). والمهم إن الـ Sequential نفسه Module: ليه forward وbackward وparameters. ده اسمه composite pattern: مجموعة Modules متسلسلة هي نفسها Module، فتقدر تحط Sequential جوه Sequential.

الـ Optimizer: مش عارف حاجة عن الشبكة

الـ optimizer بيشوف قايمة مسطحة من الباراميترز والـ gradients بتاعتهم، وبس. مش عارف فين Linear وفين BatchNorm. SGD: param -= lr * grad. Adam: بيحتفظ بتقدير للـ momentum والـ variance لكل باراميتر وبعدين يحدّث. الفصل ده هو اللي بيخليك تبدّل SGD بـ Adam في سطر واحد.

الـ DataLoader: التغذية على دفعات

الـ batching مهم لسببين: (١) في المشاكل الكبيرة مش هتقدر تحط الداتا كلها في الميموري مرة واحدة، (٢) الـ mini-batch gradient descent بيضيف «دوشة» بتساعد تهرب من الـ local minima. الـ DataLoader بيقسم الداتا لـ batches وممكن يخلطها (shuffle) في أول كل epoch.

الصورة الكاملة

DataLoader → batch → Model.forward → Loss → Loss.backward → Model.backward → Optimizer.step → zero_grad

Modules (Linear، ReLU، Sigmoid، Dropout، BatchNorm) جوه Container (Sequential)، وجنبهم Losses (MSELoss، BCELoss) و Optimizers (SGD، Adam) و Data (DataLoader). الـ Linear والـ ReLU والـ Sequential كلهم بيورثوا من Module.

المرحلة ١ · الأساس: Module + Linear

كل layer هيورث من الكلاس ده. الـ default بتاع parameters() قايمة فاضية (الـ ReLU مثلًا ملهوش أوزان).

class Module:
    def __init__(self):
        self.training = True          # كل موديول عنده flag للـ train/eval

    def forward(self, x):             # احسب الخرج
        raise NotImplementedError

    def backward(self, grad):         # رجّع الـ gradient للي قبلك
        raise NotImplementedError

    def parameters(self):             # الأوزان اللي تتدرب (افتراضيًا: مفيش)
        return []

    def train(self):
        self.training = True

    def eval(self):
        self.training = False

الـ Linear بيحسب Wx + b وبيستخدم He init (std = √(2/fan_in)) من درس الـ initialization. لاحظ ٣ حاجات: بيحفظ self.input عشان الـ backward، والـ gradients بتتجمع بـ +=، وparameters() بترجع tuples بالشكل (container, i, j, grad_container) عشان الـ optimizer يقدر يعدّل المكان ده بالظبط.

import math
import random


class Linear(Module):
    def __init__(self, fan_in, fan_out):
        super().__init__()
        std = math.sqrt(2.0 / fan_in)  # He init من درس 08
        self.weights = [[random.gauss(0, std) for _ in range(fan_in)] for _ in range(fan_out)]
        self.biases = [0.0] * fan_out
        self.weight_grads = [[0.0] * fan_in for _ in range(fan_out)]
        self.bias_grads = [0.0] * fan_out
        self.fan_in = fan_in
        self.fan_out = fan_out
        self.input = None

    def forward(self, x):
        self.input = x                 # احفظ الدخل عشان الـ backward
        output = []
        for i in range(self.fan_out):
            val = self.biases[i]
            for j in range(self.fan_in):
                val += self.weights[i][j] * x[j]
            output.append(val)
        return output

    def backward(self, grad):
        input_grad = [0.0] * self.fan_in
        for i in range(self.fan_out):
            self.bias_grads[i] += grad[i]                          # += يعني بيتراكم
            for j in range(self.fan_in):
                self.weight_grads[i][j] += grad[i] * self.input[j]
                input_grad[j] += grad[i] * self.weights[i][j]      # ده اللي بيرجع للي قبله
        return input_grad

    def parameters(self):
        params = []                    # كل باراميتر = (المكان, i, j, مكان الـ grad)
        for i in range(self.fan_out):
            for j in range(self.fan_in):
                params.append((self.weights, i, j, self.weight_grads))
            params.append((self.biases, i, None, self.bias_grads))
        return params
Check ١: Linear(2, 16).parameters() لازم يرجع 2×16 + 16 = 48 عنصر. وLinear(2,3).forward([1.0, 2.0]) يرجع قايمة طولها 3.

المرحلة ٢ · الـ Activations

كل activation بيحفظ اللي محتاجه للـ backward: الـ ReLU بيحفظ mask (مين كان موجب)، والـ Sigmoid والـ Tanh بيحفظوا الخرج لأن المشتقة بتتكتب بيه: σ(1−σ) و 1−tanh².

class ReLU(Module):
    def __init__(self):
        super().__init__()
        self.mask = None

    def forward(self, x):
        self.mask = [1.0 if v > 0 else 0.0 for v in x]   # افتكر مين كان موجب
        return [max(0.0, v) for v in x]

    def backward(self, grad):
        return [g * m for g, m in zip(grad, self.mask)]


class Sigmoid(Module):
    def __init__(self):
        super().__init__()
        self.output = None

    def forward(self, x):
        self.output = []
        for v in x:
            v = max(-500, min(500, v))   # حماية من overflow في exp
            self.output.append(1.0 / (1.0 + math.exp(-v)))
        return self.output

    def backward(self, grad):
        return [g * o * (1 - o) for g, o in zip(grad, self.output)]


class Tanh(Module):
    def __init__(self):
        super().__init__()
        self.output = None

    def forward(self, x):
        self.output = [math.tanh(v) for v in x]
        return self.output

    def backward(self, grad):
        return [g * (1 - o * o) for g, o in zip(grad, self.output)]
Check ٢: ReLU().forward([-1, 2]) = [0.0, 2]، وبعدها backward([5, 5]) = [0.0, 5.0]. وSigmoid().forward([0]) = [0.5].

المرحلة ٣ · Dropout و BatchNorm (الطبقات اللي بتفرق بين train و eval)

class Dropout(Module):
    def __init__(self, p=0.5):
        super().__init__()
        self.p = p
        self.mask = None

    def forward(self, x):
        if not self.training:            # في الـ eval: عدّي كل حاجة زي ما هي
            return x
        self.mask = [0.0 if random.random() < self.p else 1.0 / (1 - self.p) for _ in x]
        return [v * m for v, m in zip(x, self.mask)]

    def backward(self, grad):
        if self.mask is None:
            return grad
        return [g * m for g, m in zip(grad, self.mask)]

الـ BatchNorm بيعمل normalize لكل feature على مستوى الـ batch: يطرح الـ mean ويقسم على الـ std، وبعدين يضرب في gamma ويزوّد beta (دول بيتعلموا). وقت التدريب بيحدّث running_mean وrunning_var بـ momentum، ووقت الـ eval بيستخدمهم بدل إحصائيات الـ batch.

class BatchNorm(Module):
    def __init__(self, size, momentum=0.1, eps=1e-5):
        super().__init__()
        self.size = size
        self.gamma = [1.0] * size        # scale بيتعلم
        self.beta = [0.0] * size         # shift بيتعلم
        self.gamma_grads = [0.0] * size
        self.beta_grads = [0.0] * size
        self.running_mean = [0.0] * size # للـ eval
        self.running_var = [1.0] * size
        self.momentum = momentum
        self.eps = eps
        self.x_norm = None
        self.std_inv = None
        self.batch_input = None

    def forward_batch(self, batch):
        batch_size = len(batch)
        output_batch = []
        if self.training:
            mean = [0.0] * self.size     # متوسط كل feature على الـ batch
            for sample in batch:
                for j in range(self.size):
                    mean[j] += sample[j]
            mean = [m / batch_size for m in mean]
            var = [0.0] * self.size
            for sample in batch:
                for j in range(self.size):
                    var[j] += (sample[j] - mean[j]) ** 2
            var = [v / batch_size for v in var]
            self.std_inv = [1.0 / math.sqrt(v + self.eps) for v in var]
            self.x_norm = []
            self.batch_input = batch
            for sample in batch:
                normed = [(sample[j] - mean[j]) * self.std_inv[j] for j in range(self.size)]
                self.x_norm.append(normed)
                output = [self.gamma[j] * normed[j] + self.beta[j] for j in range(self.size)]
                output_batch.append(output)
            for j in range(self.size):   # حدّث المتوسط الجاري
                self.running_mean[j] = (1 - self.momentum) * self.running_mean[j] + self.momentum * mean[j]
                self.running_var[j] = (1 - self.momentum) * self.running_var[j] + self.momentum * var[j]
        else:                            # الـ eval: استخدم الـ running stats
            std_inv = [1.0 / math.sqrt(v + self.eps) for v in self.running_var]
            for sample in batch:
                normed = [(sample[j] - self.running_mean[j]) * std_inv[j] for j in range(self.size)]
                output = [self.gamma[j] * normed[j] + self.beta[j] for j in range(self.size)]
                output_batch.append(output)
        return output_batch

    def forward(self, x):
        result = self.forward_batch([x])
        return result[0]

    def backward(self, grad):
        if self.x_norm is None:
            return grad
        for j in range(self.size):
            self.gamma_grads[j] += self.x_norm[0][j] * grad[j]
            self.beta_grads[j] += grad[j]
        return [grad[j] * self.gamma[j] * self.std_inv[j] for j in range(self.size)]

    def parameters(self):
        params = []
        for j in range(self.size):
            params.append((self.gamma, j, None, self.gamma_grads))
            params.append((self.beta, j, None, self.beta_grads))
        return params

المرحلة ٤ · الـ Sequential

class Sequential(Module):
    def __init__(self, *modules):
        super().__init__()
        self.modules = list(modules)

    def forward(self, x):
        for module in self.modules:            # شمال ← يمين
            x = module.forward(x)
        return x

    def backward(self, grad):
        for module in reversed(self.modules):  # بالعكس: من الآخر للأول
            grad = module.backward(grad)
        return grad

    def parameters(self):
        params = []
        for module in self.modules:            # لم الأوزان من كل الموديولز
            params.extend(module.parameters())
        return params

    def train(self):
        self.training = True
        for module in self.modules:
            module.train()

    def eval(self):
        self.training = False
        for module in self.modules:
            module.eval()

    def count_parameters(self):               # موجودة في code/main.py
        return len(self.parameters())

المرحلة ٥ · Losses و Optimizers

الـ loss بيرجع رقم، وbackward() بتاعه بيرجع أول gradient في السلسلة كلها. الـ BCE بيقص الـ prediction بين 1e-7 و 1−1e-7 عشان log(0) ميطلعش لانهائي.

class MSELoss:
    def __call__(self, predicted, target):
        self.predicted = predicted
        self.target = target
        n = len(predicted)
        self.loss = sum((p - t) ** 2 for p, t in zip(predicted, target)) / n
        return self.loss

    def backward(self):                  # أول gradient في السلسلة كلها
        n = len(self.predicted)
        return [2 * (p - t) / n for p, t in zip(self.predicted, self.target)]


class BCELoss:
    def __call__(self, predicted, target):
        self.predicted = predicted
        self.target = target
        eps = 1e-7
        n = len(predicted)
        self.loss = 0
        for p, t in zip(predicted, target):
            p = max(eps, min(1 - eps, p))  # ممنوع log(0)
            self.loss += -(t * math.log(p) + (1 - t) * math.log(1 - p))
        self.loss /= n
        return self.loss

    def backward(self):
        eps = 1e-7
        n = len(self.predicted)
        grads = []
        for p, t in zip(self.predicted, self.target):
            p = max(eps, min(1 - eps, p))
            grads.append((-t / p + (1 - t) / (1 - p)) / n)
        return grads

الـ optimizer بياخد القايمة المسطحة ويمشي عليها. لو j مش None يبقى وزن في مصفوفة [i][j]، غير كده يبقى عنصر في قايمة [i] (bias أو gamma/beta).

class SGD:
    def __init__(self, parameters, lr=0.01):
        self.params = parameters
        self.lr = lr

    def step(self):
        for container, i, j, grad_container in self.params:
            if j is not None:                     # وزن في مصفوفة
                container[i][j] -= self.lr * grad_container[i][j]
            else:                                 # bias أو gamma/beta
                container[i] -= self.lr * grad_container[i]

    def zero_grad(self):
        for container, i, j, grad_container in self.params:
            if j is not None:
                grad_container[i][j] = 0.0
            else:
                grad_container[i] = 0.0


class Adam:
    def __init__(self, parameters, lr=0.001, beta1=0.9, beta2=0.999, eps=1e-8):
        self.params = parameters
        self.lr = lr
        self.beta1 = beta1
        self.beta2 = beta2
        self.eps = eps
        self.t = 0
        self.m = [0.0] * len(parameters)          # momentum لكل باراميتر
        self.v = [0.0] * len(parameters)          # variance لكل باراميتر

    def step(self):
        self.t += 1
        for idx, (container, i, j, grad_container) in enumerate(self.params):
            g = grad_container[i][j] if j is not None else grad_container[i]
            self.m[idx] = self.beta1 * self.m[idx] + (1 - self.beta1) * g
            self.v[idx] = self.beta2 * self.v[idx] + (1 - self.beta2) * g * g
            m_hat = self.m[idx] / (1 - self.beta1 ** self.t)   # bias correction
            v_hat = self.v[idx] / (1 - self.beta2 ** self.t)
            update = self.lr * m_hat / (math.sqrt(v_hat) + self.eps)
            if j is not None:
                container[i][j] -= update
            else:
                container[i] -= update

    def zero_grad(self):
        for container, i, j, grad_container in self.params:
            if j is not None:
                grad_container[i][j] = 0.0
            else:
                grad_container[i] = 0.0
Check ٥: اعمل باراميتر واحد قيمته 1 والـ grad بتاعه 2، وSGD بـ lr=0.1: بعد step() لازم يبقى 0.8. وبعد zero_grad() الـ grad يرجع 0.

class DataLoader:
    def __init__(self, data, batch_size=32, shuffle=True):
        self.data = data
        self.batch_size = batch_size
        self.shuffle = shuffle

    def __iter__(self):
        indices = list(range(len(self.data)))
        if self.shuffle:
            random.shuffle(indices)              # ترتيب جديد كل epoch
        for start in range(0, len(indices), self.batch_size):
            batch_indices = indices[start:start + self.batch_size]
            batch = [self.data[i] for i in batch_indices]
            inputs = [item[0] for item in batch]
            targets = [item[1] for item in batch]
            yield inputs, targets                # generator: batch ورا batch

    def __len__(self):
        return (len(self.data) + self.batch_size - 1) // self.batch_size  # تقريب لفوق

def make_circle_data(n=500, seed=42):
    random.seed(seed)
    data = []
    for _ in range(n):
        x = random.uniform(-2, 2)
        y = random.uniform(-2, 2)
        label = 1.0 if x * x + y * y < 1.5 else 0.0   # جوه الدايرة = 1
        data.append(([x, y], [label]))
    return data


def train():
    random.seed(42)
    model = Sequential(
        Linear(2, 16), ReLU(),
        Linear(16, 16), ReLU(),
        Linear(16, 8), ReLU(),
        Linear(8, 1), Sigmoid(),
    )
    criterion = BCELoss()
    optimizer = Adam(model.parameters(), lr=0.01)

    data = make_circle_data(500)
    split = int(len(data) * 0.8)                 # 80% تدريب / 20% اختبار
    train_data, test_data = data[:split], data[split:]
    loader = DataLoader(train_data, batch_size=16, shuffle=True)

    model.train()                                # وضع التدريب
    for epoch in range(100):
        total_loss = total_correct = total_samples = 0
        for batch_inputs, batch_targets in loader:
            for x, t in zip(batch_inputs, batch_targets):
                pred = model.forward(x)          # 1. forward
                loss = criterion(pred, t)        # 2. loss
                total_loss += loss
                optimizer.zero_grad()            # 3. امسح القديم
                grad = criterion.backward()      # 4. أول gradient
                model.backward(grad)             # 5. backward في كل الطبقات
                optimizer.step()                 # 6. حدّث الأوزان
                if (1.0 if pred[0] >= 0.5 else 0.0) == t[0]:
                    total_correct += 1
                total_samples += 1
        if epoch % 10 == 0 or epoch == 99:
            print(f"Epoch {epoch:3d} | Loss: {total_loss/total_samples:.6f} | "
                  f"Train Accuracy: {total_correct/total_samples*100:.1f}%")

    model.eval()                                 # وضع التقييم
    correct = 0
    for x, t in test_data:
        pred = model.forward(x)
        if (1.0 if pred[0] >= 0.5 else 0.0) == t[0]:
            correct += 1
    print(f"Test Accuracy: {correct/len(test_data)*100:.1f}% ({correct}/{len(test_data)})")
    return model

التمارين

اختار اتنين النهاردة. تمرين ٥ هو الأهم لأنه بيصلّح حاجة في الـ loop نفسه.

  1. SoftmaxCrossEntropyLoss: لـ multi-class. اعمل softmax للـ predictions، احسب الـ cross-entropy، واعمل الـ backward المدموج. جرّبه على spiral dataset بـ ٣ classes.
    تلميحالمشتقة المدموجة بتاعة softmax + cross-entropy بالنسبة للـ logits بسيطة جدًا: p − one_hot. فبلاش Sigmoid في الآخر؛ آخر طبقة Linear بـ ٣ مخارج. 
    def softmax(z):
    m = max(z)                                  # اطرح الأكبر عشان الثبات العددي
    e = [math.exp(v - m) for v in z]
    s = sum(e)
    return [v / s for v in e]

class SoftmaxCrossEntropyLoss:
    def __call__(self, logits, target_index):
        self.p = softmax(logits)
        self.t = target_index
        return -math.log(max(1e-12, self.p[target_index]))

    def backward(self):                         # المشتقة المدموجة: p - one_hot
        return [p - (1.0 if k == self.t else 0.0) for k, p in enumerate(self.p)]
  2. LR scheduling: ضيف set_lr() للـ optimizer ووصّل الـ cosine schedule من امبارح. درّب بـ warmup + cosine وقارن بالـ lr الثابت.
    تلميحdef set_lr(self, lr): self.lr = lr. في الـ loop عدّ الخطوات (step += 1) وقبل كل optimizer.step() نادي optimizer.set_lr(warmup_cosine_schedule(step, lr=0.01, total_steps=..., warmup_steps=...)). الـ total_steps = عدد الـ epochs × عدد العينات (لأن التحديث per-sample).
  3. save() و load(): احفظ كل الأوزان في JSON ورجّعها، واتأكد إن الموديل المحمّل بيطلّع نفس الـ predictions.

    تلميح 
    # تمرين إضافي: موديول مراقبة (زي forward hooks في PyTorch)
class Monitor(Module):
    """موديول شفاف بيطبع إحصائيات الـ activations والـ gradients"""
    def __init__(self, name):
        super().__init__()
        self.name = name

    def forward(self, x):
        dead = sum(1 for v in x if v == 0) / len(x)   # نسبة الـ dead ReLUs
        self.last = (min(x), max(x), dead)
        return x                                      # مش بيغيّر حاجة

    def backward(self, grad):
        gnorm = sum(g * g for g in grad) ** 0.5
        self.last_grad = gnorm
        return grad

model = Sequential(Linear(2, 16), ReLU(), Monitor("h1"),
                   Linear(16, 1), Sigmoid())

إضافة مني: حاجات الدرس مقالهاش صريح

١. الـ loop ده فعليًا batch_size = 1. لو بصيت على الكود، zero_grad وstep بيتنادوا جوه الـ loop بتاع العينات. يعني الـ DataLoader هنا بيعمل shuffle بس، والتحديث بيحصل بعد كل عينة. تمرين ٥ هو اللي بيحوّله لـ mini-batch حقيقي.
٢. الـ BatchNorm هنا تعليمي. الـ forward(x) بينادي forward_batch([x]) بعينة واحدة، ومع عينة واحدة الـ mean = العينة نفسها والـ variance = 0، فالخرج المتنرمل بيبقى أصفار. كمان الـ backward بيعامل الـ mean والـ variance كأنهم ثوابت. علشان كده تجارب الملف مش بتستخدم BatchNorm. لو عايز تستخدمه بجد لازم تمرر الـ batch كله مرة واحدة وتكتب الـ backward الكامل.
٣. أخطاء بتحصل لكل الناس: نسيان model.eval() قبل الاختبار (Dropout شغال)، نسيان zero_grad (gradients بتتراكم)، إنك تعمل Adam(model.parameters()) قبل ما تبني كل الطبقات (الـ optimizer مش هيشوف الأوزان الجديدة)، وإنك تنسى reversed في الـ backward.
٤. فين ده في الـ LLMs؟ أي LLM في PyTorch هو شجرة Modules: الموديل جواه Sequential/ModuleList من transformer blocks، وكل block جواه attention و MLP و LayerNorm، وكلهم بنفس الواجهة اللي بنيتها. الـ gradient accumulation (تمرين ٥) بيُستخدم في تدريب و fine-tuning الموديلات الكبيرة عشان تحاكي batch كبير على GPU صغير. وparameters() هو اللي بيخليك تعمل freeze لجزء من الموديل وتدرّب جزء (زي الـ LoRA): بتدي الـ optimizer قايمة باراميترز أصغر.

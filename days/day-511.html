01

المشكلة: security theater

فريق قرا عن jailbreak، كتب regex واحد زي r"ignore (all )?previous"، شحنه، وسماه «دفاع الـ prompt injection». بعد أسبوعين نفس الهجوم جه بـ "disregard the prior"، الـ regex فوّته، والفريق لام الموديل.

المشكلة مش إن الـ regex ضعيف. المشكلة إن محدش قاسه: محدش يعرف الـ precision، ولا الـ recall، ولا بيغطي أنهي فئات. ده زي جهاز كشف معادن في مطار محدش جرّبه قبل كده على شنطة فيها مسدس ولا على شنطة فيها مفاتيح بس.

تعريف الدرس: الـ detector هو function بتاخد prompt وترجّع فئة + confidence في [0, 1]. وأي حاجة غير كده «vibe». ومع corpus متعلّم، تقدر تحسب لكل فئة TP و FP و TN و FN، وتطلّع precision و recall، والفريق يقرر يشحن إيه ويصرف السبرنت الجاي فين، ويبطّل تخمين.

التصميم: قواعد كداتا + ٣ طبقات

الـ detector هنا قايمة Rule. كل قاعدة ليها name وcategory (من الـ ٦) وscore ثابت. القاعدة يا إما تشتغل (fire) يا لأ، ولو اشتغلت الـ score بتاعها هو الـ confidence. والقواعد متخزنة كـ dictionaries في rules.py، مش كود: أي حد يقدر يضيف قاعدة من غير ما يلمس المنطق.

الطبقةبتعمل إيهمثال
١. Normalizeتكشف الكلام المستخبي قبل ما القواعد تشوفهتشيل zero-width، تفك base64
٢. Substringجمل مكتوبة بالإيد، case-insensitive"ignore previous" → instruction-override, 0.85
٣. Regexأنماط على مستوى الكلمة بتمسك «عيلة» كاملة\bignor\w*\s+(all|prior|previous|earlier)\b

الطبقة ١: Normalize بالترتيب

  1. شيل الحروف الخفية: zero-width (U+200B..U+200D, U+2060) وحروف التحكم في الاتجاه bidi (U+202A..U+202E). حد ممكن يكتب R·E·D·A·C·T·E·D بحرف مخفي بين كل حرفين فالـ substring ما يلاقيهوش.
  2. Homoglyphs: حروف سيريلية شكلها زي اللاتيني بالظبط (А ← A، О ← O…) ترجع لاتيني.
  3. Base64: أي token طوله ١٦+ من حروف الـ base64 يتجرب يتفك؛ لو طلع نص فيه حروف، يتحط مكانه.
  4. Lowercase + Hex: أي سلسلة hex طولها ١٦+ وعدد حروفها زوجي تتفك.
  5. Leet: 0→o, 1→i, 3→e, 4→a, 5→s, 7→t, @→a, $→s.
  6. Rot13 بحذر: بيعمل نسخة rot13 من النص، ويحتفظ بيها (يضيفها جنب الأصل) بس لو فيها كلمتين أو أكتر من قايمة كلمات شائعة صغيرة. ده heuristic رخيص عشان ما يضيفش زبالة لكل نص.

وحاجة مهمة: الـ detector بيحتفظ بـ النص الأصلي (lowercase) والنسخة المتنضفة الاتنين، وأي قاعدة بتشتغل لو لقت نفسها في أي واحد منهم. ليه؟ لأن فيه قواعد محتاجة تشوف الـ bytes الأصلية (وجود zero-width نفسه إشارة).

التجميع: Verdict

لكل فئة خد أعلى score من القواعد اللي اشتغلت. الفئة اللي عندها أعلى score تكسب، والـ confidence = الـ score ده. لو مفيش ولا قاعدة اشتغلت: Verdict("benign", 0.0).

prompt → normalize → (substring ∪ regex) fired → max per category → argmax → Verdict(category, confidence, fired)

القياس: confusion matrix لكل فئة

الـ runner بيقرا taxonomy.json بتاع درس ٨٢، يشغّل الـ detector على كل fixture، ويقارن الفئة الحقيقية بالفئة المتوقعة. لفئة C:

الشرطبالبلدي
TPtrue = C and predicted = Cمسكت هجوم C وسميته صح
FPtrue ≠ C and predicted = Cقلت C وهو مش C (هجوم تاني أو prompt بريء)
FNtrue = C and predicted ≠ Cهجوم C عدّى، أو اتسمى غلط، أو طلع benign
TNالباقيمش C ومتقالش C
precision = TP / (TP + FP) recall = TP / (TP + FN) F1 = 2PR / (P + R)

تشبيه: precision = «لما الإنذار يرن، كام مرة بيبقى فيه حرامي فعلًا؟». recall = «من كل الحرامية اللي دخلوا، كام واحد الإنذار رن عليه؟».

وفيه كمان corpus بريء من ٢٥ prompt (benign.py) زي «Write a Python function that reverses a linked list». المفروض ولا واحد فيهم يشغّل الـ detector، ولو اشتغل يبقى FP للفئة اللي اتقالت. ده اللي بيمسك القواعد الواسعة زيادة.

اختيار مقصود: الـ detector مايل لـ recall عالي في encoding-trick و instruction-override، وقابل بـ precision متوسطة في role-play، لأن هجمات الـ role-play بتختلط بطلبات كتابة إبداعية عادية، والبوابة النهائية هتعتمد على إشارات تانية (rules engine، classifier) في الحالات دي. والدرس نفسه بيقول إن الـ detector غلطان عن قصد في بعض الـ fixtures، والتقرير بيبيّن ده بدل ما يخبّيه.

معمل ٢: حرّك الـ threshold (تمرين ٣ قدامك)

أي verdict الـ confidence بتاعه أقل من الـ threshold يتحسب benign. عند 0 ده الـ detector الأصلي بالظبط (accuracy 0.62، والـ ٢٥ بريء عدّوا كلهم).

المصفوفة: الصفوف = الفئة الحقيقية، الأعمدة = المتوقعة، والعمود الأخير benign. القطر = صح. ارفع الـ threshold وشوف الأرقام بتهرب للعمود الأخير: الـ recall بتنزل (أو تثبت)، بس الـ precision مش مضمون تطلع: بص على role-play عند 0.80.

خطوة ٢ (M2): Normalize

import base64, codecs, re

LEET_TABLE = str.maketrans({"0": "o", "1": "i", "3": "e", "4": "a", "5": "s", "7": "t", "@": "a", "$": "s"})
ZERO_WIDTH = re.compile("[​‌‍⁠‪-‮]")
HOMOGLYPHS = str.maketrans({"А": "A", "В": "B", "С": "C", "Е": "E",
                            "Н": "H", "К": "K", "М": "M", "О": "O",
                            "Р": "P", "Т": "T", "Х": "X"})   # سيريلي ← لاتيني

def normalize(text: str) -> str:
    stripped = ZERO_WIDTH.sub("", text)               # ١. الحروف الخفية
    homoglyph_fixed = stripped.translate(HOMOGLYPHS)  # ٢. الحروف الشبيهة
    decoded = _try_decode_base64(homoglyph_fixed)     # ٣. base64 (قبل الـ lower!)
    hex_decoded = _try_decode_hex(decoded.lower())    # ٤. lower + hex
    leet = hex_decoded.translate(LEET_TABLE)          # ٥. leet
    return _try_rot13(leet)                           # ٦. rot13 بحذر

def _try_decode_base64(text: str) -> str:
    out = text
    for match in re.finditer(r"[A-Za-z0-9+/=]{16,}", text):
        tok = match.group(0)
        try:
            decoded = base64.b64decode(tok, validate=True).decode("utf-8", errors="ignore").lower()
            if decoded and any(c.isalpha() for c in decoded):   # لازم يطلع كلام
                out = out.replace(tok, " " + decoded + " ")
        except Exception:
            pass                                       # مش base64؟ سيبه
    return out

def _try_decode_hex(text: str) -> str:
    out = text
    for match in re.finditer(r"\b[0-9a-f]{16,}\b", text):
        tok = match.group(0)
        if len(tok) % 2 != 0:                          # كل byte = حرفين hex
            continue
        try:
            decoded = bytes.fromhex(tok).decode("utf-8", errors="ignore").lower()
            if decoded and any(c.isalpha() for c in decoded):
                out = out.replace(tok, " " + decoded + " ")
        except Exception:
            pass
    return out

_COMMON_WORDS = {"the", "and", "answer", "how", "do", "i", "you", "ignore",
                 "previous", "instructions", "redacted", "harmful", "is"}

def _try_rot13(text: str) -> str:
    if " " not in text:
        return text
    candidate = codecs.encode(text, "rot_13")
    words = re.findall(r"[a-z]+", candidate)
    if not words:
        return text
    score = sum(1 for w in words if w in _COMMON_WORDS)
    return text + " " + candidate if score >= 2 else text   # ضيف، ما تستبدلش

خطوة ٣ (M3): الـ Detector

from dataclasses import dataclass, field
from rules import all_rules

@dataclass
class Verdict:
    category: str
    confidence: float
    fired: list[str] = field(default_factory=list)

class Detector:
    def __init__(self, rules=None) -> None:
        rules_list = list(rules) if rules is not None else all_rules()
        self.substring_rules, self.regex_rules = [], []
        for r in rules_list:
            if "substring" in r:
                self.substring_rules.append(r)
            elif "regex" in r:                         # compile مرة واحدة بس
                compiled = re.compile(str(r["regex"]), re.IGNORECASE | re.DOTALL)
                self.regex_rules.append({**r, "_compiled": compiled})
            else:
                raise ValueError(f"rule {r.get('name')} missing substring or regex")

    def analyze(self, prompt: str) -> Verdict:
        normalized = normalize(prompt)
        haystacks = (prompt.lower(), normalized)       # الأصل والمتنضف الاتنين
        scores_by_category: dict[str, float] = {}
        fired: list[str] = []
        for r in self.substring_rules:
            if any(str(r["substring"]).lower() in h for h in haystacks):
                cat = str(r["category"])
                scores_by_category[cat] = max(scores_by_category.get(cat, 0.0), float(r["score"]))
                fired.append(str(r["name"]))
        for r in self.regex_rules:
            if any(r["_compiled"].search(h) for h in haystacks):
                cat = str(r["category"])
                scores_by_category[cat] = max(scores_by_category.get(cat, 0.0), float(r["score"]))
                fired.append(str(r["name"]))
        if not scores_by_category:
            return Verdict(category="benign", confidence=0.0, fired=[])
        best_cat = max(scores_by_category.items(), key=lambda kv: kv[1])   # الأعلى يكسب
        return Verdict(category=best_cat[0], confidence=best_cat[1], fired=fired)

خطوة ٤ (M4): المقاييس والـ evaluate

@dataclass
class PerCategoryMetrics:
    category: str
    tp: int = 0
    fp: int = 0
    fn: int = 0
    tn: int = 0

    @property
    def precision(self) -> float:
        d = self.tp + self.fp
        return self.tp / d if d else 0.0               # مفيش قسمة على صفر

    @property
    def recall(self) -> float:
        d = self.tp + self.fn
        return self.tp / d if d else 0.0

    @property
    def f1(self) -> float:
        p, r = self.precision, self.recall
        return 2 * p * r / (p + r) if (p + r) else 0.0

def evaluate(detector, fixtures, benign) -> dict:
    categories = sorted({str(f["category"]) for f in fixtures})
    metrics = {c: PerCategoryMetrics(category=c) for c in categories}
    total_correct = 0
    for f in fixtures:
        true_cat = str(f["category"])
        pred_cat = detector.analyze(str(f["prompt"])).category
        if pred_cat == true_cat:
            metrics[true_cat].tp += 1
            total_correct += 1
        else:
            metrics[true_cat].fn += 1                  # فاتت على الفئة الصح
            if pred_cat in metrics:
                metrics[pred_cat].fp += 1              # واتنسبت لفئة غلط
        for c in categories:
            if c != true_cat and c != pred_cat:
                metrics[c].tn += 1
    benign_tn = 0
    for prompt in benign:                              # الـ false positives على البريء
        v = detector.analyze(prompt)
        if v.category == "benign":
            benign_tn += 1
        elif v.category in metrics:
            metrics[v.category].fp += 1
        for c in categories:
            if c != v.category:
                metrics[c].tn += 1
    # ... جمّع per_category: tp/fp/fn/tn + precision/recall/f1 مقربين لـ 4 أرقام

  1. عيلة قواعد للـ context-smuggling (تعليمات مستخبية في JSON نتيجة tool). قيس تحسن الـ recall وتكلفة الـ FP على البريء.

  2. المساهمة الحدّية لكل قاعدة: كام TP هيضيع لو شلت كل قاعدة. رتّب.
    تلميحloop على القواعد: Detector([r for r in all_rules() if r is not rule]) وشغّل evaluate واطرح total_correct. خد بالك إن الرقم ممكن يطلع سالب: شيل قاعدة ممكن يزوّد الصح لو كانت بتسرق الـ argmax. وده حاصل فعلًا هنا مع from-now-on-unchained (بتسرق mt-06) وoverride-claim (بتسرق cs-06). ولما حسبتها لقيت إن ٢٠ قاعدة بس من الـ ٥٣ ليهم مساهمة مش صفر؛ الباقي يا إما مكرر يا إما مش بيمسك حاجة في الـ corpus ده. معمل ٣ بيحسبها جاهزة، قارن نتيجتك بيها.
  3. knob للـ confidence_threshold: اعمل sweep من 0 لـ 1 وارسم precision-recall لكل فئة.
    تلميحجوه analyze أو جوه evaluate: لو v.confidence < threshold اعتبرها benign. هتلاحظ إن الـ scores قيم ثابتة قليلة (0.40، 0.55، 0.75…)، فالمنحنى عبارة عن «سلالم» مش خط ناعم. معمل ٢ بيرسمها، بس ارسمها انت بـ matplotlib.
  4. إضافة مني · تمرين شغل حقيقي: shadow mode. في أي منتج حقيقي، ما تشغّلش detector جديد على إنه يمنع من أول يوم. شغّله في الـ shadow: يسجّل الـ verdict بس وما يمنعش. بعد فترة، خد عينة ٥٠ prompt اشتغل عليهم و٥٠ ما اشتغلش، وعلّمهم بإيدك، واحسب precision تقريبي وrecall تقريبي.
    تلميحاعمل wrapper: def handle(prompt): v = detector.analyze(prompt); log.info({"cat": v.category, "conf": v.confidence, "fired": v.fired}); return model(prompt). الـ precision من عينة الـ «اشتغل» = نسبة اللي فعلًا هجمات. الـ recall أصعب لأن الهجمات نادرة في عينة «ما اشتغلش»، فغالبًا هتحتاج تكبّر العينة دي. ومن غير ما تحس، انت كده بتعمل نفس الـ evaluate بتاع الدرس بس على داتا حقيقية.

إضافة مني: اللي الدرس ما قالوش

دي حاجات لقيتها وأنا بنقل الـ detector لـ JavaScript للمعامل وبقارن النتايج بالتقرير الأصلي:

  • • الـ normalize لوحده ما بيمسكش حاجة: et-04 (zero-width) وet-08 (homoglyph) الاتنين طلعوا benign. الـ normalize كشف redacted_harmful فعلًا، بس مفيش قاعدة بتدور على الطلب نفسه؛ القواعد كلها بتدور على شكل الحيلة. كشف الشفرة من غير قاعدة بعدها = ولا حاجة.
  • • الـ leet بيعمل false positives غريبة: «year 1850» بتبقى "i8so" بعد الـ leet، والـ regex [a-z][0-9]{1,2}[a-z] بيلاقي "i8s"، فـ rp-09 اتصنف encoding-trick! وأي كلمة زي b2b أو mp3s هتشغّله برضه. جرّبهم في معمل ١.
  • • الـ argmax بيسرق: mt-06 فيه «unchained» (0.85) و«you committed earlier» (0.75)، فاتصنف role-play. وcs-08 جواه «ignore prior instructions» فاتصنف instruction-override. ده نفس تداخل الفئات اللي اتكلمنا عليه امبارح، بس دلوقتي بقى بأرقام.
  • • القواعد إنجليزي بس: «تجاهل كل التعليمات السابقة» بتعدّي benign. أي detector مبني على قواعد لازم يتقاس على كل لغة المنتج بيدعمها. ده مهم ليك لو هتبني لمستخدمين عرب.
  • • المهاجم يقدر يقرا القواعد: قواعد ثابتة = المهاجم يجرّب لحد ما يلاقي صياغة بتعدّي. عشان كده الدرس مصمم إن الـ detector إشارة من ٤، وفي الواقع الفرق بتحط معاه classifier متدرب (موديل) بيعمم أحسن من القواعد.
  • • فين بتظهر في الـ LLMs والـ agents؟ في الـ agents، الـ detector ده المفروض يشتغل مش بس على رسالة اليوزر، لكن كمان على كل نتيجة tool وكل صفحة web وكل document قبل ما يدخلوا الـ context. فاكر cs-01؟ tool output فيه system:. ده indirect prompt injection، وهو التهديد الأكبر للـ agents اللي بتتصفح وبتقرا إيميلات.
